# EMCAD 解码器四个核心概念与分割图恢复过程

> 本文对应问题：通道注意力、空间注意力、多尺度深度卷积、注意力门控 skip connection 分别是什么意思？EMCAD 解码器怎样利用它们恢复分割图？
>
> 本文依据当前项目中的 [`lib/decoders.py`](../lib/decoders.py) 和 [`lib/networks.py`](../lib/networks.py) 编写。文中公式全部使用普通文本和代码块，避免 Markdown 阅读器不支持 LaTeX 时无法显示。

---

## 1. 最重要的结论

EMCAD 解码器不是把压缩过的原始图像重新还原出来，也不是四个模块中的某一个直接生成了器官掩膜。

更准确的完整过程是：

```text
输入医学图像
    ↓
编码器逐级下采样，得到四级特征 x1、x2、x3、x4
    ↓
EMCAD 从最深的 x4 开始逐级上采样
    ↓
利用门控 skip connection 找回编码器保存的位置和边界细节
    ↓
利用通道注意力、空间注意力、多尺度卷积筛选并细化融合后的特征
    ↓
得到四级解码特征 d4、d3、d2、d1
    ↓
1×1 输出头把内部特征转换成每个类别的 logits
    ↓
双线性插值恢复到输入图像尺寸
    ↓
Softmax + argmax 得到最终整数分割标签图
```

因此，“恢复分割图”实际上包含三类恢复：

1. **空间尺寸恢复**：通过 EUCB 和最终插值逐级提高特征图分辨率。
2. **定位细节恢复**：通过 skip connection 取回编码器浅层保存的边缘和位置线索。
3. **类别语义恢复**：通过训练得到的特征加工模块和输出头，判断每个像素属于哪个类别。

## 2. 阅读这些模块前，先认识特征张量

解码器处理的不是普通 RGB 图像，而是形如下面的四维特征张量：

```text
F.shape = [B, C, H, W]
```

各维含义是：

| 符号 | 含义 |
|---|---|
| `B` | batch size，一次并行处理的图像数量 |
| `C` | 特征通道数量 |
| `H` | 当前特征图高度 |
| `W` | 当前特征图宽度 |

例如：

```text
[B, 64, 56, 56]
```

表示每张输入图像在这一层被表示成 64 张 `56×56` 的内部特征图。

这些通道通常不能机械地理解为：

```text
通道0 = 肝脏
通道1 = 胰腺
通道2 = 背景
```

更准确的理解是，不同通道会在训练过程中学习对不同视觉模式产生响应，例如：

- 灰度或亮度变化；
- 水平、垂直或弯曲边缘；
- 局部纹理；
- 圆形、细长形或块状结构；
- 器官内部区域；
- 器官和背景的交界；
- 多种低级模式组合形成的高层语义。

一个通道也不一定只表达一种容易命名的含义。深度网络中的语义经常分布在多个通道之间。

## 3. 通道注意力：判断“哪些特征类型重要”

### 3.1 它解决什么问题

假设当前特征有 64 个通道，但这 64 个通道对当前图像、当前器官和当前解码阶段并不是同等重要的。

通道注意力要回答：

> 当前这份特征中，哪些通道代表的特征更有用，哪些通道应该被削弱？

可以把它简化记成：

```text
通道注意力回答“什么特征重要”。
```

本项目通过 `CAB` 实现通道注意力，定义位于 [`lib/decoders.py`](../lib/decoders.py#L711)。

### 3.2 输入与输出

假设输入为：

```text
F = [B, C, H, W]
```

通道注意力生成：

```text
M_c = [B, C, 1, 1]
```

然后执行：

```text
F_c = M_c × F
```

广播后，每个通道的所有空间位置都乘以该通道自己的权重。

最终形状保持不变：

```text
输入：[B,C,H,W]
权重：[B,C,1,1]
输出：[B,C,H,W]
```

### 3.3 CAB 怎样生成通道权重

第一步，对每个通道的整张 `H×W` 特征图做全局平均池化：

```python
avg_pool_out = self.avg_pool(x)
```

得到：

```text
[B,C,1,1]
```

它表示每个通道在整张特征图上的平均响应强度。

第二步，对每个通道做全局最大池化：

```python
max_pool_out = self.max_pool(x)
```

同样得到：

```text
[B,C,1,1]
```

它表示每个通道有没有出现过特别强烈的局部响应。

两者的侧重点不同：

| 统计方式 | 侧重点 |
|---|---|
| 全局平均池化 | 该通道整体上是否持续有效 |
| 全局最大池化 | 该通道是否在某个局部位置出现强响应 |

第三步，两条路径共用两层 `1×1` 卷积：

```text
C → C/ratio → C
```

默认 `ratio=16`。例如 `C=64` 时：

```text
64 → 4 → 64
```

这两层相当于一个小型通道 MLP，用于学习不同通道之间的依赖关系。

第四步，把平均池化路径和最大池化路径的结果相加，再经过 Sigmoid：

```text
M_c = sigmoid(avg_out + max_out)
```

得到 0～1 之间的通道权重。例如：

```text
[0.08, 0.91, 0.24, ..., 0.76]
```

这不是硬删除通道，而是软加权：

- 接近 1：更多保留该通道；
- 接近 0：强烈压低该通道；
- 位于中间：部分保留。

### 3.4 EMCAD 中怎样使用 CAB

在最深层，代码执行：

```python
d4 = self.cab4(x) * x
```

对应 [`lib/decoders.py`](../lib/decoders.py#L959)。

需要注意：

- `CAB` 只产生 `[B,C,1,1]` 权重；
- 真正的特征加权发生在 `self.cab4(x) * x`；
- 加权前后形状不变；
- 此时仍然不是分割图，只是被重新筛选的内部特征。

## 4. 空间注意力：判断“哪些位置重要”

### 4.1 它解决什么问题

通道注意力选出了有用的特征类型，但一张特征图中仍然既包含器官区域，也包含无关背景。

空间注意力要回答：

> 当前特征图的哪些空间位置值得重点关注？

可以简化记成：

```text
空间注意力回答“哪里重要”。
```

本项目通过 `SAB` 实现空间注意力，定义位于 [`lib/decoders.py`](../lib/decoders.py#L794)。

### 4.2 输入与输出

输入：

```text
F_c = [B,C,H,W]
```

空间注意力生成：

```text
M_s = [B,1,H,W]
```

然后执行：

```text
F_s = M_s × F_c
```

同一空间位置的所有通道共享一个空间权重。

最终形状仍不改变：

```text
输入：[B,C,H,W]
权重：[B,1,H,W]
输出：[B,C,H,W]
```

### 4.3 SAB 怎样生成空间权重

第一步，沿通道维计算平均值：

```python
avg_out = torch.mean(x, dim=1, keepdim=True)
```

得到：

```text
[B,1,H,W]
```

它表示每个空间位置在全部通道上的平均响应。

第二步，沿通道维取最大值：

```python
max_out, _ = torch.max(x, dim=1, keepdim=True)
```

同样得到：

```text
[B,1,H,W]
```

它表示每个空间位置是否至少有一个通道产生了强烈响应。

第三步，把平均图和最大图沿通道维拼接：

```python
x = torch.cat([avg_out, max_out], dim=1)
```

得到：

```text
[B,2,H,W]
```

第四步，通过 `7×7` 卷积观察较大邻域，再经 Sigmoid：

```text
[B,2,H,W]
    ↓ 7×7 Conv
[B,1,H,W]
    ↓ Sigmoid
0～1 空间权重图
```

例如器官候选区域的权重可能较大：

```text
0.82、0.91、0.95
```

无关背景区域的权重可能较小：

```text
0.05、0.12、0.20
```

### 4.4 EMCAD 中怎样使用 SAB

代码执行：

```python
d4 = self.sab(d4) * d4
```

对应 [`lib/decoders.py`](../lib/decoders.py#L962)。

单通道空间权重 `[B,1,H,W]` 会广播到全部 `C` 个通道。

### 4.5 CAB 与 SAB 的区别

| 模块 | 回答的问题 | 权重形状 | 加权方式 |
|---|---|---|---|
| CAB | 哪些特征类型重要？ | `[B,C,1,1]` | 一个通道共享一个权重 |
| SAB | 哪些空间位置重要？ | `[B,1,H,W]` | 一个位置的所有通道共享一个权重 |

最简记忆：

```text
CAB：选“什么”。
SAB：选“哪里”。
```

## 5. 多尺度深度卷积：用不同大小的邻域观察结构

### 5.1 它解决什么问题

医学图像中的目标大小、形状和边界复杂程度不同：

- 小血管、细边界需要关注局部细节；
- 中等大小结构需要观察周围组织关系；
- 大器官需要更宽的上下文才能判断其完整范围；
- 同一种器官在不同患者中的尺寸也可能不同。

如果始终只用一种卷积核，网络观察局部邻域的尺度比较单一。

多尺度卷积让同一份特征同时经过不同大小的卷积核：

```text
                   ┌─ 1×1 depth-wise convolution ─┐
输入特征 F ────────┼─ 3×3 depth-wise convolution ─┼─ 多尺度融合
                   └─ 5×5 depth-wise convolution ─┘
```

本项目默认：

```python
kernel_sizes = [1, 3, 5]
```

对应的直观含义是：

| 卷积核 | 观察范围 |
|---|---|
| `1×1` | 当前空间位置 |
| `3×3` | 当前点周围较小邻域 |
| `5×5` | 更宽的局部上下文 |

MSDC 定义位于 [`lib/decoders.py`](../lib/decoders.py#L259)。

### 5.2 什么是 depth-wise convolution

普通卷积同时执行：

```text
空间特征提取 + 不同通道之间的信息混合
```

如果输入输出通道都是 `C`，普通 `k×k` 卷积的权重数量大约是：

```text
C × C × k × k
```

深度卷积设置：

```python
groups = C
```

于是每个输入通道只使用自己的卷积核进行空间处理，不在这一步混合不同通道。

其权重数量大约是：

```text
C × k × k
```

例如 `C=128`、卷积核为 `5×5`：

```text
普通卷积权重数约为：128 × 128 × 25 = 409600
深度卷积权重数约为：128 × 25       =   3200
```

因此深度卷积非常轻量。

但它也有一个限制：每个通道独立处理，不能充分完成跨通道融合。

所以 EMCAD 使用的 `MSCB` 会把 point-wise convolution 和 depth-wise convolution 组合起来：

```text
1×1 普通卷积：负责混合和扩张通道
多尺度深度卷积：负责低成本空间建模
1×1 普通卷积：负责重新融合并投影通道
```

MSCB 定义位于 [`lib/decoders.py`](../lib/decoders.py#L354)。

### 5.3 默认 MSCB 的完整形状变化

假设输入为：

```text
x = [B,64,56,56]
```

默认扩张倍数为 2。

第一步，通过 `1×1` 卷积扩张通道：

```text
[B,64,56,56]
    ↓
[B,128,56,56]
```

第二步，分别执行三个深度卷积分支：

```text
1×1 分支：[B,128,56,56]
3×3 分支：[B,128,56,56]
5×5 分支：[B,128,56,56]
```

第三步，默认 `add=True`，将三个尺度逐元素相加：

```text
[B,128,56,56]
```

相加不会让通道数变成 384。只有 `add=False`、使用 concat 时才会变成：

```text
[B,384,56,56]
```

第四步，执行 channel shuffle，重新排列通道顺序，促进不同分组信息交换。形状不变。

第五步，通过第二个 `1×1` 卷积压回目标通道：

```text
[B,128,56,56]
    ↓
[B,64,56,56]
```

第六步，和原输入建立残差连接：

```text
输出 = 原输入 + 多尺度处理结果
```

最终仍为：

```text
[B,64,56,56]
```

### 5.4 它在恢复分割图时做什么

MSDC/MSCB 本身不进行上采样，也不会直接输出类别编号。它主要负责：

- 识别不同尺度的局部结构；
- 修整融合后的器官轮廓；
- 加强边界附近的特征；
- 利用周围组织关系消除局部歧义；
- 用较低参数量完成空间特征提取；
- 通过残差连接保留原有信息并让训练更稳定。

可以简化记成：

```text
多尺度深度卷积回答“应该观察多大的邻域”。
```

## 6. 注意力门控 skip connection：决定哪些编码器细节可以传入解码器

### 6.1 先理解普通 skip connection

编码器不断下采样：

```text
224×224
   ↓
56×56
   ↓
28×28
   ↓
14×14
   ↓
7×7
```

越靠近深层：

- 感受野越大；
- 语义越强；
- 越容易判断“大概是什么器官”；
- 但空间分辨率越低；
- 边界位置越粗糙。

编码器浅层的高分辨率特征保存了较多：

- 边缘；
- 纹理；
- 小结构；
- 准确位置。

因此 U-Net 类网络会把编码器某一级特征直接送给同分辨率的解码器：

```text
encoder x3 ───────────────> decoder d3
encoder x2 ───────────────> decoder d2
encoder x1 ───────────────> decoder d1
```

这条跨越编码器和解码器的长连接就是 skip connection。

### 6.2 为什么不能把所有浅层信息直接传过来

编码器浅层特征虽然细节丰富，也包含大量无关内容：

- 背景边缘；
- 成像噪声；
- 无关组织纹理；
- 与目标器官外观相似的结构；
- 不具有类别语义的高频细节。

如果全部无条件传给解码器，解码器可能在恢复边界的同时也引入背景干扰。

所以 EMCAD 在 skip connection 上增加 `LGAG` 注意力门，定义位于 [`lib/decoders.py`](../lib/decoders.py#L622)。

### 6.3 注意力门的两个输入

LGAG 接收：

```text
g：来自更深解码层、已经上采样的 gating 特征
x：来自编码器的同分辨率 skip 特征
```

二者特点不同：

| 输入 | 优势 | 不足 |
|---|---|---|
| 解码特征 `g` | 高层语义较强，较清楚目标大概在哪里 | 边界和小结构较粗糙 |
| 编码特征 `x` | 空间位置和边界细节较丰富 | 背景噪声多，类别语义较弱 |

注意力门的目的，就是用 `g` 的高层语义指导 `x` 的细节筛选。

### 6.4 LGAG 的计算过程

以第三解码阶段为例：

```text
g = [B,320,14,14]
x = [B,320,14,14]
```

第一步，分别投影到内部通道：

```text
W_g(g) → [B,160,14,14]
W_x(x) → [B,160,14,14]
```

第二步，把两路结果逐元素相加并激活：

```text
q = ReLU(W_g(g) + W_x(x))
```

第三步，通过 `1×1` 卷积把通道压成 1，再经过 Sigmoid：

```text
psi = sigmoid(Conv(q))
psi.shape = [B,1,14,14]
```

`psi` 是一张空间门控图。

第四步，只对编码器 skip 特征进行加权：

```text
gated_skip = x × psi
```

需要特别注意：LGAG 返回的是被筛选后的编码器 `x`，不是解码器 `g`。

第五步，EMCAD 把它与解码特征相加：

```python
x3 = self.lgag3(g=d3, x=skips[0])
d3 = d3 + x3
```

对应 [`lib/decoders.py`](../lib/decoders.py#L974)。

这可以解释成：

> 解码器利用自己已经掌握的高层语义，询问编码器：“你保存的高分辨率细节中，哪些位置与我当前寻找的目标有关？”

如果解码器认为某片区域很可能是目标器官：

```text
门控权重较大 → 更多编码器细节通过
```

如果某片区域很可能是无关背景：

```text
门控权重较小 → 对应浅层纹理受到抑制
```

### 6.5 LGAG 与 SAB 的区别

SAB 和 LGAG 都会产生空间权重，但二者用途不同：

| 模块 | 操作对象 | 生成权重的依据 | 主要目的 |
|---|---|---|---|
| SAB | 当前解码特征 | 当前特征自身 | 整理当前特征中的重要空间位置 |
| LGAG | 编码器 skip 特征 | 解码特征和编码特征共同决定 | 决定哪些外部编码器细节允许进入解码器 |

简化记忆：

```text
SAB：整理自己已有的信息。
LGAG：检查外部送来的信息。
```

### 6.6 skip connection 与 residual connection 不是一回事

本项目中同时存在两种“捷径”，不要混淆：

```text
skip connection：
编码器 x1/x2/x3 跨越较长路径，送到解码器对应阶段。

residual connection：
MSCB 内部执行 output = x + F(x)，帮助信息和梯度通过一个局部模块。
```

## 7. 四个概念的统一对照

| 概念 | 核心问题 | 主要输入 | 权重或处理范围 | 是否改变 H/W | 在 EMCAD 中的作用 |
|---|---|---|---|---|---|
| 通道注意力 CAB | 哪些特征类型重要？ | 当前特征 | 每通道一个权重 | 否 | 筛选有用语义通道 |
| 空间注意力 SAB | 哪些位置重要？ | 当前特征 | 每空间位置一个权重 | 否 | 强调器官候选区域 |
| 多尺度深度卷积 MSDC/MSCB | 应观察多大的邻域？ | 当前特征 | `1×1/3×3/5×5` 局部区域 | 默认否 | 细化局部结构和边界 |
| 注意力门控 skip connection | 哪些编码器细节应传过来？ | 解码特征 + 编码器 skip | 对 skip 生成空间门控图 | 否 | 有选择地补回边缘和定位细节 |

四者本身都不会把 `7×7` 直接变成 `224×224`。真正提高空间尺寸的是 EUCB 和最终的 `F.interpolate`。

## 8. EMCAD 怎样逐级恢复分割图

下面以默认 PVTv2-B2 编码器和 `224×224` 输入为例。

### 8.1 编码器输出四级特征

```text
输入图像：[B,3,224,224]

x1：[B, 64,56,56]
x2：[B,128,28,28]
x3：[B,320,14,14]
x4：[B,512, 7, 7]
```

它们的侧重点可以近似理解为：

| 特征 | 优势 | 不足 |
|---|---|---|
| `x1` | 位置、边缘和纹理最丰富 | 类别语义较弱，背景噪声多 |
| `x2` | 保留中等尺度细节 | 高层语义仍有限 |
| `x3` | 语义和空间细节较均衡 | 分辨率已经较低 |
| `x4` | 全局语义最强 | 只有 `7×7`，边界非常粗糙 |

`x4` 可能已经能够表达“这片区域像肝脏”，但它只有 49 个空间位置，不能精确描述 `224×224` 原图上的器官边界。

### 8.2 最深层 d4：先整理语义

EMCAD 从 `x4` 开始：

```python
d4 = self.cab4(x) * x
d4 = self.sab(d4) * d4
d4 = self.mscb4(d4)
```

数据流是：

```text
x4
  ↓ CAB：选择有用通道
  ↓ SAB：选择重要位置
  ↓ MSCB：进行多尺度局部细化
d4
```

形状保持：

```text
d4 = [B,512,7,7]
```

此时 `d4` 仍是深层特征，不是分割图。

### 8.3 EUCB 第一次上采样

EUCB 定义位于 [`lib/decoders.py`](../lib/decoders.py#L549)。

它把：

```text
[B,512,7,7]
```

变成：

```text
[B,320,14,14]
```

它完成两件事：

1. 空间尺寸扩大 2 倍；
2. 通道数从 512 投影到下一阶段需要的 320。

但单纯上采样只是在更密的网格上重新表示已有粗特征。它不能凭空知道下采样时丢失的真实边缘在哪里。

因此，必须使用编码器保存的 `x3`。

### 8.4 门控 x3 并融合

当前解码候选特征：

```text
d3_up = [B,320,14,14]
```

编码器 skip 特征：

```text
x3 = [B,320,14,14]
```

注意力门执行：

```text
filtered_x3 = LGAG(g=d3_up, x=x3)
```

然后融合：

```text
d3 = d3_up + filtered_x3
```

融合后的 `d3` 同时具有：

```text
来自深层解码路径的语义：目标大概是什么、在哪里
来自编码器 x3 的细节：更准确的位置和局部边界
```

随后再执行：

```text
CAB → SAB → MSCB
```

筛选并细化融合结果，得到：

```text
d3 = [B,320,14,14]
```

### 8.5 重复恢复到 28×28

```text
d3 [B,320,14,14]
    ↓ EUCB：二倍上采样，320→128
d2_up [B,128,28,28]
    ↓ LGAG：用 d2_up 筛选 x2
filtered_x2 [B,128,28,28]
    ↓ 与 d2_up 相加
    ↓ CAB + SAB + MSCB
d2 [B,128,28,28]
```

### 8.6 重复恢复到 56×56

```text
d2 [B,128,28,28]
    ↓ EUCB：二倍上采样，128→64
d1_up [B,64,56,56]
    ↓ LGAG：用 d1_up 筛选 x1
filtered_x1 [B,64,56,56]
    ↓ 与 d1_up 相加
    ↓ CAB + SAB + MSCB
d1 [B,64,56,56]
```

完整前向路径位于 [`lib/decoders.py`](../lib/decoders.py#L952)。

### 8.7 解码器返回四级特征

EMCAD 返回：

```python
return [d4, d3, d2, d1]
```

对应形状：

```text
d4：[B,512, 7, 7]
d3：[B,320,14,14]
d2：[B,128,28,28]
d1：[B, 64,56,56]
```

这些仍然是内部特征，不是最终类别标签图。

## 9. 内部特征怎样真正变成分割图

### 9.1 1×1 输出头把特征翻译成类别 logits

`EMCADNet` 为四级解码特征分别建立一个 `1×1` 输出头，见 [`lib/networks.py`](../lib/networks.py#L211)：

```python
self.out_head4 = nn.Conv2d(channels[0], num_classes, 1)
self.out_head3 = nn.Conv2d(channels[1], num_classes, 1)
self.out_head2 = nn.Conv2d(channels[2], num_classes, 1)
self.out_head1 = nn.Conv2d(channels[3], num_classes, 1)
```

对于 Synapse 的 9 类分割，最高分辨率解码特征发生：

```text
d1：[B,64,56,56]
       ↓ 1×1 Conv，64→9
p1：[B, 9,56,56]
```

这一步才把 64 个内部特征通道转换成 9 个类别分数通道。

对于每个 `56×56` 位置，模型都会输出 9 个 logits，例如：

```text
背景：  -1.2
主动脉： 0.4
胆囊：   2.8
左肾：   0.1
右肾：  -0.7
肝脏：   0.6
胰腺：  -0.2
脾脏：   0.3
胃：    -0.5
```

此时类别 2 的分数最高，但这些数仍是 logits，不是最终整数标签。

### 9.2 恢复到原图尺寸

最高分辨率输出 `p1` 当前为：

```text
[B,9,56,56]
```

代码执行：

```python
p1 = F.interpolate(p1, scale_factor=4, mode='bilinear')
```

见 [`lib/networks.py`](../lib/networks.py#L267)。

得到：

```text
[B,9,224,224]
```

现在原图中的每个像素位置都有 9 个类别 logits。

### 9.3 Softmax 和 argmax 生成最终标签

测试时执行：

```python
out = torch.argmax(torch.softmax(outputs, dim=1), dim=1)
```

见 [`utils/utils.py`](../utils/utils.py#L557)。

过程为：

```text
[B,9,224,224] logits
    ↓ Softmax：每个像素得到9类概率
[B,9,224,224] probabilities
    ↓ argmax：选择概率最大的类别编号
[B,224,224] integer labels
```

最终每个像素是一个整数类别：

```text
0 = 背景
1 = 主动脉
2 = 胆囊
……
8 = 胃
```

这张 `[B,224,224]` 的整数类别图才是最终分割结果。

## 10. 四个输出头与深监督

EMCAD 不只对 `d1` 建立输出头，还对 `d4、d3、d2` 建立输出头：

```text
d4：[B,512, 7, 7] → p4：[B,K, 7, 7] → 放大32倍
d3：[B,320,14,14] → p3：[B,K,14,14] → 放大16倍
d2：[B,128,28,28] → p2：[B,K,28,28] → 放大 8倍
d1：[B, 64,56,56] → p1：[B,K,56,56] → 放大 4倍
```

四个结果最后都恢复为：

```text
[B,K,224,224]
```

训练时可以让较深的粗尺度输出也直接接受标签监督，这叫 deep supervision。它可以让梯度更直接地到达不同解码阶段。

项目测试通常取返回列表最后一个 `p1` 作为最终预测。

## 11. 为什么这些模块能逐渐学会器官分割

这些模块刚初始化时并不知道：

- 什么是肝脏或胰腺；
- 哪个通道有用；
- 哪个空间位置应该被强调；
- 哪些 skip 细节应该通过；
- `1×1、3×3、5×5` 卷积应该检测什么结构。

训练时，模型预测与人工标注之间会计算损失。当前 Synapse 训练使用：

```text
总损失 = 0.3 × CrossEntropyLoss + 0.7 × DiceLoss
```

对应 [`trainer.py`](../trainer.py#L207)。

完整学习链路是：

```text
模型预测
    ↓
与人工分割标签计算交叉熵和 Dice 损失
    ↓
得到当前预测错误程度
    ↓
反向传播计算每个参数应如何变化
    ↓
优化器更新输出头、MSCB、SAB、CAB、LGAG、EUCB和编码器参数
```

经过许多训练样本后，网络逐渐学会：

- 哪些通道与目标器官有关；
- 哪些空间位置更可能是目标区域；
- 哪些大小的局部邻域有助于判断结构；
- 哪些浅层边界信息应该通过注意力门；
- 如何把融合后的特征转换成逐像素类别 logits。

所以注意力图不是人工规则，也不是程序员提前标出器官位置。它是通过最终分割损失反向传播学习出来的中间控制信号。

## 12. 为什么不能只上采样，不使用 skip connection

假设最深特征只有 `7×7`：

```text
[B,512,7,7]
```

即使连续插值到：

```text
[B,512,224,224]
```

也只是把粗糙的 49 个空间位置扩展成更密的网格。插值不会凭空创造真实边界信息。

可以类比把一张非常模糊的小图放大：

- 图像尺寸变大了；
- 像素数量增加了；
- 但原先丢失的细节并不会自动回来。

skip connection 的意义，就是编码器在下采样前保存了不同尺度的特征副本。解码器扩大分辨率后，再取回这些高分辨率特征用于定位。

因此：

```text
上采样负责“扩大网格”。
skip connection 负责“补回定位线索”。
注意力门负责“避免把所有噪声也补回来”。
```

## 13. 352×352 输入时的完整尺寸变化

如果输入为项目中另一种常见尺寸 `352×352`，PVTv2-B2 编码器输出：

```text
x1：[B, 64,88,88]
x2：[B,128,44,44]
x3：[B,320,22,22]
x4：[B,512,11,11]
```

EMCAD 解码过程：

```text
x4 [B,512,11,11]
    ↓ CAB + SAB + MSCB
d4 [B,512,11,11]
    ↓ EUCB + gated x3 + CAB + SAB + MSCB
d3 [B,320,22,22]
    ↓ EUCB + gated x2 + CAB + SAB + MSCB
d2 [B,128,44,44]
    ↓ EUCB + gated x1 + CAB + SAB + MSCB
d1 [B, 64,88,88]
```

对 9 类任务，四个输出头产生：

```text
p4：[B,9,11,11] → 放大32倍 → [B,9,352,352]
p3：[B,9,22,22] → 放大16倍 → [B,9,352,352]
p2：[B,9,44,44] → 放大 8倍 → [B,9,352,352]
p1：[B,9,88,88] → 放大 4倍 → [B,9,352,352]
```

## 14. 常见误解

### 误解一：注意力权重就是最终分割概率

不是。

```text
CAB 权重：[B,C,1,1]
SAB 权重：[B,1,H,W]
LGAG 权重：[B,1,H,W]
```

这些都是内部特征的软门控系数，不是最终的 K 类概率。

最终类别概率来自：

```text
解码特征 → 1×1类别输出头 → logits → Softmax
```

### 误解二：空间注意力图就是器官掩膜

不是。

空间注意力只表示当前阶段哪些区域值得重点处理。它可能覆盖器官、边界或与判断相关的上下文区域，不要求与人工标注掩膜完全相同。

### 误解三：上采样会自动找回丢失的信息

不会。

上采样只提高采样网格密度。真实的细节线索主要来自编码器 skip，最终边界由训练后的融合和卷积共同推断。

### 误解四：多尺度卷积负责提高分辨率

在当前 EMCAD 中不是。

MSCB 的 stride 为 1，输入输出 H/W 相同。提高分辨率的是 EUCB 和最终的 `F.interpolate`。

### 误解五：每个特征通道固定对应一个器官

通常不是。类别对应关系是在最终输出头才显式建立的。中间特征通道往往表达分布式视觉模式。

### 误解六：LGAG、SAB 是同一个模块

不是。

- SAB 根据当前特征自身生成空间权重；
- LGAG 同时观察解码特征和编码器 skip，并只筛选 skip。

### 误解七：恢复分割图等于恢复原图

不是。

模型最终恢复的是与原图同尺寸的类别标签场，而不是原始 CT 灰度值或 RGB 像素。

## 15. 用一个比喻理解整个解码器

可以把编码器和解码器想象成绘制一张器官地图。

最深层 `x4` 像一张非常粗糙的总览图：

```text
它知道城市大概位于哪里，但街道和边界不清楚。
```

EUCB 相当于把总览图逐级放大：

```text
扩大地图比例尺，但放大本身不会自动产生真实街道。
```

skip connection 相当于取回之前保存的高分辨率测绘资料：

```text
其中有道路、边界和局部纹理，也混有大量无关信息。
```

LGAG 相当于资料审核员：

```text
利用当前总览语义，只允许相关地区的细节资料进入。
```

CAB 相当于选择资料种类：

```text
当前更需要边界资料、纹理资料，还是区域语义资料？
```

SAB 相当于在地图上圈出重点区域：

```text
哪些位置值得集中处理？
```

MSDC/MSCB 相当于用不同大小的放大镜检查：

```text
小范围看精细边缘，大范围看整体结构和周围关系。
```

最后的 `1×1` 输出头相当于给每个位置正式标注类别：

```text
背景、主动脉、胆囊、左肾、右肾、肝脏、胰腺、脾脏或胃。
```

Softmax 和 argmax 则从多个候选类别中作出最终决定。

## 16. 最终记忆框架

把 EMCAD 的主要职责压缩成下面几句话：

```text
编码器：回答“图中大概有什么”。

EUCB：逐级提高空间分辨率。

skip connection：找回“具体在哪里、边界在哪里”的浅层线索。

LGAG：过滤 skip 中不相关的背景和噪声。

CAB：选择有用的特征通道，即选择“什么特征重要”。

SAB：选择有用的空间位置，即选择“哪里重要”。

MSDC/MSCB：从不同大小邻域细化结构和边界。

1×1 输出头：把内部特征翻译成每个类别的 logits。

插值 + Softmax + argmax：得到与原图同尺寸的最终整数分割图。
```

最核心的一句话是：

> EMCAD 一边上采样低分辨率语义特征，一边有选择地取回编码器保存的高分辨率细节，再通过通道筛选、空间筛选和多尺度局部建模不断细化；最终由类别输出头和推理后处理把这些特征转换成逐像素分割标签。
