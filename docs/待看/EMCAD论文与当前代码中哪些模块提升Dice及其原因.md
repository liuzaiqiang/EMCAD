# EMCAD 论文与当前代码：哪些模块让 Dice 提升，以及为什么

## 1. 先说结论

EMCAD 的 Dice 提升不是由某一个孤立层“自动产生”的，而是由一条完整的解码链共同造成的：

~~~text
PVTv2 分层编码器
        |
        v
深层语义特征 x4
        |
        v
MSCAM = CAB -> SAB -> MSCB
        |
        v
EUCB 上采样
        |
        v
LGAG 门控浅层 skip
        |
        v
解码特征与 gated skip 相加
        |
        v
下一层 MSCAM，逐级重复
        |
        v
四个 segmentation head + 多阶段监督
        |
        v
最终分割图
~~~

从论文的消融实验看，最直接的排序是：

1. **级联解码结构（cascaded structure）**提供基础提升；
2. **MSCAM，尤其是其中的 MSCB 多尺度卷积**是主要的性能贡献；
3. **LGAG**进一步提升 Dice，同时大幅降低注意力门的参数量和 FLOPs；
4. **ImageNet 预训练的 PVTv2 编码器**对最终 Dice 的影响也很大，但它不是 EMCAD 解码器本身；
5. **深监督（deep supervision）**通常带来小幅但稳定的额外提升；
6. **输入分辨率**提高会带来明显 Dice 提升，但这属于实验配置/信息保留量，不是新模块；
7. **[1, 3, 5] 多尺度卷积核、并行 MSDC、残差连接、通道和空间注意力**分别承担不同作用，其中有些有论文消融支持，有些主要是结构机制解释，不能在没有单独消融时声称“单独贡献了多少 Dice”。

必须区分两种说法：

| 说法 | 是否严谨 |
|---|---|
| 论文表 4 显示加入 MSCAM 后 Synapse Dice 从 81.92 提升到 82.86 | 严谨，属于消融证据 |
| MSCB 一定单独贡献了 0.94 个百分点 | 不严谨，表 4 消融的是整个 MSCAM，不是只拆出 MSCB |
| LGAG 可以抑制无关 skip 特征，因此有助于 Dice | 合理的结构机制解释 |
| 当前某一次训练 Dice 上升一定是 LGAG 造成的 | 不严谨，还可能来自随机种子、预训练、输入尺寸、监督方式等 |

## 2. 先确认当前项目实际使用的网络

当前训练入口使用的是 EMCADNet。其总结构在 [lib/networks.py](../lib/networks.py) 和 [lib/decoders.py](../lib/decoders.py) 中。

### 2.1 编码器

默认配置通常是：

~~~python
encoder = 'pvt_v2_b2'
pretrain = True
~~~

PVTv2-B2 提供四级层次特征：

~~~text
x1: 较浅层，高分辨率，边缘和纹理较丰富
x2: 中浅层
x3: 中深层
x4: 最深层，分辨率最低，语义最强
~~~

以 224 x 224 输入为例，典型形状是：

~~~text
x1 = [B,  64, 56, 56]
x2 = [B, 128, 28, 28]
x3 = [B, 320, 14, 14]
x4 = [B, 512,  7,  7]
~~~

这里的 B 是 batch size，第二维是通道数，最后两维是空间尺寸。

PVTv2 的价值是：深层特征可以通过 Transformer 的全局或较大范围建模理解器官之间的上下文关系。例如，某一块局部纹理单独看可能像背景，但结合整张腹部 CT 的位置和周围结构后，模型更容易判断它是否属于胰腺、肾脏或肝脏。

但 PVTv2 也有一个问题：深层 Transformer 特征很擅长语义和长距离关系，却可能不够精细地保留局部边界。EMCAD 主要是在解码端补足多尺度局部建模和细节恢复。

### 2.2 解码器

当前 EMCAD 初始化的四级通道通常是：

~~~text
channels = [512, 320, 128, 64]
~~~

解码流程是：

~~~text
x4 -> MSCAM4 -> d4
d4 -> EUCB3 -> 与 LGAG(x3) 门控结果相加 -> MSCAM3 -> d3
d3 -> EUCB2 -> 与 LGAG(x2) 门控结果相加 -> MSCAM2 -> d2
d2 -> EUCB1 -> 与 LGAG(x1) 门控结果相加 -> MSCAM1 -> d1
~~~

在代码中，所谓 MSCAM 不是一个名为 MSCAM 的 Python 类，而是三步组合：

~~~python
d = CAB(x) * x
d = SAB(d) * d
d = MSCB(d)
~~~

对应 [lib/decoders.py](../lib/decoders.py) 中 EMCAD.forward 的 d4、d3、d2、d1 路径。

## 3. 论文消融给出的直接证据

### 3.1 表 4：级联结构、LGAG、MSCAM 的贡献

论文在 Synapse 多器官数据集、PVTv2-B2 编码器上做了组件消融：

| Cascaded | LGAG | MSCAM | Dice |
|---|---|---|---:|
| No | No | No | 80.10 |
| Yes | No | No | 81.08 |
| Yes | Yes | No | 81.92 |
| Yes | No | Yes | 82.86 |
| Yes | Yes | Yes | 83.63 |

从这组实验可以得到：

#### 级联结构

从 80.10 到 81.08，提升约 0.98 个百分点。

这说明逐级解码、逐级融合并不是纯粹的代码组织方式，而是性能相关的结构设计。每一级解码输出都会作为下一级的输入，使高层语义逐步传递到高分辨率空间，而不是一次性把所有特征粗暴拼接。

#### LGAG

在已有 cascaded structure 的基础上：

~~~text
81.08 -> 81.92
提升约 0.84 个百分点
~~~

这说明用门控注意力筛选 skip 特征，比不筛选直接融合更有效。

#### MSCAM

在已有 cascaded structure 的基础上：

~~~text
81.08 -> 82.86
提升约 1.78 个百分点
~~~

这是表 4 中单独加入一个模块时更大的增益，说明 MSCAM 是论文中最重要的性能组件之一。

#### LGAG + MSCAM

两者同时加入：

~~~text
81.08 -> 83.63
总提升约 2.55 个百分点
~~~

与最简单的非级联、无注意力、无 MSCAM 配置相比：

~~~text
80.10 -> 83.63
总提升约 3.53 个百分点
~~~

论文也报告了这个完整 EMCAD 解码器的额外代价约为 0.381G FLOPs 和 1.91M 参数。

重要限制：表 4 的 MSCAM 行把 CAB、SAB、MSCB 作为一个整体加入。因此这张表证明的是 MSCAM 整体有效，不能严格拆出 CAB、SAB、MSCB 各自的独立百分点。

### 3.2 表 5：MSDC 的多尺度卷积核

论文比较了 MSDC 中不同深度卷积核：

| 卷积核集合 | Synapse Dice | ClinicDB Dice |
|---|---:|---:|
| [1] | 82.43 | 94.81 |
| [3] | 82.79 | 94.90 |
| [5] | 82.74 | 94.98 |
| [1, 3] | 82.98 | 95.13 |
| [3, 3] | 82.81 | 95.06 |
| [1, 3, 5] | 83.63 | 95.21 |
| [3, 3, 3] | 82.92 | 95.15 |
| [3, 5, 7] | 83.11 | 95.03 |
| [1, 3, 5, 7] | 83.57 | 95.18 |
| [1, 3, 5, 7, 9] | 83.34 | 95.07 |

最终选择 [1, 3, 5] 的理由不是“核越多越好”，而是它在这两个数据集上取得了最好的组合结果。

当前代码中：

~~~python
kernel_sizes = [1, 3, 5]
~~~

对应每个 MSCB 的 MSDC 分支：

~~~text
1 x 1 深度卷积：保留较局部、较直接的通道内响应
3 x 3 深度卷积：处理中等局部邻域
5 x 5 深度卷积：扩大局部感受野，补充更宽的结构上下文
~~~

医疗图像中的目标大小差异很大。胰腺、胆囊等器官的形状和尺度不同，器官内部与边界处需要的空间上下文也不同。多个核让同一层同时观察不同大小的邻域，因此比单一 3 x 3 更有机会兼顾：

~~~text
小结构和窄边界
器官内部区域
较宽的局部形状和上下文
~~~

7 x 7、9 x 9 并没有继续提高 Dice，说明更大的感受野会带来计算量和背景混入风险，不能简单把“大核”等同于“更好”。

### 3.3 表 7：并行与串行 MSDC

论文结果：

| 模型 | 串行 Synapse | 并行 Synapse |
|---|---:|---:|
| PVT-EMCAD-B0 | 81.82 | 81.97 |
| PVT-EMCAD-B2 | 83.54 | 83.63 |

并行只带来约 0.03 到 0.15 个百分点的小幅提升，但标准差更小，因此论文最终采用并行。

当前代码默认：

~~~python
dw_parallel = True
~~~

并行的含义是所有 1、3、5 分支都读取同一个输入：

~~~text
out1 = DWConv1(x)
out3 = DWConv3(x)
out5 = DWConv5(x)
融合 = out1 + out3 + out5
~~~

串行则会把前一个分支的结果加回输入，再送入下一个分支：

~~~text
x1 = x + DWConv1(x)
x2 = x1 + DWConv3(x1)
...
~~~

并行更容易保持各尺度响应的独立性，也避免后一个尺度过度依赖前一个尺度的误差。论文证据表明它略好，但这不是 EMCAD Dice 提升的最大来源。

### 3.4 表 8：LGAG 与普通 Attention Gate

论文将 LGAG 与 Attention U-Net 的普通 AG 对比：

| 模型 | AG Dice | LGAG Dice |
|---|---:|---:|
| PVT-EMCAD-B0 | 81.74 | 81.97 |
| PVT-EMCAD-B2 | 83.51 | 83.63 |

Dice 提升约 0.12 到 0.23 个百分点，看起来不大，但计算成本下降非常明显。以 B2 为例，三个注意力门的参数从 124.68K 降到 11.01K，FLOPs 从 61.68M 降到 10.47M。

这说明 LGAG 的核心价值是：

~~~text
稍微提升或保持精度
同时显著降低门控融合的计算和参数成本
~~~

### 3.5 表 9：ImageNet 预训练

这不是解码器模块，但对最终 Dice 很重要：

| 模型 | 无预训练 Dice | 有预训练 Dice |
|---|---:|---:|
| PVT-EMCAD-B0 | 77.47 | 81.97 |
| PVT-EMCAD-B2 | 80.18 | 83.63 |

提升分别约为 4.50 和 3.45 个百分点。

预训练让编码器在医学数据训练开始时已经具备较好的边缘、纹理、形状和层次特征提取能力。医学数据集样本量通常远小于 ImageNet，直接随机初始化容易过拟合或训练不稳定。这里必须把“EMCAD 结构的贡献”和“预训练的贡献”分开，否则会把预训练带来的大幅提升错误归因给解码器。

### 3.6 表 10：深监督

论文在 7 个数据集上比较有无 deep supervision，带深监督的版本在 6 个数据集上略好，其中 Synapse 影响最大。

当前训练代码中，deep supervision 对四个输出头分别计算损失：

~~~text
L = L(P[0]) + L(P[1]) + L(P[2]) + L(P[3])
~~~

它的作用不是改变前向结构，而是改变梯度路径：

~~~text
粗尺度输出也直接接收标签监督
较深层解码器获得更明确的训练信号
梯度更早、更直接地传到各级解码特征
~~~

当前代码还支持 mutation。mutation 会对四个输出头的全部非空组合计算损失，共 15 组。论文的多阶段损失对二分类明确写出单头和四头相加项；当前项目训练器的 mutation 实现更激进，使用所有非空组合。二者不要混写。

### 3.7 表 11：输入分辨率

论文 Synapse 结果显示，分辨率越高 Dice 越高，但 FLOPs 也明显增加：

| 模型 | 分辨率 | FLOPs | Dice |
|---|---|---:|---:|
| PVT-EMCAD-B2 | 224 x 224 | 4.29G | 83.63 |
| PVT-EMCAD-B2 | 256 x 256 | 5.60G | 84.47 |
| PVT-EMCAD-B2 | 384 x 384 | 12.59G | 85.78 |
| PVT-EMCAD-B2 | 512 x 512 | 22.39G | 86.53 |

分辨率提升保留了更多器官边界和小结构信息，所以 Dice 可能上升。但它不是“某个模块让 Dice 上升”，而是输入信息量、计算量和显存一起增加的结果。

## 4. 每个核心模块为什么可能提升 Dice

下面把论文模块映射到当前代码，并解释它影响 Dice 的路径。

## 4.1 MSCB：最值得优先理解的模块

当前实现位置：[lib/decoders.py](../lib/decoders.py) 中的 MSCB 类。

代码主线：

~~~text
x
 |
 v
1 x 1 point-wise convolution：C -> expansion_factor*C
 |
 v
MSDC：1、3、5 深度卷积分支
 |
 v
分支求和
 |
 v
channel shuffle
 |
 v
1 x 1 point-wise convolution：扩张通道 -> C
 |
 v
残差相加
~~~

### 为什么它有助于 Dice

#### 1. 同时捕获不同尺度的局部结构

单个 3 x 3 只能观察固定大小的邻域。器官边界、细小器官、内部纹理和较大形状需要不同感受野。1、3、5 三个尺度使每个位置同时获得多种局部证据。

#### 2. 扩张通道后再做空间加工

默认 expansion_factor=2。输入通道先扩大为 2C，使网络在中间层有更多特征子空间表达：

~~~text
C -> 2C -> 多尺度空间处理 -> C
~~~

这类似倒残差结构：先增加表达空间，再使用便宜的深度卷积做空间建模，最后压回原通道。

#### 3. 深度卷积降低成本，使多尺度设计可用

普通卷积的参数量大致与输入通道乘输出通道乘核面积相关；深度卷积让每个通道独立做空间卷积，参数量大致与通道数乘核面积相关。这样才能在不让解码器过重的情况下使用多个核。

#### 4. channel shuffle 补回跨通道交流

深度卷积的弱点是通道之间不直接混合。MSCB 用 channel shuffle 重排通道，再用第二个 1 x 1 卷积进行跨通道融合。因此它不是单纯地把每个通道各自处理完就结束。

#### 5. 残差连接保留已有语义

当前 stride=1 时返回：

~~~python
return x + out
~~~

这让 MSCB 更像“在已有特征上做修正”，而不是强迫主分支从零重建特征。残差还提供较短的梯度路径，通常有利于优化稳定。

### 关于 expansion_factor

当前项目上层默认值通常为 2，虽然 decoders.py 中 EMCAD 类的直接默认参数写成 6，但正常通过 EMCADNet 构造时会显式传入 2。扩大 expansion_factor 可能增加表达能力，但也会增加参数、FLOPs、显存和过拟合风险，不能未经消融就认定更大一定提高 Dice。

## 4.2 CAB：选择重要通道

当前实现位置：CAB 类。

CAB 对每个通道做全局平均池化和全局最大池化，然后通过共享的小型 MLP 产生通道权重：

~~~text
输入 [B,C,H,W]
    |
    +--> 全局平均池化 -> [B,C,1,1]
    |
    +--> 全局最大池化 -> [B,C,1,1]
                         |
                         v
                   共享 fc1 -> 激活 -> fc2
                         |
                         v
                 两路相加 -> Sigmoid
                         |
                         v
                   乘回原特征
~~~

它回答的是：

~~~text
当前解码阶段，哪些通道更有用？
~~~

某些通道可能更偏向边缘，某些更偏向器官内部，某些更偏向纹理或语义。CAB 可以提高相关通道权重，压低背景或噪声通道。

它有助于 Dice 的原因是减少了无关响应进入后续 MSCB 和 segmentation head 的机会，从而可能减少假阳性区域。

但 CAB 的权重是每个通道一张全局权重图，空间上同一通道共享一个权重。它不能独立回答“图像中哪个位置重要”，这由 SAB 和 LGAG 补足。

## 4.3 SAB：选择重要空间位置

当前实现位置：SAB 类。

SAB 沿通道维计算平均图和最大图，拼成 2 通道空间描述，再用 7 x 7 卷积得到空间权重：

~~~text
输入 [B,C,H,W]
    |
    +--> channel mean -> [B,1,H,W]
    |
    +--> channel max  -> [B,1,H,W]
                         |
                         v
                    concat [B,2,H,W]
                         |
                         v
                    7 x 7 Conv
                         |
                         v
                       Sigmoid
                         |
                         v
                 乘回全部 C 个通道
~~~

它回答的是：

~~~text
当前特征图的哪些空间位置更值得保留？
~~~

7 x 7 卷积比 1 x 1 观察更大的局部邻域，因此对连续器官区域、边界附近上下文和局部形状更敏感。空间门控可能使目标区域响应更集中，减少背景位置的激活。

当前 EMCAD 在每个 MSCAM 中先 CAB，再 SAB：

~~~python
d = self.cabX(x) * x
d = self.sab(d) * d
~~~

这可以理解为先做“通道筛选”，再做“位置筛选”。论文公式中的 MSCAM 是 CAB、SAB、MSCB 三者整体；当前代码中 SAB 模块参数在四个解码阶段共享，而 CAB 每级独立。

## 4.4 MSCAM：CAB + SAB + MSCB 的组合增益

论文公式是：

~~~text
MSCAM(x) = MSCB(SAB(CAB(x)))
~~~

它不是三个互不相关的技巧堆叠，而是一个顺序：

1. CAB 从通道维度筛选；
2. SAB 从空间维度筛选；
3. MSCB 在筛选后的特征上做多尺度空间加工。

组合逻辑是：

~~~text
先减少不重要的通道
再减少不重要的位置
再用多个感受野细化剩余特征
~~~

因此 MSCAM 可能比单独使用某一个操作更有效。不过当前论文表 4 只验证了 MSCAM 整体，若要知道 CAB、SAB、MSCB 谁贡献最大，需要自己补充四组以上的独立消融。

## 4.5 LGAG：用深层语义筛选浅层 skip

当前实现位置：LGAG 类。

解码器每一级都要把高层语义和编码器浅层特征融合。浅层特征的优点是边缘清楚、分辨率高；缺点是背景纹理和噪声也多。LGAG 使用当前解码特征作为 gating signal，生成空间门控图：

~~~text
g：上采样后的深层解码特征，语义较强
x：编码器 skip 特征，细节较多
 |
 +--> W_g(g)
 |
 +--> W_x(x)
          |
          v
       相加 -> ReLU -> 1 x 1 Conv -> BN -> Sigmoid
                                      |
                                      v
                                 psi [B,1,H,W]
                                      |
                                      v
                               gated skip = x * psi
~~~

随后 EMCAD 再做：

~~~python
d3 = d3 + x3
~~~

### 为什么能提升 Dice

如果直接把浅层 skip 全部融合，背景边缘、血管纹理、扫描噪声可能被带进解码器，导致：

~~~text
假阳性增多
器官边界外扩
小器官附近出现错误碎片
~~~

LGAG 让深层语义告诉浅层特征“哪些位置更可能与目标有关”，从而在融合前抑制无关位置。

它使用 3 x 3 分组卷积而不是普通 Attention Gate 的 1 x 1 卷积，因此门控计算可以观察局部邻域；分组又控制了参数量和 FLOPs。论文表 8 证明它在更低成本下略有更好的 Dice。

## 4.6 EUCB：高效上采样和通道对齐

当前实现位置：EUCB 类。

流程：

~~~text
最近邻上采样 x2
    -> 3 x 3 depth-wise Conv + BN + ReLU
    -> channel shuffle
    -> 1 x 1 Conv 改变通道数
~~~

例如 PVTv2-B2：

~~~text
512 @ 7x7  -> 320 @ 14x14
320 @14x14 -> 128 @ 28x28
128 @28x28 ->  64 @ 56x56
~~~

EUCB 本身主要承担“把解码特征恢复到下一级 skip 的分辨率并对齐通道”的职责。它的 Dice 贡献通常不能像 MSCAM 那样单独强调，因为论文表 4 的 cascaded decoder 已包含整个逐级解码过程，论文没有在表中把 EUCB 单独拆出来。

它仍然可能影响 Dice，原因是：

1. 逐级恢复空间分辨率，避免深层特征一次性放大造成细节损失；
2. 上采样后使用深度卷积修整局部响应，减少简单插值带来的粗糙边界；
3. 通道投影使其能够和对应 skip 正确融合。

## 4.7 级联结构和加法融合

EMCAD 不是把所有尺度特征一次性拼接，而是：

~~~text
d4 处理后上采样
        + gated x3 -> d3
d3 处理后上采样
        + gated x2 -> d2
d2 处理后上采样
        + gated x1 -> d1
~~~

这种级联方式的好处是：

~~~text
高层语义逐级传递
每一级都有机会重新筛选和细化
高分辨率细节不会过早与所有尺度混在一起
~~~

当前代码采用加法：

~~~python
d3 = d3 + x3
~~~

加法要求两路形状对齐，但不会像 concat 那样直接把通道数翻倍，计算更加轻量。加法还保留了两路特征的逐元素融合关系，后面的 CAB、SAB、MSCB 可以继续对合成特征进行选择和加工。

### 第一层：最有论文证据的组件

其中论文表 4 显示，在同一 PVTv2-B2、同一 Synapse 设置下，MSCAM 的单独加入增益大于 LGAG；完整两者结合达到最高 Dice。

这些部件组成了 EMCAD 的完整实现。可以解释为什么它们有助于 Dice，但不能凭结构图直接计算它们各自的贡献。

## 6. 为什么这些提升最终会体现在 Dice 上

Dice 的定义是：

~~~text
Dice = 2 * |预测区域 与 标注区域的交集| / (预测区域大小 + 标注区域大小)
~~~

因此，Dice 上升通常意味着以下一种或多种变化：

1. **漏分割减少**：预测区域更完整，交集变大；
2. **假阳性减少**：预测区域不再过度外扩，分母中的错误区域减少；
3. **边界更准确**：预测轮廓与标注轮廓更重合；
4. **小器官更稳定**：小目标不容易被背景淹没；
5. **尺度变化适应更好**：不同大小、不同形状的目标都能被较合适的感受野看到。

把 EMCAD 的模块映射到这些变化：

| 模块 | 更可能改善的错误类型 | 机制 |
|---|---|---|
| PVTv2 | 语义混淆、远距离上下文不足 | 分层特征和较大范围关系建模 |
| MSCB/MSDC | 尺度变化、局部结构丢失 | 1/3/5 多尺度局部感受野 |
| CAB | 无关通道响应 | 通道重加权 |
| SAB | 无关空间位置、局部背景 | 空间重加权和 7 x 7 邻域 |
| LGAG | skip 带入背景纹理 | 深层语义引导空间门控 |
| EUCB | 上采样后细节粗糙 | 高效上采样后局部修整 |
| 残差 | 训练不稳、特征过度破坏 | 保留原始特征和短梯度路径 |
| 深监督 | 某些解码级学不到 | 多个输出头直接得到标签梯度 |

所以更准确的说法是：

> EMCAD 通过“深层语义理解 + 浅层细节门控 + 多尺度局部细化 + 多阶段监督”同时减少漏分割和假阳性，最终提高预测区域与标注区域的重叠，也就是提高 Dice。

## 7. 当前项目代码中最容易误判的地方

### 7.1 PVTv2 和 EMCAD 的功劳不能混为一谈

网络名称 PVT-EMCAD 同时包含：

~~~text
PVTv2：编码器
EMCAD：解码器
~~~

论文表 9 表明预训练本身就能带来 3.45 到 4.50 个百分点提升。若比较一个“随机初始化 PVT + EMCAD”和一个“预训练 PVT + EMCAD”，不能把全部差值归因于 EMCAD。

### 7.2 MSCAM 不是单独一个 class

当前代码没有：

~~~python
class MSCAM(...)
~~~

而是在 EMCAD.forward 中按顺序调用 CAB、SAB、MSCB。搜索不到 MSCAM 类并不表示论文模块没有实现。

### 7.3 P[0]、P[1]、P[2]、P[3] 不是四个器官类别

四个输出头分别是多阶段解码预测；每个输出内部仍有 9 个 Synapse 类别通道。监督方式改变的是“哪些输出头接受损失”，不是改变器官类别定义。

### 7.4 训练 loss 变小不等于测试 Dice 必然变大

当前训练器可能对 mutation 的 15 个组合累加损失，对 deep supervision 累加 4 项，对 last-layer 累加 1 项。因此三种模式的 loss 数值尺度不同。最终必须用固定测试流程比较验证/测试 Dice，而不能只比较训练 loss。

### 7.5 代码中的模块存在，不代表当前实验真的使用了预期配置

需要核对：

~~~text
encoder 是否为目标 PVTv2 版本
pretrain 是否真的加载成功
kernel_sizes 是否为 [1,3,5]
expansion_factor 训练和测试是否一致
lgag_ks 是否为 3
supervision 是否为预期模式
测试时是否取 P[-1] 或显式融合
~~~

## 9. 对 Synapse 多器官分割的具体直觉

Synapse 有 8 个前景器官，器官之间大小差异明显，且部分器官边界模糊、形状变化大。不同模块可能对应不同器官难点：

~~~text
肝脏：
    区域较大，多尺度和全局语义有助于保持完整区域。

胰腺：
    较小、形态变化大、边界不清。
    多尺度 MSCB、深层语义 gating、深监督可能更重要。

胆囊：
    目标较小，容易受背景纹理影响。
    LGAG、SAB 的空间抑制可能减少假阳性。

左右肾：
    形状和位置具有一定上下文规律。
    PVTv2 的高层语义与 skip 细节融合有助于区分目标区域。

主动脉：
    局部圆形/细长结构明显。
    3 x 3、5 x 5 多尺度局部上下文有助于连续边界。
~~~

这只是机制层面的合理解释。要证明某模块对某个器官特别有效，必须比较逐器官 Dice，而不能只看总体平均 Dice。

## 10. 最终归纳

### 最主要的结构贡献

~~~text
1. MSCAM，尤其是 MSCB 的多尺度深度卷积
2. LGAG 对浅层 skip 的语义门控
3. 逐级级联解码和多尺度特征融合
~~~

### 最主要的训练/配置贡献

~~~text
1. ImageNet 预训练 PVTv2
2. 适合任务的 deep supervision 或 mutation
3. 足够的输入分辨率
4. 与训练结构一致的测试配置
~~~

### 最准确的一句话

> EMCAD 提高 Dice 的根本原因，是它没有只依赖单一尺度、单一空间位置或未经筛选的 skip 特征，而是让 PVTv2 提供高层语义，让 LGAG 筛选浅层细节，让 CAB/SAB 进行通道和空间重加权，再让 MSCB 用多个局部感受野细化特征，并通过逐级解码和多阶段监督把这些信息稳定地传到最终分割头。

但是：

> 论文能直接证明的是模块组合和消融配置的性能差异；CAB、SAB、MSCB、EUCB 等子部件各自的精确 Dice 贡献，必须在当前项目中用严格的单变量消融重新测量，不能只凭结构直觉下结论。
