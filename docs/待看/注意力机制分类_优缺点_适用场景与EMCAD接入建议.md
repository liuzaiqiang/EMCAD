# 注意力机制分类、优缺点、适用场景与 EMCAD 接入建议

## 1. 先理解“注意力”在做什么

对特征张量 `X∈R^(B×C×H×W)`，注意力机制通常学习一个权重 `A`，再进行：

```text
Y = A ⊙ X
```

`A` 可以沿通道变化、沿空间位置变化，也可以同时沿通道和空间变化。它的本质不是凭空产生新信息，而是重新分配已有特征的表示能力：重要区域权重大，不重要区域权重小。

注意力机制主要回答四类问题：

1. 哪些通道重要？
2. 哪些空间位置重要？
3. 哪些 token 或切片彼此相关？
4. 哪些 skip、尺度或分支应该被保留？

## 2. 当前 EMCAD 已经使用的注意力

### 2.1 CAB：通道注意力

代码位置：`lib/decoders.py` 的 `CAB`。

典型过程是对特征做全局平均池化和最大池化，得到每个通道的全局描述，再经过两层 `1×1` 投影和 Sigmoid，生成 `[B,C,1,1]` 的通道权重。

```text
[B,C,H,W]
→ 全局池化
→ [B,C,1,1]
→ 通道 MLP
→ [B,C,1,1]
→ 与原特征广播相乘
```

优点：参数少，计算便宜，适合筛选语义通道；对多器官分割中“哪些通道代表肝脏、胰腺或边界”有帮助。

缺点：全局池化丢掉了具体位置；同一通道的所有像素共享一个权重；小器官可能被大器官的全局统计量淹没。

适用场景：decoder、低分辨率深层特征、类别或语义通道选择。

### 2.2 SAB：空间注意力

代码位置：`lib/decoders.py` 的 `SAB`。

它沿通道做平均池化和最大池化，形成 `[B,2,H,W]`，再用空间卷积和 Sigmoid 生成 `[B,1,H,W]` 的位置权重，并广播到所有通道。

优点：直接强调器官区域和边界位置；尺寸不变；计算成本低。

缺点：所有通道共享同一张空间权重图；无法表达“某个位置对胰腺通道重要、但对肝脏通道不重要”；大卷积核会增加计算。

适用场景：高分辨率 decoder 特征、边界细化、抑制背景。

### 2.3 LGAG：门控注意力

代码位置：`lib/decoders.py` 的 `LGAG`。

它同时接收 decoder gate `g` 和 encoder skip `x`，把两路特征投影到较低维空间后相加，经过激活、卷积和 Sigmoid，得到 skip 的门控图。

```text
decoder 特征 g + encoder skip x
→ 对齐通道
→ 融合
→ 生成 0~1 权重
→ 权重 × skip
```

优点：能够抑制 encoder skip 中与当前解码目标无关的低层纹理；比无条件 `d + skip` 更有选择性。

缺点：增加分支和卷积；gate 质量不好时可能误删有效细节；它主要解决跨层融合，不是全局建模。

适用场景：U-Net 类 encoder-decoder 的 skip connection，尤其适合背景复杂、低层纹理噪声较多的医学图像。

## 3. 通道注意力家族

| 机制 | 主要做法 | 优点 | 缺点 | 适用场景 | EMCAD建议 |
|---|---|---|---|---|---|
| SE | 全局池化 + 两层 MLP | 稳定、简单、参数少 | 降维可能丢通道信息；无位置感 | 深层语义特征 | 可替换 CAB |
| ECA | 全局池化后用 1D 局部卷积建模通道邻域 | 比 SE 更轻，不做降维 | 只建模局部通道关系 | 资源受限、小 batch | 优先替换 CAB |
| GCT | 对通道响应做归一化和门控 | 计算低，抑制通道竞争 | 超参数敏感，资料和实现较少 | 多分支 CNN | 可做轻量对照 |
| SKNet | 并行不同卷积核，由输入生成尺度权重 | 能动态选择感受野 | 参数和实现复杂度高 | 尺度变化明显的目标 | 可替换 MSDC 固定相加 |
| GCNet | 全局上下文池化后进行通道校正 | 低成本补充全局信息 | 可能重复 CAB | 深层 decoder | 放 d4/d3 |

### 通道注意力的共同优缺点

共同优点是便宜、容易插入、通常不改变张量尺寸；共同缺点是依赖全局统计，空间定位能力弱。对 Synapse，通道注意力更可能改善语义混淆，但不能单独解决边界和 z 轴连续性。

## 4. 空间注意力家族

| 机制 | 主要做法 | 优点 | 缺点 | 适用场景 | EMCAD建议 |
|---|---|---|---|---|---|
| Spatial Gate | 池化通道后用卷积生成空间图 | 简单、直接 | 通道共享一张图 | 背景抑制和边界 | 已有 SAB，可替换对照 |
| CBAM spatial | 平均池化 + 最大池化 + 卷积 | 经典、易复现 | 与现有 SAB 功能重叠 | 轻量 2D CNN | 不建议无条件叠加 |
| Coordinate Attention | 沿 H、W 分别池化，保留坐标方向信息 | 对细长结构和位置敏感 | 比 SE/ECA 稍复杂 | 血管、肠道、器官边缘 | 可替换 CAB |
| RFB | 多分支卷积和膨胀率模拟不同感受野 | 兼顾局部和上下文 | 与 MSDC 重叠；参数增加 | 形状尺度变化 | 做参数匹配实验 |
| Deformable Attention/Conv | 学习采样位置或偏移 | 能适应不规则边界 | 训练不稳定、显存和实现成本高 | 形变器官、细长结构 | 放 d2/d1，后试 |

## 5. 通道-空间联合注意力

### CBAM

CBAM 通常先做通道注意力，再做空间注意力：

```text
X → Channel Attention → Spatial Attention → Y
```

优点是结构直观、适用于多数 CNN；缺点是顺序固定，且在 EMCAD 中会和 CAB+SAB 重复。正确的实验应是：

```text
原始 CAB+SAB
对照 CBAM
```

而不是在 CAB、SAB 后再盲目添加 CBAM。

### BAM

BAM 在通道和空间上并行生成注意力后融合，适合放在编码器或 decoder block 之间。它比 CBAM 更强调并行融合，但参数和显存略高，当前 EMCAD 中优先级低于 ECA、Coordinate Attention 和 SK。

### scSE / concurrent spatial-channel squeeze-excitation

scSE 同时包含 channel squeeze-excitation 和 spatial squeeze-excitation，常用于医学分割。优点是专门面向像素级分割、结构简单；缺点是两个门控可能产生冗余。它适合作为 EMCAD 的 CAB+SAB 替换基线。

## 6. 非局部与自注意力

### Non-local Block

任意位置之间计算相似性，能建立远距离依赖。

优点：全局建模强，适合器官整体形状和远距离关系。

缺点：标准实现的空间复杂度接近 `O((HW)^2)`；放在 `56×56` 特征图上可能明显增加显存。

适用场景：低分辨率深层特征，如 EMCAD 的 d4 或 d3，不建议放 d1。

### Self-Attention / MHSA

把空间位置展平为 token，计算 Query-Key-Value 注意力。

优点：建模能力强，可捕获长距离依赖。

缺点：计算量、显存和实现复杂；二维医学数据量小，容易过拟合；需要位置编码或相对位置偏置。

适用场景：深层低分辨率特征、混合 CNN-Transformer 结构。

### Axial Attention

把二维注意力拆成 H 轴和 W 轴注意力，降低复杂度。

优点：比全局 MHSA 省显存，仍能捕获长距离关系。

缺点：实现复杂，轴向分解可能损失完整二维关系；对当前 EMCAD 属于结构改造。

适用场景：d3/d4，器官整体形状建模。

### Criss-Cross Attention

每个位置只与同一行和同一列交互，经过多次传播获得较大范围上下文。

优点：比全局非局部注意力便宜；适合有连续边界的目标。

缺点：需要控制递归次数；高分辨率上仍有额外开销。

适用场景：细长器官、血管、边界连续结构。

## 7. 交叉尺度、跨层和门控注意力

### FPN/BiFPN 加权融合

对不同尺度特征学习非负归一化权重，而不是直接相加。

优点：解决多尺度特征贡献不均的问题；与 EMCAD 的 skip 融合很契合。

缺点：需要统一通道和空间尺寸；权重可能塌缩到单一路径。

适用场景：encoder-decoder、目标大小变化明显的分割任务。

### ASFF

对每个空间位置学习不同尺度的融合权重。

优点：比全局固定权重更灵活；适合器官大小和边界差异大的任务。

缺点：需要改动多尺度特征接口；参数量和调参成本高。

适用场景：多尺度检测、医学多器官分割。

### Gated Skip / Attention Gate

使用 decoder 语义特征控制 encoder skip 的通过比例。

优点：与 U-Net 结构天然兼容，能减少低层噪声。

缺点：gate 过强会删除小器官边界；需要检查门控图是否饱和。

适用场景：当前 EMCAD 的 `d + skip` 融合处。EMCAD 已有 LGAG，因此应做替换或参数匹配，而不是简单叠加。

## 8. 频域、相似度和调制类注意力

### FcaNet

用多频率二维离散余弦变换提取通道统计，而不是只用全局平均池化。

优点：保留更丰富的频率信息；可能改善纹理和边界。

缺点：实现和频率选择更复杂；小数据集上收益不稳定。

适用场景：纹理明显、边界依赖频率信息的图像。

### SimAM

通过神经元能量函数产生无参数注意力。

优点：几乎不增加可学习参数，接入最简单。

缺点：表达能力有限；对任务和特征归一化敏感。

适用场景：希望低风险测试注意力收益时，可放在 MSCB 输出后。

### Focal Modulation

通过局部上下文聚合和内容相关门控调制特征。

优点：比完整 Transformer 注意力更适合卷积特征，能覆盖不同上下文范围。

缺点：模块较新，代码实现和超参数更多；替换现有 MSDC 需要谨慎。

适用场景：d3/d2 的空间上下文增强。

## 9. 跨切片注意力

2.5D inter-slice attention 将 `z-1,z,z+1` 等相邻切片编码后融合，只预测中心切片。

优点：能够处理当前 EMCAD 完全缺失的 z 轴上下文，可能减少层间断裂。

缺点：不是单纯 decoder 即插即用；必须修改 Dataset、输入适配、增强同步和测试推理；还要处理 z-spacing 和边界切片。

适用场景：Synapse 这类三维 CT 切片分割。建议先做 3 张，再比较 5 张，不要直接假定 7/9 张更好。

## 10. 如何为 EMCAD 选择注意力机制

### 按问题选择

| 你想解决的问题 | 首选候选 |
|---|---|
| 通道语义混淆 | ECA、SE、Coordinate Attention |
| 背景假阳性 | SAB、CBAM、SimAM |
| 器官边界不准 | Coordinate Attention、Deformable Conv、Boundary Head |
| encoder skip 噪声 | LGAG、Attention Gate、Gated Skip |
| 多尺度贡献不均 | SK、BiFPN、ASFF、动态 MSDC |
| 远距离二维上下文不足 | GCNet、Axial Attention、Criss-Cross |
| 前后切片不连续 | 2.5D inter-slice attention |

### 按接入难度排序

1. **低风险**：ECA、SE、SimAM、Coordinate Attention、Lovász/Tversky 等损失。
2. **中风险**：SK、RFB、ASPP、BiFPN、Boundary Head、Deformable Conv。
3. **高风险**：Non-local、Axial Attention、Criss-Cross、ASFF、2.5D 跨切片注意力。

## 11. 面向 Dice 的实验建议

建议保持 `PVTv2-B2、224×224、病例划分、seed、训练轮数和损失` 不变，每次只替换一个模块：

```text
E00：原始 CAB + SAB + LGAG
E01：ECA 替换 CAB
E02：Coordinate Attention 替换 CAB
E03：SimAM 替换 CAB/SAB
E04：SK 替换 MSDC 固定相加
E05：Gated Skip 替换 LGAG 或 d+skip
E06：ASPP 替换 d4 的 MSCB
E07：Boundary Head + 原损失
E08：2.5D-3 + 中心切片监督
```

每个实验至少报告 mean Dice、8 个器官 Dice、HD95 和显存。尤其查看胆囊、胰腺、胃，而不是只看一次平均 Dice。

## 12. 最重要的结论

注意力机制没有统一的“最强排名”：

- 通道注意力便宜，但位置能力弱；
- 空间注意力能找区域，但通常通道共享权重；
- 联合注意力更全面，但容易重复和增加计算；
- 非局部/自注意力全局能力强，但显存和过拟合风险高；
- 跨层门控适合 U-Net，但可能误删细节；
- 跨切片注意力最可能解决 EMCAD 当前缺少的 z 轴信息，但改动最大。

对当前 EMCAD，最合理的路线不是把所有注意力叠加，而是先明确误差来源，再选择一个与该误差对应的注意力机制，并通过器官级 Dice、HD95 和多次重复实验验证。
