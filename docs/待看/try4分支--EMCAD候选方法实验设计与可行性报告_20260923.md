# EMCAD 候选方法实验设计与可行性报告

日期：2026-09-23  
适用分支：`try4`  
候选名称：EMCAD 输出端分歧引导图块残差细化（EMCAD Disagreement-Routed Tile Residual Refinement，暂记 DTRR）

## 1. 研究问题和主假设

当前 EMCAD 编码器、EMCAD 解码器、四路多尺度输出和既有监督方式保持为唯一 baseline。候选模块只读取 EMCAD 已经生成并上采样到输入分辨率的最终输出 `p1` 与相邻尺度输出 `p2`，在 `p1` 上增加残差 logits；`p4/p3/p2` 和原有监督组合不改变。

主假设预先限定为：**在图块大小 `16`、选择比例 `0.25`、其余训练协议完全相同的条件下，使用 `p1/p2` 类别预测分歧选择图块（`disagreement`）是否优于同计算预算的固定均匀选块（`uniform`），从而提高患者级总体 Dice。** 这是候选方法/待验证方法，代码和本报告不预先声称有效。

当前会话无法读取用户所说的截图内容，因此不能声称本实现已经按截图逐字复现；实现依据是当前仓库中已确定的 EMCAD 输出端增量方向。若截图创新点不同，应在正式训练前暂停并修正假设与模块定义。

## 2. 最小方法定义

`EMCADNet` 在原有四路 logits 完成上采样后执行：

1. `features = concat(p1, p2)`，形状为 `[B, 2K, H, W]`；
2. 轻量卷积头 `3x3 -> ReLU -> 1x1` 预测 `[B, K, H, W]` 残差；
3. 仅把残差加到 `p1`，返回列表仍为 `[p4, p3, p2, p1_refined]`；
4. 最后卷积层零初始化，所以候选训练开始时的输出等于 EMCAD 输出；
5. `dense` 对所有位置细化；`uniform` 在按行展开的一维图块编号上用 `linspace` 等间隔选固定编号（**不保证二维空间均匀分布**）；`disagreement` 按 `argmax(p1) != argmax(p2)` 的图块平均分歧率选择 top-k 图块。

`uniform` 与 `disagreement` 使用相同的图块大小、选择数量和 halo 处理；二者的唯一预声明差异是图块路由信号。`dense` 用于判断“加入细化头”整体是否有作用，不能单独证明分歧路由机制。`off` 是不含新增参数的 EMCAD baseline。

## 3. 严格消融矩阵

| 组别 | `refinement_mode` | 唯一改变因素 | 可归因结论 |
|---|---|---|---|
| B0 | `off` | 无新增模块 | 当前 EMCAD baseline |
| B1 | `dense` | 加入输出端残差细化头，所有位置计算 | 相对 B0 只能归因于“新增细化头整体” |
| B2 | `uniform` | B1 的细化头改为固定编号选块，预算 `25%` | 与 B3 配对时作为路由对照；B1→B2 还改变处理范围和计算量 |
| B3 | `disagreement` | 仅把 B2 的固定路由换为 p1/p2 分歧 top-k 路由 | 相对 B2 才能检验主假设 |

正式比较固定：病例清单、数据目录、预处理、损失、四路监督、batch size、epoch、优化器、学习率、checkpoint 选择规则、评估实现、输入尺寸和 `tile_size=16/tile_ratio=0.25` 全部一致。每个组都新建独立输出目录，禁止覆盖旧权重、CSV 和日志。

如果要报告“稳定改善”，必须在预先登记的多个 seed 上逐病例按 `case_name` 配对，并报告均值、标准差和每例差值；单一 seed 只能是一次配对结果。不得按测试 Dice 选择结构、阈值或 seed。

## 4. 数据划分和评估边界

代码没有生成、修改或重排任何病例清单。ACDC 仍由现有 `train.txt/valid.txt/test.txt` 路径驱动；Synapse 仍沿用仓库当前 `train` 与 `test_vol` 流程。Synapse 训练入口当前每轮使用 `test_vol` 评估并选择 `best.pth`，这意味着若该清单是官方测试病例，则测试集参与模型选择，存在论文规范风险。这里按用户明确要求保留现状，没有擅自改变划分；论文中必须如实说明，且不能把该结果包装为严格独立测试。

ACDC 使用现有验证集选择 checkpoint，最终测试只在参数冻结后运行。两个测试入口均要求显式 checkpoint 和全新的输出目录；Synapse 额外保存逐病例 CSV，ACDC 保留现有逐病例 CSV。指标定义、空类别处理和体推理流程未被重写。

## 5. 服务器运行参数

未修改任何 `.sh`。下面是需要在远程 Linux 上确认或增加的 Python 参数；路径按服务器实际目录替换。

训练 Synapse（四组分别使用不同 `run_name`）：

```bash
python train_synapse.py --run_name syn_b0_s2222 --refinement_mode off --seed 2222 --output_dir ./model_pth/Synapse
python train_synapse.py --run_name syn_b1_s2222 --refinement_mode dense --refinement_tile_size 16 --refinement_tile_ratio 0.25 --seed 2222 --output_dir ./model_pth/Synapse
python train_synapse.py --run_name syn_b2_s2222 --refinement_mode uniform --refinement_tile_size 16 --refinement_tile_ratio 0.25 --seed 2222 --output_dir ./model_pth/Synapse
python train_synapse.py --run_name syn_b3_s2222 --refinement_mode disagreement --refinement_tile_size 16 --refinement_tile_ratio 0.25 --seed 2222 --output_dir ./model_pth/Synapse
```

训练 ACDC：

```bash
python train_acdc.py --run_name acdc_b0_s2222 --refinement_mode off
python train_acdc.py --run_name acdc_b1_s2222 --refinement_mode dense --refinement_tile_size 16 --refinement_tile_ratio 0.25
python train_acdc.py --run_name acdc_b2_s2222 --refinement_mode uniform --refinement_tile_size 16 --refinement_tile_ratio 0.25
python train_acdc.py --run_name acdc_b3_s2222 --refinement_mode disagreement --refinement_tile_size 16 --refinement_tile_ratio 0.25
```

Synapse 最终评估必须显式给出对应 `best.pth` 和新目录；其余 EMCAD 结构参数必须与训练命令一致：

```bash
python test_synapse.py --checkpoint ./model_pth/Synapse/syn_b3_s2222/best.pth --output_dir ./eval/Synapse/b3_s2222 --refinement_mode disagreement --refinement_tile_size 16 --refinement_tile_ratio 0.25
```

ACDC：

```bash
python test_acdc.py --checkpoint ./model_pth/ACDC/acdc_b3_s2222/best.pth --output_dir ./eval/ACDC/b3_s2222 --refinement_mode disagreement --refinement_tile_size 16 --refinement_tile_ratio 0.25 --output_csv ./eval/ACDC/b3_s2222/test_metrics.csv
```

正式运行前必须核对 `--root_path`、`--volume_path`、`--list_dir`、`--encoder`、`--img_size`、`--supervision`、`--batch_size`、`--base_lr`、`--max_epochs` 与当前基线命令一致。不要用 smoke test、合成数据、损失下降、参数量或单器官指标替代总体患者级 Dice 证据。

## 6. 结果判定规则

只有当 B3 相对 B2 在同一病例清单、同一 seed 配对下总体患者级 Dice 改善，并在预先登记的重复 seed 上方向稳定，且 B1/B2/B3 的消融关系支持路由机制，才可以写“分歧路由带来提升”。若仅 B1 优于 B0，只能写“残差细化头整体有效”；若只改善某器官、单一 seed、验证集或边界指标，结论必须限定。若 B3 不稳定或不优于 B2，应报告负结果并停止该假设，不得挑选有利 checkpoint 或病例。

截至本报告生成时没有远程正式训练或测试结果，因此 Dice 效果状态为：**尚未验证**。
