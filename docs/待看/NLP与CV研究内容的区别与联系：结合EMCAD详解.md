# NLP 与 CV 研究内容的区别与联系：结合 EMCAD 详解

## 1. 最核心的区别是什么？

**NLP 主要研究如何让计算机处理、理解和生成语言；CV 主要研究如何让计算机从图像、视频及其他视觉数据中感知、理解、重建和生成视觉世界。**

- NLP：Natural Language Processing，自然语言处理。
- CV：Computer Vision，计算机视觉。

这是一种按研究对象和问题划分的学科边界，不是按“是否使用 Transformer”或“模型参数有多大”划分。

两者都是人工智能中的重要方向，但 AI 还包括机器学习基础、机器人、规划、搜索、强化学习、语音等，不能把整个 AI 只分成 NLP 和 CV。

你的 EMCAD 医学图像分割研究，主要属于 **CV 与医学影像计算的交叉领域**。即使编码器使用 Transformer 和 token，它仍然是视觉研究，不会因此变成 NLP。

## 2. 用同一位患者的资料理解两者

假设有一位患者的腹部 CT、影像报告和病历：

| 输入资料与任务 | 主要属于什么 | 输出举例 |
|---|---|---|
| 从腹部 CT 勾画肝脏、胃和胰腺 | CV：医学图像分割 | 每个像素／体素的器官标签 |
| 从影像报告提取病灶大小和位置 | NLP：信息抽取 | 部位、大小等结构化字段 |
| 判断病历中的“未见转移”是否表示转移存在 | NLP：否定与语义理解 | “当前描述不支持转移” |
| 根据多次 CT 判断病灶位置是否对应 | CV：配准、追踪或变化分析 | 空间对应与变化量 |
| 根据 CT 生成影像报告 | 视觉—语言多模态 | 一段与影像一致的文字 |
| 输入“请标出胰腺”，在 CT 中生成掩膜 | 语言引导的视觉分割 | 指定器官的分割结果 |

这个例子说明：研究的领域取决于你处理什么信息、解决什么问题，而不是取决于应用场景是否都叫“医疗”。

## 3. 整体对照表

| 维度 | NLP | CV |
|---|---|---|
| 典型输入 | 文本、词／子词序列、文档、对话 | 图像、视频、体数据、深度图、点云等 |
| 信息组织 | 词序、句法、语义、篇章、对话关系 | 空间邻接、几何、尺度、纹理、运动、三维关系 |
| 典型输出 | 类别、实体、关系、答案、生成文本 | 类别、框、掩膜、关键点、深度、三维结构、生成图像 |
| 常见歧义 | 一词多义、指代、否定、隐含意图 | 遮挡、视角、光照、模糊、相似外观 |
| 典型标注 | 文本类别、实体跨度、翻译、问答、偏好 | 图像类别、检测框、像素掩膜、关键点、深度 |
| 部分典型模型 | 统计模型、RNN、Transformer、语言模型 | CNN、视觉 Transformer、扩散模型、几何模型 |
| 部分典型指标 | Accuracy、F1、BLEU、ROUGE、困惑度及人工评价 | Accuracy、mAP、IoU、Dice、HD95、PSNR 等 |
| 核心困难之一 | 表达灵活，正确答案可能有多种说法 | 外观变化大，精确位置与结构恢复困难 |

这些是常见倾向，不是绝对限制。NLP 也处理结构与空间概念，CV 也处理序列和生成；不同任务的差异，有时比 NLP 与 CV 的整体差异更大。

## 4. NLP 到底研究哪些内容？

### 4.1 语言表示：如何把文字变成可计算的对象

计算机不能直接用人类直觉处理“胃”“疼痛”“可能”等词语，通常要将文本转为离散 token，再映射为向量。

研究问题包括：

- 如何分词或切分子词？
- 如何表示多义词和罕见词？
- 如何让表示随上下文变化？
- 如何处理不同语言、专业术语和长文档？

例如，“苹果发布新品”和“患者吃了苹果”中的“苹果”，在不同上下文中应该形成不同的语义表示。

### 4.2 文本分类

给整段文本或某个片段分配类别。例如垃圾邮件检测、情感分析、病历类型分类。

“患者否认胸痛”和“患者出现胸痛”包含相同关键词，但分类可能相反。因此不是简单看有没有某个词。

### 4.3 信息抽取

从自然语言中提取实体、关系和事件。例如：

> 胰腺尾部见约 2 cm 低密度灶。

可提取部位“胰腺尾部”、大小“约 2 cm”、描述“低密度灶”。这需要定位原文片段，并判断字段含义。

还包括实体关系、事件发生时间、用药剂量、否定与不确定性。提取到一段文字，不代表已经完成临床诊断。

### 4.4 句法、语义、篇章与语用

- 句法：谁与谁构成修饰、主谓宾等结构关系。
- 语义：句子表达什么内容，前后是否矛盾。
- 篇章：跨句子的指代、论证和信息衔接。
- 语用：结合语境理解说话者意图。

例如“这段写得太学术了”可能是在请求改写，并非只是在陈述一个事实。现代模型可能隐式学习这些关系，但相关研究问题没有因此消失。

### 4.5 翻译、摘要和改写

翻译要保持含义，摘要要保留重要信息，改写要满足风格约束。不同任务的目标不同，不能用“生成得通顺”代替全部评价。

病历摘要尤其需要保留否定、时间、剂量和关键异常，不能为了简短而改变事实。

### 4.6 问答、对话与检索增强

研究如何理解问题、寻找依据、组织答案和维持多轮上下文。检索增强生成（RAG）把外部资料检索与回答生成结合起来。

检索到资料不保证答案忠实于资料。研究还包括证据归因、冲突处理、不可回答问题、工具使用与事实一致性。

检索本身也属于信息检索领域，不能把所有检索系统都归为 NLP。

### 4.7 语言生成与大语言模型

包括预训练、指令微调、偏好优化、推理、长上下文、多语言、可控生成、效率和可靠性等。

LLM 是 NLP 中很重要的模型路线，但 NLP 不等于聊天机器人，也不是所有 NLP 问题都需要大模型。对固定分类或实体抽取，小模型可能更经济、可控。

代码生成与语言模型关系密切，但程序语言不是自然语言；相关研究也交叉软件工程、程序分析和形式方法。

## 5. CV 到底研究哪些内容？

### 5.1 图像分类：是什么？

输入一张图片，输出类别。例如猫／狗，或某种病变类别。

分类输出通常不精确说明目标在哪里。多标签分类还允许一张图同时含多个类别。

### 5.2 目标检测：是什么，在哪里？

输出目标类别与位置框。例如在图像中找出多个结节的位置。

框给出范围，但不能精确描述不规则边界。

### 5.3 图像分割：每个位置属于什么？

| 类型 | 目标 | 例子 |
|---|---|---|
| 语义分割 | 给每个位置分配语义类别 | 背景、肝脏、胃、胰腺 |
| 实例分割 | 区分同类中的不同个体 | 每一个细胞各有独立编号 |
| 全景分割 | 结合语义与实例层面的标注 | 同时标注可数个体及背景区域 |

EMCAD 在 Synapse 上主要进行多类器官语义分割。它最终对位置进行分类，但研究难度不只是把图像分类器重复运行：边界、上下文、尺度和结构一致性都很重要。

### 5.4 关键点、姿态和形状估计

定位人体关节、面部标志点、器官解剖标志点，或恢复目标形状。核心不仅是“认出来”，还包括结构是否合理。

### 5.5 视频理解、追踪与运动估计

视频除了空间维度，还有时间维度。研究对象包括目标追踪、动作识别、事件理解、光流及时间一致性。

CT 相邻切片有三维空间关系，但通常不是时间序列；不能把切片索引与视频时间直接等同。动态医学影像则可能同时包含空间和时间。

### 5.6 三维视觉与几何

研究深度估计、相机姿态、三维重建、点云理解、SLAM 等。这里的相机模型、投影几何、尺度与坐标变换非常重要，不只是网络层堆叠。

### 5.7 低层视觉和图像重建

包括去噪、去模糊、超分辨率、修复、图像增强和成像重建。

医学场景中，从采样测量重建 CT/MRI 图像，与对已重建图像分割器官，是不同任务。前者还会涉及成像物理和逆问题。

### 5.8 图像和视频生成

包括按文本生成图像、编辑局部内容、控制姿态和布局、生成视频等。不是所有 CV 任务都只“识别”，视觉生成也是重要方向。

生成结果看起来真实，不代表医学结构或病理信息真实可靠。医学增强、修复和合成尤其需要防止制造或抹去关键异常。

## 6. 数据的本质差异：语言符号与视觉测量

### 6.1 文本 token 通常来自离散词表

文本经过 tokenizer 转成整数 ID，再查找或计算向量表示。一个 token 可能是词、子词、字符或字节片段，不能简单说“一词等于一个 token”，中文也不保证“一字一个 token”。

具体切分以实际 tokenizer 为准，不应凭肉眼给出所谓唯一切分结果。

### 6.2 视觉 token 通常来自局部图像特征

图像起初是一张数值网格，例如 RGB 为 `[B,3,H,W]`。模型可以通过卷积或 patch 投影形成 `[B,N,C]` 的 token 序列。

在你当前 EMCAD 的 PVTv2-B2 中，224×224 输入的第一阶段产生 `[B,3136,64]`：3136 个空间位置，每个位置 64 维特征。

这里没有文字词表；3136 不是单词数，64 不是器官数。视觉 token 来自对图像的学习变换。

部分视觉生成模型会采用离散视觉编码，但这不是所有 CV 模型都使用的做法，也不是当前 PVTv2 这条路径。

### 6.3 两者都数字化，但结构不同

图像存储在计算机中也经过离散采样和量化，所以不能粗暴说“文本离散，图像绝对连续”。更有用的区别是：

- 文本的 token 是语言符号序列中的单元。
- 图像值是空间网格上的测量或编码数值。
- 视觉模型需要处理空间邻接、尺度和几何变化。
- 语言模型需要处理词序、组合语义、指代和语境。

## 7. 为什么顺序与空间都不能随便打乱？

### 7.1 NLP 中改变顺序可能改变含义

“医生帮助患者”和“患者帮助医生”，词基本相同，角色关系不同。

“没有发现病灶”和“发现没有消退的病灶”，共享一些词，却表达不同事实。

### 7.2 CV 中改变位置可能破坏结构

把 CT 的像素随机打乱，强度直方图可以基本不变，但器官形状与空间关系已被破坏。

把 token 展平为序列，并不表示模型可以忽略二维布局。PVTv2 保留 H、W，并在部分操作中恢复二维特征图。

### 7.3 关注点随任务变化

分类通常希望对一定程度的平移或视角变化保持稳定；分割则需要预测随目标位置一起移动。前者常涉及不变性，后者更强调对应的等变关系。

这些是设计目标，不是任意网络天然严格满足的数学性质。也不能说 NLP 没有空间概念，或者 CV 没有顺序：视频、阅读图像和三维扫描都涉及顺序或方向关系。

## 8. 模型为什么越来越像，但领域并没有合并？

### 8.1 共享的基础工具

两者都使用向量表示、矩阵运算、梯度下降、反向传播、注意力、残差、归一化、预训练和微调。

因此看到 Transformer，不能立刻判断是 NLP；看到卷积，也不能断言只能用于图像。

### 8.2 同一个注意力公式可以服务不同数据

`Attention(Q,K,V)=softmax(QKᵀ/√d)V`。

在语言中，它可能聚合前文中与当前表达相关的 token；在视觉中，它可能聚合其他空间区域的特征。

公式类似，但 token 来源、位置编码、遮罩、序列长度和输出任务可能完全不同。

### 8.3 三种注意力不要混淆

| 机制 | 典型用途 | 注意点 |
|---|---|---|
| 双向自注意力 | BERT 式文本理解、视觉特征编码 | 一个位置可参考两侧或多个空间位置 |
| 因果自注意力 | 自回归语言生成等 | 当前 token 不能看到训练目标中的未来 token |
| 交叉注意力 | 翻译解码、视觉语言融合等 | Q 与 K/V 来自不同表示来源 |

NLP 不都是因果注意力；CV 也可以使用因果或自回归模型。EMCAD 的 PVTv2 注意力不是聊天模型那种“逐字只能看前文”的默认路径。

### 8.4 “解码器”这个词在两个领域可能指不同结构

EMCAD 解码器主要上采样、融合 skip、生成密集分割预测。语言模型中的 decoder block 通常指一类注意力与前馈结构；encoder–decoder 翻译系统的 decoder 还可能读取 encoder 输出。

不能因为都叫 decoder，就以为它们都是“把低分辨率特征放大”，也不能认为 decoder-only LLM 内含 U-Net 式解码器。

## 9. 训练目标有什么区别？

### 9.1 用两个例子直接对照

| 项目 | 自回归语言模型预训练 | EMCAD 的 Synapse 分割训练 |
|---|---|---|
| 输入 | 文本前缀／token 序列 | CT 切片 |
| 预测目标 | 各位置的下一个 token | 各像素的器官类别 |
| 类别集合 | tokenizer 的词表 | 背景与 8 个器官，共 9 类 |
| 典型输出 | `[B,L,V]`，V 为词表大小 | 每个预测头 `[B,9,H,W]` |
| 监督来源 | 原始文本自身构造目标 | 专业标注的器官掩膜 |
| 常见损失 | token 级交叉熵 | 当前代码的加权 CE＋Dice |

相同点是，都可以对“正确类别的概率”计算损失。区别在于类别含义、位置结构、监督来源与任务目标不同。

### 9.2 NLP 不只有自监督，CV 也不只有人工标注

NLP 的实体抽取、情感分类、偏好训练等可能需要人工标注；CV 可以使用对比学习、掩码图像建模等自监督方法，从未标注图像学习表示。

语言预训练容易从海量文本构造监督，是现代 LLM 扩展的重要优势。医学分割的精确标签通常更昂贵，但这不是 NLP/CV 全部任务的绝对分界。

### 9.3 生成与判别也不是 NLP/CV 的分界

NLP 有文本分类等判别任务，也有文本生成；CV 有分类、分割，也有图像生成。扩散模型、对抗训练或自回归目标的使用，取决于任务与方法。

## 10. 一个训练样本与一次推理有什么不同？

### 10.1 NLP 分类例子

输入“患者否认腹痛”，输出“腹痛不存在于当前陈述”。训练需要知道对应标签；推理可一次性给出类别，不必像聊天那样逐 token 生成长答案。

### 10.2 NLP 生成例子

输入“解释这段病历”，模型可能逐 token 生成答案。训练时可以在因果遮罩下并行计算多个位置的预测损失，而常见推理仍需要序列式生成。

### 10.3 EMCAD 分割例子

输入一张 CT，经一次前向产生整张切片的类别分数图，再按像素选择类别。它不需要先生成左上角像素，再逐个生成到右下角。

因此，不能用“Transformer 训练可并行”推断“所有生成都一次完成”，也不能用“输出是很多类别”推断“分割必须自回归”。

## 11. 标注与数据管理分别难在哪里？

| 问题 | NLP 示例 | CV／医学分割示例 |
|---|---|---|
| 标注歧义 | 同一句话的情绪、意图可能有争议 | 器官边界模糊，不同医生勾画不完全一致 |
| 长尾 | 罕见词、方言、少数语言、专业术语 | 小病灶、少见器官形态、异常病例 |
| 域偏移 | 社交文本与病历语言不同 | 不同医院、扫描仪、成像协议不同 |
| 数据泄漏 | 训练语料包含测试答案或重复文档 | 同一患者切片出现在训练和测试中 |
| 隐私 | 姓名、病史等文本信息 | DICOM 元数据、可识别图像与病历关联 |
| 数据增强 | 改写可能改变否定和事实 | 翻转、裁剪可能破坏方向含义或裁掉目标 |

对你的项目，患者级隔离比简单把切片随机分开重要。类似地，NLP 也可能需要按用户、文档来源、事件或时间划分，而不是随机打散每一句话。

## 12. 评价指标为什么不同？

### 12.1 CV 分割：位置和轮廓非常具体

Dice 衡量预测区域与真实区域的重叠：`Dice=2|P∩G|/(|P|+|G|)`。

假设真实器官有 100 个像素，预测有 110 个，其中 90 个重合，Dice 约为 85.7%。它直接回答“区域重叠如何”，但不能完整表达每一处边界错误。

HD95、表面 Dice 等补充边界方面的信息，医学应用还可能关注体积误差和临床相关量。

### 12.2 NLP 生成：正确答案可能有多种表达

“未见明显异常”与“没有发现明确异常表现”可能语义接近，但字面并不完全相同。因此只看逐字一致常常不够。

BLEU、ROUGE 测量某些形式的匹配；困惑度反映模型对文本的预测能力；事实一致性、指令遵循和推理正确性通常还需要任务专用评价或人工评估。

不能说 ROUGE 高就一定没有幻觉，也不能说困惑度低就一定更会解决临床问题。

### 12.3 不同任务的分数不能横向比较

EMCAD 的 Dice 83.63 与语言模型某个问答准确率 83.63，没有共同的能力单位。即使同为 F1，也要看统计对象、匹配规则和平均方式。

| 指标 | 常见任务 | 不能直接说明什么 |
|---|---|---|
| Accuracy／F1 | 文本分类、图像分类、实体抽取等 | 不保证复杂生成质量 |
| BLEU／ROUGE | 翻译、摘要等 | 不保证事实正确和完整推理 |
| Perplexity | 语言预测 | 不等于所有下游能力 |
| mAP | 目标检测等 | 不等于像素边界质量 |
| Dice／IoU | 分割 | 不等于临床安全与跨院泛化 |
| HD95 | 边界距离 | 仍需确认空间单位、空类别及实现方式 |

## 13. 两个领域分别特别难在哪里？

### 13.1 NLP 的困难

- 同一个意思有很多表达，同一句话在不同语境下有不同意思。
- 否定、指代、时间和条件关系需要跨句理解。
- 流畅生成可能掩盖事实错误。
- 长文档中的重要证据可能分散，而且相互矛盾。
- 语言、文化、专业领域之间差异明显。
- 自动评价很难完整覆盖开放式答案质量。

### 13.2 CV 的困难

- 同一物体在不同光照、角度、尺度下外观差别很大。
- 不同物体可能外观相似，尤其医学图像的低对比度组织。
- 遮挡、噪声、模糊和采样限制使信息本身不完整。
- 三维结构在二维投影或切片中可能存在歧义。
- 精确定位与边界标注成本高。
- 分辨率提高会增加显存和计算，低分辨率又可能损失细节。

没有统一依据说明 NLP 一定比 CV 难或相反。一个受控的文本分类任务，可能比复杂三维分割简单；高可靠长文档推理也可能比普通图像分类困难得多。

## 14. 多模态如何把 NLP 和 CV 连起来？

多模态不仅是“一个模型能收图片和文字”，还包括不同模态之间如何建立对应关系。

| 交叉任务 | 需要建立什么关系 |
|---|---|
| 图像描述 | 视觉内容与语言表达对应 |
| 视觉问答 | 问题中的对象、属性与图像证据对应 |
| 图文检索 | 文字与图像在共同表示空间中匹配 |
| 文生图 | 语言约束转换为视觉内容 |
| 指代表达分割 | “左边那个人”等表达对应具体目标区域 |
| 医学报告生成 | 影像证据与医学陈述对应 |
| 视觉语言引导的器官分割 | 器官语义、图像位置与掩膜对应 |

一个典型但非唯一的结构是：视觉编码器提取图像特征，连接模块将其适配到语言模型或融合网络，再由任务头输出文字、位置或掩膜。

这不意味着把 EMCAD 接到 LLM 后就一定更好。需要明确文字信息新增了什么有效信息、训练样本如何配对、错误如何评估，以及计算成本是否值得。

### OCR 为什么也是交叉例子？

文字检测与识别需要从图像恢复字符；后续理解文档结构、字段语义和跨段关系则涉及语言与版面信息。完整文档系统常同时包含视觉、语言和布局建模。

语音识别也不能简单说就是 NLP：它首先处理音频信号，同时涉及语言建模，与语音技术等领域交叉。

## 15. 把你的 EMCAD 放进这张学科地图

### 15.1 你的任务位置

```text
人工智能
  → 计算机视觉与医学影像计算
    → 医学图像分割
      → 腹部 CT 多器官语义分割
        → PVTv2 编码器 + EMCAD 解码器
```

这是便于理解的路径，不是所有学会或数据库采用的唯一分类体系。

### 15.2 当前代码实际做什么？

依据当前 `lib/networks.py`：

1. 单通道输入适配为三通道表示。
2. `self.backbone(x)` 输出四级特征。
3. `self.decoder(x4, [x3,x2,x1])` 逐级融合。
4. 四个预测头生成分类 logits。
5. 返回 `[p4,p3,p2,p1]`，测试路径使用最后一个输出。

224×224、PVTv2-B2 的四阶段 token 数为 3136、784、196、49。它们都是空间位置表示，不是自然语言词元；最后的 9 通道才对应 Synapse 的背景和 8 个器官类别。

### 15.3 从 NLP 借方法不等于改做 NLP

你可以借鉴注意力、预训练、蒸馏、参数高效适配等方法，只要最终研究问题仍然是图像分割，主要研究方向仍是 CV／医学影像。

是否使用跨注意力也不能单独证明是多模态：Q 与 K/V 来自两个视觉特征流，同样可以形成纯视觉交叉注意力。

### 15.4 哪些借鉴比较合理？

| 想借鉴的思想 | 对医学分割可提出的问题 | 不该直接假设 |
|---|---|---|
| 自监督预训练 | 未标注 CT 能否改善少标签学习？ | 文本预训练损失可以原样套在像素上 |
| 长上下文建模 | 能否利用更多切片或更大空间范围？ | 连续切片放入 batch 就会自动交流 |
| 参数高效适配 | 不同医院数据能否低成本适配？ | 可训练参数少就一定显存少、效果好 |
| 蒸馏 | 能否把强模型知识迁移给轻量模型？ | 教师更大就一定能教好 |
| 语言引导 | 器官描述是否提供新增有效约束？ | 多加入文字模态就必然涨 Dice |

## 16. 两个领域做论文，通常分别在证明什么？

### NLP 例子：医学文本信息抽取

研究问题可以是：跨医院病历格式变化后，模型能否仍准确提取带否定和时间条件的诊断信息？

需要证据包括：实体／关系指标、按否定类型分解、跨机构或时间测试、错误分析、标注一致性和成本。

### CV 例子：改进 EMCAD

研究问题可以是：在接近原有计算预算下，能否改善小器官边界与相邻切片一致性？

需要证据包括：Dice、边界指标、逐器官与逐病例表现、参数与延迟、消融、不同种子、外部数据，以及严格病例隔离。

两者共同的研究逻辑是：明确问题 → 解释已有方法缺陷 → 提出机制 → 做公平比较 → 分解改进来源 → 说明局限。

区别主要在问题、数据与证据，而不是某个领域只需要讲故事、另一个领域才需要实验。

## 17. 初学者应该分别补哪些知识？

### 两者共同的基础

线性代数、概率统计、微积分与优化、Python/PyTorch、数据划分、损失函数、过拟合、实验复现和误差分析。

### NLP 更需要熟悉

- 分词、词表、嵌入和上下文表示。
- 语言歧义、否定、指代和篇章结构。
- 预训练目标、因果遮罩和生成解码。
- 文本检索、事实一致性、生成评价。
- 多语言、长文本、领域适配。

### CV 更需要熟悉

- 图像采样、分辨率、通道与坐标。
- 卷积、感受野、下采样、上采样和多尺度特征。
- 分类、检测、分割的输出及损失差异。
- 几何与成像知识，按具体方向深入。
- 视觉增强、像素标注和空间指标。

对于你当前路线，应优先补齐医学影像与分割基础，再按具体研究需要借用 NLP 方法。没有必要为了“Transformer 两边都用”而先把整个 NLP 学完。

## 18. 常见误解对照

| 误解 | 更准确的说法 |
|---|---|
| NLP 就是 ChatGPT | NLP 还包括分类、抽取、翻译、句法、检索等 |
| CV 就是图像分类 | CV 还包括分割、几何、运动、重建与生成等 |
| 使用 Transformer 就属于 NLP | Transformer 是可用于多种模态的架构 |
| 使用 token 就是在处理语言 | 视觉也可形成 token，当前 PVTv2 就是例子 |
| NLP 只生成，CV 只识别 | 两者都有生成和判别任务 |
| 图像 token 等于原始像素 | 常对应投影后的局部／网格特征 |
| NLP 有上下文，CV 没有 | 视觉上下文包括邻域、全图、时间与三维结构 |
| CV 完全没有语义 | 器官类别、对象关系、动作和场景都有语义 |
| 多模态必然比单模态强 | 要看信息增益、数据质量、融合与成本 |
| 大模型已经让专业任务没必要研究 | 高可靠、低成本、领域数据和精确结构问题仍需专门研究 |
| NLP 和 CV 是完全独立的两门技术 | 工具高度共享，问题与数据结构仍有差异 |

## 19. 最后用三句话建立记忆

1. **NLP 关心语言表达了什么、如何使用和生成语言；CV 关心视觉数据里有什么、在哪里、如何变化，以及如何重建和生成它。**
2. **两者可以使用相似的神经网络工具，但输入结构、监督信号、输出目标与评价方法不相同。**
3. **EMCAD 是医学分割的视觉模型；PVTv2 中的 token 是视觉特征，不是文字。只有真正引入并建模语言等其他模态，才会进入相应的多模态交叉问题。**
