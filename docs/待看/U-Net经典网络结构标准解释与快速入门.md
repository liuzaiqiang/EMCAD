# U-Net 网络与模型结构：经典医学图像分割网络的标准解释

## 1. 用一句话认识 U-Net

U-Net 是一个面向像素级分割的全卷积编码器-解码器网络。它先通过编码器逐步下采样、提取越来越抽象的语义特征，再通过解码器逐步上采样、恢复空间分辨率，并用跳跃连接把编码器中的高分辨率细节直接传给对应的解码阶段。

最重要的思想可以概括为：

~~~text
编码器负责回答：图像中有什么？
解码器负责回答：它具体位于哪里？
跳跃连接负责：把边缘、纹理和定位细节补回来。
~~~

U-Net 之所以经典，是因为它同时解决了两个困难：

1. 深层网络经过多次下采样后，语义理解增强，但边界和位置信息变粗；
2. 医学图像分割需要输出每个像素的类别，而不是只给整张图一个类别。

---

## 2. U-Net 的整体外形：为什么叫 U-Net

标准 U-Net 的结构图呈现一个 U 形：

~~~text
输入图像
   |
   v
编码器左半边：逐级下采样，空间尺寸变小，通道数变多
   |
   v
U 的底部：最深层瓶颈特征
   |
   v
解码器右半边：逐级上采样，空间尺寸变大，通道数变少
   |
   v
输出分割图
~~~

完整主线：

~~~text
输入 -> 编码器 -> 瓶颈 -> 解码器 -> 1 x 1 分类头 -> 分割输出
          |                         ^
          +------ 跳跃连接 ----------+
~~~

“U”不是因为网络执行了某个字母操作，而是因为左侧压缩分辨率、底部最深、右侧恢复分辨率的拓扑形状看起来像 U。

## 3. 原始 U-Net 的标准组成

原始 U-Net 通常由以下部分组成：

~~~text
输入层
编码器（contracting path）
瓶颈层（bottom / bottleneck）
解码器（expanding path）
跳跃连接（skip connection）
最终 1 x 1 卷积分类头
~~~

### 3.1 输入层

输入可以是二维医学图像，例如：

~~~text
灰度 CT 切片：[B, 1, H, W]
RGB 图像：[B, 3, H, W]
~~~

其中 B 是 batch size，1 或 3 是输入通道数，H 和 W 是图像高度与宽度。

经典 U-Net 原论文使用二维图像作为例子，但 U-Net 思想也被扩展到 3D 医学图像，届时二维卷积和二维池化会变成三维版本。

### 3.2 卷积块

原始 U-Net 的基本卷积块通常是：

~~~text
3 x 3 卷积
ReLU
3 x 3 卷积
ReLU
~~~

现代实现常常在卷积和激活之间加入 BatchNorm，但原始 U-Net 的经典描述主要强调两次 3 x 3 卷积和 ReLU。

卷积块的作用是提取边缘、纹理、局部形状，并逐层把简单特征组合成更复杂的结构。

### 3.3 下采样

编码器通常用 2 x 2 最大池化、步幅为 2：

~~~text
空间尺寸减半：
H x W -> H/2 x W/2
~~~

下采样可以降低计算量、扩大有效感受野、获得更大范围上下文，并使特征从局部纹理逐渐转向器官或病灶的高级语义。

代价是空间细节会损失，所以需要跳跃连接补回来。

### 3.4 上采样

解码器必须逐步恢复分辨率。经典 U-Net 通常使用 2 x 2 转置卷积、步幅为 2。现代实现也常使用插值上采样加卷积。

上采样的目标不是直接生成最终分割，而是把低分辨率、强语义特征恢复到更高空间分辨率，以便和对应的编码器特征融合。

### 3.5 跳跃连接

跳跃连接把编码器某一层的高分辨率特征直接传给解码器中空间尺寸对应的阶段。

经典 U-Net 通常使用通道维拼接：

~~~text
decoder_feature = Concat(upsampled_decoder, encoder_feature)
~~~

拼接后通道数会增加，后面的卷积块再学习如何融合这些通道。

跳跃连接的核心价值：

~~~text
深层特征：语义强，但位置粗
浅层特征：位置精确，但语义弱
跳跃连接：把两者放到同一解码阶段融合
~~~

### 3.6 最终 1 x 1 卷积

最后使用 1 x 1 卷积把特征通道映射到目标类别数：

~~~text
[B, C_feature, H, W]
        |
        v
1 x 1 Conv
        |
        v
[B, num_classes, H, W]
~~~

1 x 1 卷积不会改变 H 和 W，只在每个像素位置上完成通道之间的线性组合。

多类别分割通常输出一个类别一个通道并使用 softmax；二分类常见输出一个前景通道并使用 sigmoid。

## 4. 用具体尺寸理解 U-Net

假设输入为单通道 224 x 224 图像，类别数为 9，batch size 为 B。为便于说明，假设编码器通道数依次为 64、128、256、512，瓶颈为 1024。

### 4.1 编码器路径

~~~text
输入                         [B,   1, 224, 224]
卷积块1                     [B,  64, 224, 224]
最大池化                    [B,  64, 112, 112]

卷积块2                     [B, 128, 112, 112]
最大池化                    [B, 128,  56,  56]

卷积块3                     [B, 256,  56,  56]
最大池化                    [B, 256,  28,  28]

卷积块4                     [B, 512,  28,  28]
最大池化                    [B, 512,  14,  14]

瓶颈卷积块                   [B,1024,  14,  14]
~~~

每次池化后，空间尺寸约减半，通道数通常增加。

### 4.2 解码器路径

~~~text
瓶颈特征                   [B,1024,14,14]
上采样                     [B, 512,28,28]
与编码器卷积块4拼接         [B,1024,28,28]
卷积块                     [B, 512,28,28]

上采样                     [B, 256,56,56]
与编码器卷积块3拼接         [B, 512,56,56]
卷积块                     [B, 256,56,56]

上采样                     [B, 128,112,112]
与编码器卷积块2拼接         [B, 256,112,112]
卷积块                     [B, 128,112,112]

上采样                     [B,  64,224,224]
与编码器卷积块1拼接         [B, 128,224,224]
卷积块                     [B,  64,224,224]

1 x 1 卷积                  [B,   9,224,224]
~~~

这里的通道数只是经典示例。不同实现可能使用其他宽度，但分辨率逐级变化、通道通常反向变化、对应层跳跃连接这三条主线不变。

## 5. 编码器和解码器分别学什么

编码器逐步压缩图像并提取语义。靠近输入的层更容易学到边缘、线条、局部纹理和亮暗变化；中间层开始组合局部轮廓、器官片段和形状；深层特征更适合表示器官、病灶及其上下文关系。

解码器把低分辨率、强语义特征变回像素级空间预测。它需要恢复分辨率、融合浅层细节，并在每个像素位置输出类别判断。

只使用瓶颈特征时，网络可能知道“这里有器官”，但边界不够精确。跳跃连接让解码器重新获得浅层边缘、纹理和定位信息。

---

## 6. 跳跃连接为什么是 U-Net 的核心

### 6.1 没有跳跃连接

如果只拿最深层特征从低分辨率恢复到原图大小，上采样只能放大已有的粗略信息。池化丢失的精确边缘不能完全凭空恢复，小器官和窄边界更容易模糊。

### 6.2 有跳跃连接

解码器在每个分辨率阶段都能拿到编码器保存的同分辨率特征，于是可以融合当前解码语义和对应的编码细节。

### 6.3 为什么经典 U-Net 使用 concat

拼接保留了两路特征的全部通道，后面的卷积块再学习如何组合。相比直接相加，concat 的表达容量更大，但通道数和计算量也会增加。

---

## 7. U-Net 的完整前向传播

假设输入为 x，标准 U-Net 可以写成：

~~~text
c1 = ConvBlock(x)
c2 = ConvBlock(Pool(c1))
c3 = ConvBlock(Pool(c2))
c4 = ConvBlock(Pool(c3))
b  = ConvBlock(Pool(c4))

d4 = ConvBlock(Concat(Up(b), c4))
d3 = ConvBlock(Concat(Up(d4), c3))
d2 = ConvBlock(Concat(Up(d3), c2))
d1 = ConvBlock(Concat(Up(d2), c1))

logits = Conv1x1(d1)
~~~

c1、c2、c3、c4 是编码器中保存给跳跃连接使用的特征，d4、d3、d2、d1 是解码器特征。

最终 logits 的形状是：

~~~text
[B, num_classes, H, W]
~~~

---

## 8. logits、概率图和最终分割图

### 8.1 logits

最后 1 x 1 卷积输出的是未归一化类别分数。对一个像素位置，它可能得到：

~~~text
z = [z0, z1, z2, ..., z(C-1)]
~~~

### 8.2 概率

多类别分割沿类别维做 softmax，同一个像素的类别概率总和为 1。二分类通常对单通道 logit 做 sigmoid。

### 8.3 离散分割图

多类别推理通常取最大概率类别，得到每个像素一个整数类别 ID 的标签图；二分类则使用阈值把概率图变成前景/背景掩膜。

训练时通常不要先 argmax 再计算损失，因为 argmax 是离散操作，不能提供稳定梯度。训练损失一般直接接收 logits，或使用 softmax 后的连续概率计算 soft Dice。

---

## 9. U-Net 如何训练

多类别分割常见输入输出是：

~~~text
logits：[B, C, H, W]
label：[B, H, W]
~~~

label 的每个像素是整数类别 ID。常见损失包括 Cross Entropy、Dice Loss，以及两者的加权组合。

二分类常见形式是一个前景 logit，使用 BCEWithLogitsLoss、Dice Loss 或二者组合。

标准训练步骤：

~~~text
1. DataLoader 读取 image 和 label
2. image 送入 U-Net
3. 得到 logits
4. 根据 logits 和 label 计算 loss
5. optimizer.zero_grad()
6. loss.backward()
7. optimizer.step()
~~~

---

## 10. U-Net 适合医学图像分割的原因

1. 跳跃连接保留高分辨率边界信息；
2. 输出保留空间维度，可以进行像素级预测；
3. 编码器和解码器分工清楚，结构易训练、易修改；
4. 可以在有限数据上配合增强进行端到端学习；
5. 能够替换编码器、卷积块、上采样、注意力和损失函数。

---

## 11. U-Net 的局限

1. 普通卷积主要建模局部关系，远距离上下文能力有限；
2. 直接传递浅层 skip 可能把背景纹理和噪声带入解码器；
3. 多次下采样可能损失小目标和细边界；
4. 高分辨率阶段的普通卷积计算量较大；
5. 固定结构不一定适合所有医学数据集。

---

## 12. 常见 U-Net 变体

### U-Net++

增加嵌套、密集的跳跃路径，减小编码器和解码器之间的语义差距。

### Attention U-Net

在 skip 处加入注意力门，根据高级语义抑制无关背景。

### ResUNet

把普通卷积块替换或增强为残差块，改善梯度传播和特征复用。

### UNet 3+

强调不同尺度之间的全尺度跳跃连接，提供更丰富的多尺度融合。

### nnU-Net

不是一个固定网络，而是自动配置医学分割预处理、patch、网络和训练策略的框架，是很强的医学分割基线。

### TransUNet、UNETR、Swin UNETR

保留 U-Net 式的编码器-解码器和跳跃连接，但把编码器或部分模块换成 Transformer。

## 13. U-Net 与当前 EMCAD 项目的关系

当前 EMCAD 不是原始 U-Net，但继承了 U-Net 的大框架：

~~~text
层次化编码器
逐级解码器
多尺度特征
skip connection
最终像素级分割输出
~~~

主要差异如下：

| 方面 | 原始 U-Net | 当前 EMCAD |
|---|---|---|
| 编码器 | 普通卷积编码器 | 默认 PVTv2-B2，也支持其他层次骨干 |
| 解码块 | 两次 3 x 3 卷积 | MSCAM、MSCB 等多尺度注意力卷积 |
| skip 融合 | 通常直接 concat | 先经 LGAG 门控，再与解码特征相加 |
| 上采样 | 常见转置卷积 | EUCB：上采样、深度卷积、1 x 1 投影 |
| 注意力 | 原始 U-Net 没有 | CAB、SAB、LGAG |
| 输出 | 通常一个最终输出 | 当前网络返回四个多阶段 logits |
| 训练监督 | 通常最终输出监督 | 支持 last-layer、deep supervision、mutation |

当前 EMCAD 的主线仍然可以按 U-Net 模板理解：

~~~text
PVTv2 编码器 -> [x1,x2,x3,x4]
                         |
                         v
EMCAD 解码器
                         |
                         v
[d4,d3,d2,d1]
                         |
                         v
四个 segmentation head
                         |
                         v
[p4,p3,p2,p1]
~~~

但 EMCAD 的 skip 融合不是原始 U-Net 的直接 concat，而是：

~~~text
d3 = EUCB(d4)
x3 = LGAG(d3, encoder_x3)
d3 = d3 + x3
d3 = CAB(d3)
d3 = SAB(d3)
d3 = MSCB(d3)
~~~

正确表述是：

> EMCAD 是具有 U-Net 式层次编码器-解码器和跳跃连接的增强型分割网络，但不是原始 U-Net。

## 14. 编码器特征、解码器特征和分割输出

例如 x1、x2、x3、x4、d1、d2、d3、d4，通常是内部特征：

~~~text
[B, C_feature, H, W]
~~~

经过 segmentation head 后，通道数才变成类别数：

~~~text
[B, num_classes, H, W]
~~~

当前 Synapse 项目中：

~~~text
9 个通道 = 背景 0 + 8 个器官类别
~~~

所以 P[0] 是第一个输出头，而 P[0] 的第 6 个通道才是类别 6 的 logit 图。列表下标和类别通道下标不能混淆。

## 15. 阅读 U-Net 代码的推荐顺序

1. 找总模型类，确认创建了哪些 encoder、decoder 和 head；
2. 找 forward，沿变量流向记录 x、特征和 logits；
3. 记录每层 B、C、H、W，检查 concat 或 add 时形状是否匹配；
4. 找输出头，确认输出通道数、输出数量以及是否已经 softmax/sigmoid；
5. 找 loss，确认标签是整数类别图还是 one-hot；
6. 找测试后处理，确认 argmax、threshold 和最终使用的输出头。

## 16. 一页速记

~~~text
U-Net = 编码器 + 瓶颈 + 解码器 + 跳跃连接

编码器：
    下采样，空间变小，语义变强

瓶颈：
    最深层特征，拥有较大感受野

解码器：
    上采样，空间变大，恢复像素位置

跳跃连接：
    把同分辨率的浅层特征传给解码器

经典融合：
    concat，而不是直接相加

最终输出：
    1 x 1 卷积 -> [B, num_classes, H, W]

多类别：
    softmax + argmax

二分类：
    sigmoid + threshold

核心价值：
    深层语义和浅层定位信息结合
~~~

## 17. 最终理解

U-Net 的核心不是“有很多卷积”，而是它把不同层级的信息组织成了一条有效的信息通路：

~~~text
浅层：告诉网络边界和位置
深层：告诉网络目标是什么
解码器：把语义恢复到像素空间
跳跃连接：防止细节在下采样中永久丢失
分类头：为每个像素产生类别分数
~~~

以后阅读 Attention U-Net、UNet++、TransUNet、UNETR 或 EMCAD 时，先问四个问题：

1. 编码器如何提取多尺度特征？
2. 解码器如何恢复空间分辨率？
3. skip connection 如何融合、筛选或重加权？
4. 最终如何把特征变成每像素类别输出？

只要这四个问题能回答，就已经掌握了 U-Net 及其大多数变体的主干逻辑。
