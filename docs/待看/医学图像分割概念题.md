# 基于深度学习的医学图像分割：100 个概念题、名词解释题及答案

> 内容按“基础概念 → 网络结构 → 损失与指标 → 训练方法 → 进阶技术 → 临床落地”排列。
> 面试时建议按照“定义 → 原理 → 优缺点 → 应用场景”回答。

------

## 一、医学图像分割基础

### 1. 什么是医学图像分割？

**答：** 医学图像分割是为图像中的每个像素或体素分配类别标签，例如从 CT 中分割肝脏、肿瘤或血管。它属于像素级预测任务，常用于病灶定量、手术规划、放疗靶区勾画和辅助诊断。

### 2. 语义分割、实例分割和全景分割有什么区别？

**答：**

- **语义分割**：判断每个像素属于哪个类别，但不区分同类目标的不同实例。
- **实例分割**：不仅判断类别，还区分不同实例，例如分开多个细胞核。
- **全景分割**：统一处理背景类和可数实例类。

器官和肿瘤分割通常属于语义分割，细胞核分割常需要实例分割。

### 3. 医学图像中的像素和体素分别是什么？

**答：** 像素是二维图像的最小单元；体素是三维图像的最小体积单元。CT、MRI 通常由多个切片组成，完整数据可表示为三维体素矩阵。

### 4. 什么是二分类分割和多分类分割？

**答：**

- **二分类分割**：每个位置只属于前景或背景，例如肿瘤与非肿瘤。
- **多分类分割**：每个位置属于多个互斥类别之一，例如背景、肝脏、肿瘤、血管。
- 如果同一位置可以具有多个标签，则应使用多标签分割，而不是普通多分类分割。

### 5. 图像分类、目标检测和图像分割有什么区别？

**答：**

- 分类输出整张图像的类别。
- 检测输出目标类别和边界框。
- 分割输出像素级掩膜。

分割提供最精细的空间信息，但标注和计算成本通常也最高。

### 6. 什么是分割掩膜（Mask）？

**答：** 分割掩膜是与原图空间对应的标签图。二分类掩膜通常使用 0 表示背景、1 表示前景；多分类掩膜使用不同整数表示不同解剖结构。训练时必须保证图像和掩膜经过完全一致的空间变换。

### 7. 医学图像分割为什么比自然图像分割困难？

**答：** 主要原因包括病灶尺寸小、边界模糊、类别极度不平衡、不同设备和医院间分布差异大、标注昂贵，以及不同医生之间存在标注差异。此外，漏检小病灶的临床代价可能远高于普通像素误差。

### 8. 什么是感兴趣区域（ROI）？

**答：** ROI，即 Region of Interest，是需要重点分析的局部区域。例如先定位腹部，再分割胰腺。裁剪 ROI 可以减少背景干扰、提高有效分辨率并降低显存消耗，但定位错误也可能造成目标被裁掉。

### 9. 什么是二维、2.5D 和三维分割？

**答：**

- **2D**：逐切片处理，计算量小，但缺少层间信息。
- **2.5D**：把相邻切片作为多个输入通道，兼顾部分层间信息和计算效率。
- **3D**：直接处理三维体积，能利用完整空间上下文，但显存消耗大。

### 10. 什么是端到端分割？

**答：** 端到端分割指模型从输入图像直接学习输出分割结果，中间特征由数据自动学习，不依赖人工设计特征。预处理和后处理仍可存在，因此“端到端”不等于“完全不需要工程流程”。

## 二、医学图像与数据处理

### 11. CT 图像中的 Hounsfield Unit 是什么？

**答：** Hounsfield Unit，简称 HU，是 CT 对组织放射密度的标准化表示。空气约为 -1000 HU，水约为 0 HU，致密骨通常高于 500 HU。训练 CT 模型时常根据目标器官设置 HU 窗口并进行截断归一化。

### 12. MRI 与 CT 在分割任务中有哪些差异？

**答：** CT 灰度具有相对稳定的物理含义，而 MRI 强度没有统一绝对标准，并受扫描序列和设备影响明显。MRI 往往需要偏置场校正、强度标准化和多模态配准。

### 13. 什么是窗宽和窗位？

**答：**

- **窗位**决定显示灰度范围的中心。
- **窗宽**决定显示范围的宽度。

不同窗口可以突出不同组织，例如肺窗、骨窗、软组织窗。深度学习中可将多个窗口生成多个输入通道。

### 14. 什么是医学图像配准？

**答：** 配准是将不同时间、模态或个体的图像映射到同一空间坐标系。常见类型包括刚性配准、仿射配准和非刚性配准。多模态 MRI 或术前术后对比通常需要配准。

### 15. 什么是重采样（Resampling）？

**答：** 重采样是把图像调整到统一的空间间距或尺寸。医学图像中应关注物理间距 `spacing`，而不只是矩阵大小。图像通常使用线性或三次插值，离散标签应使用最近邻插值，避免产生不存在的类别值。

### 16. 什么是各向异性体素？

**答：** 当不同方向的体素间距差异明显时，称为各向异性。例如层内分辨率为 `0.8 × 0.8 mm`，层间距为 `5 mm`。此时直接使用各向同性的 3D 卷积可能不合理，可采用 2D、2.5D 或各向异性卷积。

### 17. 常用的医学图像强度归一化方法有哪些？

**答：**

- Min-Max 归一化
- Z-score 标准化
- 百分位截断后归一化
- CT 的 HU 窗口截断
- MRI 的前景区域 Z-score 标准化

归一化参数应主要由训练集确定，避免测试信息泄漏。

### 18. 医学分割常用哪些数据增强？

**答：** 常见方法包括翻转、旋转、缩放、随机裁剪、弹性形变、噪声、模糊、伽马变换和对比度调整。增强必须符合解剖和成像规律，例如某些器官不能随意左右翻转，掩膜也不能使用连续灰度插值。

### 19. 什么是 Patch-based Training？

**答：** Patch-based Training 是从大图像或三维体积中裁剪小块训练。它能降低显存需求，并提高小目标被采样的概率。缺点是可能丢失全局上下文，因此常结合前景采样、多尺度网络或滑窗推理。

### 20. 什么是数据泄漏？

**答：** 数据泄漏是训练过程使用了测试集信息。例如同一患者的不同切片被分到训练集和测试集，会使结果虚高。医学数据必须优先按患者划分；多中心研究还可按医院或时间进行外部测试。

## 三、CNN 与经典分割网络

### 21. 什么是卷积？

**答：** 卷积使用可学习的局部核在图像上滑动，提取边缘、纹理和高级语义特征。卷积具有局部连接和参数共享特性，因此比全连接层更适合图像任务。

### 22. 什么是感受野？

**答：** 感受野是某个特征位置在原始输入中能够感知的区域。增加网络深度、卷积核尺寸、步长、池化或空洞率都能扩大感受野。医学分割既需要大感受野理解器官位置，也需要局部细节恢复边界。

### 23. Padding、Stride 和 Kernel Size 分别有什么作用？

**答：**

- `Kernel Size` 决定局部计算范围。
- `Stride` 决定卷积核移动步长，也影响下采样倍数。
- `Padding` 在边界补值，用于控制输出尺寸并保留边缘信息。

### 24. 什么是池化层？

**答：** 池化通过局部聚合降低特征图尺寸。最大池化保留局部强响应，平均池化保留平均信息。池化能扩大感受野并降低计算量，但也可能丢失小病灶和边界细节。

### 25. 什么是上采样？

**答：** 上采样将低分辨率特征恢复到高分辨率。常见方法包括双线性插值、最近邻插值、转置卷积和像素重排。转置卷积可学习，但可能产生棋盘格伪影。

### 26. 什么是编码器和解码器？

**答：** 编码器逐步降低空间分辨率并提取高级语义；解码器逐步恢复空间分辨率并输出分割图。编码器回答“是什么”，解码器回答“在哪里”。

### 27. U-Net 的核心结构是什么？

**答：** U-Net 是对称的编码器-解码器网络，通过跳跃连接把编码器的高分辨率特征传递给解码器。它兼顾语义信息和定位信息，是医学图像分割中最经典的基线模型。

### 28. U-Net 的跳跃连接有什么作用？

**答：** 跳跃连接补充分辨率较高的边界和纹理信息，缓解下采样造成的空间信息损失。但浅层特征与深层特征存在语义差距，因此后续模型常增加注意力、卷积融合或嵌套连接。

### 29. U-Net 与 FCN 有什么关系？

**答：** FCN 将分类网络中的全连接层替换为卷积层，实现任意尺寸的像素级预测。U-Net 继承了全卷积思想，并通过对称解码器和跳跃连接加强了精确定位能力。

### 30. 什么是残差连接？

**答：** 残差连接将输入与变换结果相加：

\[ y = F(x) + x \]

它改善梯度传播，使深层网络更容易训练。医学分割中的 ResUNet 就是在 U-Net 中引入残差块。

### 31. 什么是 Dense Connection？

**答：** Dense Connection 将每一层的输出传给后续所有层，实现特征复用和更充分的梯度传播。缺点是显存占用较高，并可能造成通道数快速增长。

### 32. 什么是空洞卷积？

**答：** 空洞卷积通过在卷积核元素之间插入间隔扩大感受野，而不显著增加参数量或降低分辨率。过大的空洞率可能产生网格效应并遗漏连续局部信息。

### 33. DeepLab 系列的主要思想是什么？

**答：** DeepLab 使用空洞卷积保持较高特征分辨率，并通过 ASPP 获取多尺度上下文。部分版本还使用编码器-解码器结构细化边界。

### 34. 什么是 ASPP？

**答：** ASPP，即 Atrous Spatial Pyramid Pooling，使用多个不同空洞率的并行卷积分支提取不同尺度的信息。它适合目标尺寸变化明显的场景，但会增加计算和显存开销。

### 35. 什么是 Attention U-Net？

**答：** Attention U-Net 在跳跃连接处加入注意力门，根据高级语义抑制无关背景、突出目标区域。它对小器官和复杂背景可能有效，但注意力模块并不保证一定优于标准 U-Net。

## 四、损失函数与评价指标

### 36. 什么是交叉熵损失？

**答：** 交叉熵衡量预测概率分布与真实标签之间的差异。二分类通常使用 Binary Cross-Entropy，多分类通常使用 Softmax Cross-Entropy。它按像素优化稳定，但容易被大量背景像素主导。

### 37. 什么是 Dice 系数？

**答：** Dice 衡量两个区域的重叠程度：

\[ Dice = \frac{2|P \cap G|}{|P|+|G|} \]

其中 \(P\) 是预测区域，\(G\) 是真实区域。Dice 取值通常在 0 到 1 之间，越大越好。

### 38. 什么是 Dice Loss？

**答：** Dice Loss 通常定义为：

\[ L_{Dice}=1-\frac{2\sum_i p_i g_i+\epsilon} {\sum_i p_i+\sum_i g_i+\epsilon} \]

它直接优化区域重叠，对类别不平衡较友好，但训练初期可能不如交叉熵稳定。

### 39. 为什么经常联合使用 Dice Loss 和 Cross-Entropy Loss？

**答：** Cross-Entropy 提供稳定的逐像素监督，Dice Loss 强调全局区域重叠和类别平衡。两者结合通常比单独使用其中一个更稳健：

\[ L = \lambda L_{CE} + (1-\lambda)L_{Dice} \]

### 40. IoU 和 Dice 有什么关系？

**答：** IoU 又称 Jaccard Index：

\(IoU=\frac{|P\cap G|}{|P\cup G|}\)

它与 Dice 的关系为：

\[ Dice=\frac{2IoU}{1+IoU} \]

相同预测下 Dice 数值通常高于 IoU，但两者排序一致。

### 41. Precision 和 Recall 在分割中如何解释？

**答：**

\[ Precision=\frac{TP}{TP+FP} \]

表示预测为目标的像素中有多少是真的。

\[ Recall=\frac{TP}{TP+FN} \]

表示真实目标中有多少被检出。病灶筛查通常更重视 Recall，但过低的 Precision 会带来大量误报。

### 42. 什么是 Sensitivity 和 Specificity？

**答：** Sensitivity 等价于 Recall，衡量阳性目标的检出能力；Specificity 衡量背景被正确识别的比例：

\[ Specificity=\frac{TN}{TN+FP} \]

背景极多时 Specificity 很容易接近 1，因此不能单独代表分割质量。

### 43. 什么是 Focal Loss？

**答：** Focal Loss 在交叉熵基础上降低易分类样本的权重：

\[ L=-\alpha(1-p_t)^\gamma \log(p_t) \]

它使模型更关注困难样本和少数类，适合类别不平衡或小病灶任务。

### 44. 什么是 Tversky Loss？

**答：** Tversky Index 分别控制假阳性和假阴性的惩罚：

\[ TI=\frac{TP}{TP+\alpha FP+\beta FN} \]

当漏检代价更高时，可以增大 \(\beta\)。Dice 是 \(\alpha=\beta=0.5\) 时的特殊形式。

### 45. 什么是 Boundary Loss？

**答：** Boundary Loss 利用预测边界和真实边界之间的距离进行优化，适合边界模糊、目标细长或类别极不平衡的任务。它通常作为区域损失的补充，而不是单独使用。

### 46. 什么是 Hausdorff Distance？

**答：** Hausdorff Distance 衡量两个集合边界之间最严重的偏离。它对极端离群点非常敏感，因此医学分割中常使用第 95 百分位距离 HD95。

### 47. 什么是 Average Surface Distance？

**答：** Average Surface Distance 衡量预测表面与真实表面之间的平均距离。相比 Dice，它能够更直接反映边界误差；相比最大 Hausdorff Distance，它对单个离群点不那么敏感。

### 48. 为什么 Accuracy 不适合评价小病灶分割？

**答：** 当背景占 99.9% 时，即使模型把所有像素都预测为背景，Accuracy 仍可能达到 99.9%。因此应使用 Dice、IoU、Recall、HD95、病灶级检出率等指标。

### 49. 宏平均和微平均有什么区别？

**答：**

- **宏平均**：先计算每个类别或病例的指标，再求平均，各类别或病例权重相同。
- **微平均**：先汇总所有 TP、FP、FN，再计算指标，大目标或常见类别贡献更大。

医学论文应明确报告采用哪种平均方式。

### 50. 当真实标签中不存在某个类别时，Dice 应如何处理？

**答：** 如果预测也为空，可将该病例视为正确、记为 1，或者从该类别的平均中排除；如果预测非空，则通常记为 0。不同实现差异很大，必须在实验中明确约定，否则结果不可直接比较。

## 五、训练与优化

### 51. 什么是反向传播？

**答：** 反向传播利用链式法则计算损失对各参数的梯度，优化器再根据梯度更新参数。自动微分框架通常完成具体计算，但仍需理解梯度消失、梯度爆炸和计算图。

### 52. SGD 和 Adam 有什么区别？

**答：** SGD 更新简单、泛化能力通常较好，但对学习率敏感；Adam 为不同参数维护自适应学习率，收敛快、调参方便。医学分割常用 AdamW，也可使用带动量的 SGD 获得更好的最终泛化。

### 53. 什么是学习率调度器？

**答：** 学习率调度器在训练过程中动态调整学习率。常见策略包括 Step Decay、Cosine Annealing、Polynomial Decay、OneCycle 和 ReduceLROnPlateau。学习率过大会震荡，过小会收敛缓慢或陷入次优解。

### 54. 什么是 Warm-up？

**答：** Warm-up 在训练初期从较小学习率逐步升到目标学习率，防止随机初始化或大批量训练导致参数更新不稳定。Transformer 类模型尤其常用。

### 55. Batch Normalization 有什么作用？

**答：** Batch Normalization 对小批量特征进行标准化，可加速训练并提供一定正则化效果。但 3D 医学分割的 batch size 常很小，使统计量不稳定，因此常改用 Instance Normalization 或 Group Normalization。

### 56. Instance Normalization 和 Group Normalization 有什么特点？

**答：**

- **Instance Normalization**：对每个样本、每个通道单独归一化，常用于医学图像。
- **Group Normalization**：将通道分组后归一化，不依赖 batch size。

Group Normalization 通常在小 batch 场景下更稳定。

### 57. 什么是过拟合？

**答：** 过拟合是模型在训练集表现很好，但验证集和测试集表现较差。可通过数据增强、权重衰减、Dropout、早停、降低模型复杂度、交叉验证和增加数据多样性缓解。

### 58. 什么是早停？

**答：** 早停是在验证指标长期不再改善时终止训练，以减少过拟合和计算浪费。保存模型时应依据验证集指标，不能依据测试集指标。

### 59. 什么是类别不平衡？如何处理？

**答：** 类别不平衡指目标像素远少于背景像素，或不同器官尺寸差异巨大。可采用前景 Patch 采样、Dice/Focal/Tversky Loss、类别权重、两阶段定位分割以及困难样本挖掘。

### 60. 什么是梯度累积和混合精度训练？

**答：** 梯度累积通过多次前向和反向传播后再更新参数，模拟更大的 batch size。混合精度使用 FP16 或 BF16 加速计算并减少显存占用；FP16 通常需要损失缩放以避免梯度下溢。

## 六、Transformer、注意力与现代网络

### 61. 什么是自注意力机制？

**答：** 自注意力通过 Query、Key、Value 建模不同位置之间的关系：

\[ Attention(Q,K,V)=Softmax\left(\frac{QK^T}{\sqrt{d}}\right)V \]

它擅长捕获长距离依赖，但标准注意力的计算和显存复杂度通常随 token 数量平方增长。

### 62. CNN 和 Transformer 在分割中各有什么优势？

**答：** CNN 具有局部性和平移等变等先验，小数据下更容易训练；Transformer 擅长建模全局依赖，但通常更依赖数据量、预训练和正则化。实际系统常采用 CNN-Transformer 混合结构。

### 63. 什么是 Vision Transformer？

**答：** Vision Transformer 将图像划分为 Patch，把每个 Patch 映射成 token，再用 Transformer 编码。直接应用于医学分割时，还需要解码器恢复像素级空间分辨率。

### 64. TransUNet 的主要思想是什么？

**答：** TransUNet 使用 CNN 提取局部特征，再用 Transformer 建模全局关系，最后通过 U-Net 式解码器恢复分割结果。它融合了 CNN 的局部先验和 Transformer 的全局建模能力。

### 65. Swin Transformer 有什么特点？

**答：** Swin Transformer 使用局部窗口注意力降低计算量，并通过移位窗口建立跨窗口连接。它具有层级特征结构，因此比原始 ViT 更适合检测和分割。

### 66. 什么是 UNETR？

**答：** UNETR 是面向三维医学分割的 Transformer-U-Net 架构。它使用 Transformer 编码三维 Patch，并将不同层的特征通过跳跃连接送入 CNN 解码器。

### 67. 什么是 Swin UNETR？

**答：** Swin UNETR 使用 3D Swin Transformer 作为编码器，以窗口注意力构建多尺度三维特征，再用卷积解码器恢复分辨率。它适合三维多器官分割，但显存和预训练成本较高。

### 68. 什么是通道注意力和空间注意力？

**答：**

- **通道注意力**学习“哪些特征通道更重要”。
- **空间注意力**学习“哪些空间位置更重要”。

SE、CBAM 等模块属于典型实现，但增加注意力模块后仍需消融实验验证收益。

### 69. 什么是多尺度特征融合？

**答：** 多尺度特征融合将不同分辨率层的特征组合起来。浅层特征包含边缘细节，深层特征包含高级语义。FPN、U-Net 跳跃连接和 ASPP 都体现了多尺度思想。

### 70. 什么是深监督？

**答：** 深监督在解码器的多个尺度上添加辅助输出和损失，使中间层也直接获得监督信号。它可改善梯度传播和多尺度学习；推理时通常只保留最高分辨率输出或融合多个输出。

## 七、三维、多模态与复杂目标

### 71. 2D 卷积和 3D 卷积有什么区别？

**答：** 2D 卷积只在平面内滑动，3D 卷积同时在深度、高度和宽度方向滑动。3D 卷积能利用体积上下文，但参数量、计算量和显存消耗更大。

### 72. 什么是滑窗推理？

**答：** 滑窗推理将完整图像分成多个重叠 Patch 分别预测，再拼接结果。重叠区域通常通过高斯权重或平均概率融合，以减少 Patch 边缘产生的接缝伪影。

### 73. 为什么三维分割经常使用重叠 Patch？

**答：** 非重叠 Patch 的边缘缺少上下文，预测往往不稳定。重叠能够让同一体素在不同上下文中被多次预测，再通过加权融合提高连续性。

### 74. 什么是多模态医学图像分割？

**答：** 多模态分割联合使用不同成像序列，例如脑肿瘤分割中的 T1、T1ce、T2 和 FLAIR。最简单的方法是按通道拼接，也可在特征层进行融合。

### 75. 如何处理缺失模态？

**答：** 可使用模态 Dropout、知识蒸馏、生成模型补全、模态无关特征学习或缺失感知融合。直接用全零替换虽然简单，但模型必须在训练阶段见过类似缺失模式。

### 76. 什么是级联分割？

**答：** 级联分割通常先用粗模型定位器官或 ROI，再用精细模型完成局部分割。它适合小器官和高分辨率任务，但第一阶段漏检会传播到第二阶段。

### 77. 什么是粗到细分割？

**答：** 粗到细分割先预测低分辨率全局结构，再在局部高分辨率区域细化。它本质上是在全局上下文、细节精度和计算成本之间进行折中。

### 78. 如何分割细小血管或神经？

**答：** 可使用高分辨率输入、前景采样、多尺度特征、拓扑或中心线损失，并减少过度下采样。仅优化 Dice 可能仍会得到断裂结构，因此还应评价连通性、中心线重叠或拓扑错误。

### 79. 什么是拓扑保持分割？

**答：** 拓扑保持分割不仅要求像素重叠，还要求连通性、孔洞数量和分支结构合理。血管、气道和神经分割尤其重视拓扑，可使用 clDice、持久同调损失或图结构约束。

### 80. 什么是后处理？

**答：** 后处理是在模型输出后根据任务先验修正结果。常见操作包括保留最大连通域、去除小区域、填洞、形态学开闭运算和条件随机场。后处理规则必须在验证集上确定，不能针对测试病例手工调整。

## 八、数据稀缺与泛化方法

### 81. 什么是迁移学习？

**答：** 迁移学习使用其他数据集或任务上训练的权重初始化模型，再在目标医学数据上微调。它能改善小数据训练，但自然图像与三维医学图像之间存在明显领域差异。

### 82. 什么是自监督学习？

**答：** 自监督学习利用无标注数据构造预训练任务，例如遮挡重建、对比学习、旋转预测或图像恢复，再在少量标注数据上微调。它能降低对人工标注的依赖。

### 83. 什么是半监督分割？

**答：** 半监督分割同时使用少量有标签数据和大量无标签数据。常用方法包括伪标签、一致性正则化、教师-学生模型和熵最小化。

### 84. 什么是 Mean Teacher？

**答：** Mean Teacher 包含学生模型和教师模型。学生通过梯度更新，教师参数则是学生参数的指数移动平均；模型通过监督损失和教师-学生一致性损失共同训练。

### 85. 什么是伪标签？

**答：** 伪标签是模型对无标签数据生成的预测标签，再将高置信度预测用于训练。主要风险是错误标签不断被强化，因此常配合置信度阈值、教师模型或不确定性过滤。

### 86. 什么是弱监督分割？

**答：** 弱监督分割使用图像级标签、点、涂鸦、边界框或粗糙掩膜训练模型。它能降低标注成本，但需要解决弱标签到像素级标签之间的信息缺失问题。

### 87. 什么是主动学习？

**答：** 主动学习由模型选择最值得标注的样本，再交给专家标注。选择标准可以是不确定性、代表性、多样性或预期性能提升，目标是在有限标注预算下获得更高性能。

### 88. 什么是领域适应？

**答：** 领域适应用于缓解训练域和目标域之间的分布差异，例如不同医院、扫描仪或协议。方法包括特征对齐、图像风格转换、自训练和测试时适应。

### 89. 什么是领域泛化？

**答：** 领域泛化要求模型在训练时看不到目标域的情况下，仍能泛化到新医院或新设备。常用方法包括强数据增强、风格随机化、多源训练和学习领域不变特征。

### 90. 什么是联邦学习？

**答：** 联邦学习允许多家医院在不直接共享原始数据的情况下联合训练模型，通常只交换参数或梯度。但参数仍可能泄露隐私，因此还需安全聚合、差分隐私等机制，并处理不同医院数据非独立同分布的问题。

## 九、基础模型、不确定性与可解释性

### 91. 什么是医学图像分割基础模型？

**答：** 基础模型是在大规模、多任务或多模态数据上预训练，可通过提示或少量微调适配多个分割任务的模型。它强调通用性，但在特定临床数据上仍需验证和适配。

### 92. SAM、MedSAM 与传统 U-Net 有什么区别？

**答：** SAM 使用点、框或已有掩膜作为提示，面向开放场景进行交互式分割；MedSAM 等方法针对医学图像进行适配。传统 U-Net 通常直接学习固定类别，而提示式模型更灵活，但零样本医学性能并不一定可靠。

### 93. 什么是提示式分割？

**答：** 提示式分割根据点、框、文本或粗掩膜生成目标分割结果。它适合交互标注和人机协同，但性能高度依赖提示质量，并且需要明确提示生成方式才能公平比较。

### 94. 什么是模型不确定性？

**答：** 不确定性反映模型对预测的信心。常区分数据固有噪声导致的偶然不确定性，以及模型知识不足导致的认知不确定性。临床系统可利用不确定性筛选需要人工复核的病例。

### 95. 如何估计分割模型的不确定性？

**答：** 常见方法包括预测熵、Monte Carlo Dropout、深度集成、测试时增强和贝叶斯神经网络。Softmax 概率高不等于模型真正可靠，因此最好同时检查校准表现。

### 96. 什么是模型校准？

**答：** 校准描述预测置信度是否与真实正确率一致。例如置信度为 0.8 的预测应约有 80% 正确。常用指标包括 ECE，常用校准方法包括 Temperature Scaling。

### 97. 什么是可解释性分割？

**答：** 可解释性方法用于分析模型依据了哪些区域或特征。常见方法包括 Grad-CAM、注意力图、遮挡实验和特征可视化。但热力图只能作为证据之一，不能直接证明模型学到了临床因果关系。

## 十、工程实践与面试综合题

### 98. 什么是 nnU-Net？为什么它很重要？

**答：** nnU-Net 是一个自动配置医学分割流程的框架，可根据数据自动确定预处理、重采样、Patch 大小、网络配置、训练策略和后处理。它说明稳定的数据处理和训练方案往往比盲目设计新模块更重要，也是医学分割实验中非常强的基线。

### 99. 如何设计一套可信的医学分割实验？

**答：** 应按患者划分训练、验证和测试集，固定随机种子，并记录数据版本、预处理、超参数和模型选择标准。至少报告 Dice 与边界指标，分析失败病例，进行消融实验；条件允许时还应进行多中心外部验证，并给出置信区间。

### 100. 面试题：拿到一个新的医学分割任务，你会如何完整解决？

**答：** 可以按以下流程回答：

1. 明确目标结构、临床用途、输入模态和评价标准。
2. 检查图像方向、spacing、强度范围、标签值和标注一致性。
3. 按患者划分数据，避免同患者信息泄漏。
4. 进行重采样、强度归一化、ROI 裁剪和合理增强。
5. 先建立 U-Net 或 nnU-Net 基线。
6. 根据目标尺寸和显存选择 2D、2.5D 或 3D 方法。
7. 使用 Dice 与 Cross-Entropy 等组合损失处理类别不平衡。
8. 使用 Dice、Recall、HD95、表面距离和病灶级指标综合评价。
9. 分析漏检、误检、边界错误和跨中心性能下降。
10. 再针对问题引入级联、多尺度、Transformer、半监督或领域适应。
11. 进行消融实验、外部测试、不确定性评估和推理效率测试。
12. 部署时保留人工复核机制，持续监控数据漂移和临床风险。

核心原则是：**先保证数据和评价可靠，再建立强基线，最后根据可证实的问题增加模型复杂度。**
