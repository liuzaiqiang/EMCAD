
# try5 之后可继续验证的 20 种正交创新点：基于 EMCAD 当前代码与国内论文路线的分析

日期：2026-09-27  
适用分支：try5  
当前任务：在已经验证有效的“像素级可靠性多头融合”之后，寻找一个来自不同作用节点、能够继续提升 Dice、并且可以按国内论文流程独立消融的新模块。

> 本文只做代码审计、研究假设和实验设计，不修改当前 try5 分支的任何代码。下面的 20 个方向都是待验证候选，不能把候选机制直接写成已经提升 Dice 的事实。正式论文中只能使用固定划分、多随机种子、独立验证选模型和患者级指标支持的结论。

---

## 1. 先给结论

### 1.1 新模块确实应该换一个角度

当前 try5 已经解决了一个明确问题：

> 四个解码阶段都能给出预测，但不同阶段在不同像素位置的可信程度不同，因此在输出端学习像素级的头权重。

这个问题的作用节点是：

- 四个分割头已经生成全分辨率 logits 之后；
- 每个头额外生成一张单通道可靠性图；
- 在 EMCADNet.fuse_outputs() 中沿“四个头”这一维做 softmax；
- 用可靠性权重把 p4、p3、p2、p1 融合成最终 logits；
- 用 detached 的像素级 argmax 正确性训练可靠性头。

如果下一模块仍然做以下事情，论文上会与 try5 高度重叠：

- 再增加一张置信度图、确定性图、不确定性图；
- 再为 p4、p3、p2、p1 学习全局或像素级权重；
- 再设计一个 entropy、variance、confidence map 来决定四头输出谁占比更大；
- 再把四个 logits 进行另一种加权、投票或门控；
- 只在 fuse_outputs() 附近增加一个更复杂的融合器。

这些方向最多属于 try5 的融合变体，难以被清楚写成第二个独立创新点。

### 1.2 更合适的第二个角度

后续模块应尽量落在下面四类节点之一：

1. 解码特征形成过程：MSDC/MSCB 的尺度建模、EUCB 上采样、LGAG 后的跳连融合、解码器的跨层反馈；
2. 医学结构约束：边界、表面距离、轮廓连续性、拓扑和器官关系；
3. 训练监督过程：类别不平衡、困难样本、跨尺度特征一致性、标签边界软化；
4. 数据与上下文：相邻切片、层间间距、CT 多窗口输入、病例级序列连续性。

其中最适合当前 EMCAD 的第一优先方向是：

- 特征侧的互补跳连融合；
- 解码器上采样的边界保持；
- 独立的表面/边界监督；
- spacing-aware 的 2.5D 层间上下文。

它们与 try5 的输出端可靠性融合拥有不同的机制解释，也容易建立“问题—模块—消融—指标”的论文链路。

### 1.3 20 个方向不是 20 个模块一起堆

国内论文通常需要一个清晰的主方法。建议采用以下顺序：

1. 从 20 个方向中选一个作为主模块；
2. 先做原始 EMCAD 与主模块的单变量对比；
3. 主模块稳定后，再做 try5 与主模块的组合实验；
4. 最终论文最多保留一个核心结构创新和一个辅助训练约束；
5. 其余方向作为失败候选、备选路线或后续工作记录。

## 2. 当前 try5 的实际代码路径

### 2.1 从输入到四个输出头

以 Synapse、PVTv2-B2、输入大小 224×224 为例，当前主路径可以写成：

| 阶段 | 张量 | 典型形状 | 作用 |
|---|---|---:|---|
| 输入 | CT slice | [B,1,224,224] | 单通道 CT 切片 |
| 输入适配 | 1×1 Conv + BN + ReLU | [B,3,224,224] | 适配 ImageNet 三通道骨干 |
| 编码器浅层 | x1 | [B,64,56,56] | 纹理、边缘、定位 |
| 编码器中层 | x2 | [B,128,28,28] | 局部结构与中等语义 |
| 编码器深层 | x3 | [B,320,14,14] | 高层语义 |
| 编码器最深层 | x4 | [B,512,7,7] | 大感受野、全局语义 |
| 解码器最深层 | d4 | [B,512,7,7] | MSCB 处理后的深层表示 |
| 第一次上采样 | d3 | [B,320,14,14] | EUCB 上采样后与 x3 对齐 |
| 第二次上采样 | d2 | [B,128,28,28] | 与 x2 对齐 |
| 第三次上采样 | d1 | [B,64,56,56] | 与 x1 对齐，内部最高分辨率 |
| 预测头 | p4、p3、p2、p1 | 每个最终为 [B,9,224,224] | 四个阶段的 9 类 logits |

当前实现中，四个解码器特征由 lib/decoders.py 的 EMCAD.forward() 返回为 [d4,d3,d2,d1]。lib/networks.py 中的四个 1×1 输出头分别把通道数映射为类别数，然后使用 32、16、8、4 倍插值恢复到输入分辨率。

这意味着 p4、p3、p2、p1 不是四个类别，也不是四个器官。它们是同一组 9 类器官分割任务在四个解码阶段产生的四组预测。

### 2.2 当前 EMCAD 解码器的关键节点

当前解码器的真实顺序是：

1. d4 经过 MSCB；
2. d4 经过 EUCB3 上采样得到 d3；
3. LGAG3 使用 d3 门控 x3；
4. 代码执行 d3 与门控后的 x3 逐元素相加；
5. d3 依次经过 CAB、共享 SAB 和 MSCB；
6. 对 d3 重复 EUCB2、LGAG2、跳连相加、CAB、SAB、MSCB；
7. 对 d2 重复 EUCB1、LGAG1、跳连相加、CAB、SAB、MSCB；
8. 返回 [d4,d3,d2,d1]。

当前实际跳连融合位置在 lib/decoders.py 的 d3、d2、d1 处，基本形式是：

- d3 = d3 + x3；
- d2 = d2 + x2；
- d1 = d1 + x1。

LGAG 返回的是被空间门控后的 skip 特征。它负责筛选位置，但没有显式判断 skip 中哪些通道与 decoder 主路重复，也没有显式保留与主路互补的成分。

### 2.3 try5 新增机制所在的位置

try5 在 lib/networks.py 中增加了四类融合模式：

- p1：直接使用最高分辨率的 p1；
- fixed_sum：四个 logits 直接相加；
- global_scalar：学习四个全局标量；
- pixel_reliability：每个头预测一个单通道可靠性 logit，在头维做 softmax。

像素可靠性模式的抽象公式是：

- 每个输出头产生类别 logits：p_i；
- 每个输出头再产生可靠性 logit：r_i；
- 头权重：w_i(x) = softmax_i(r_i(x))；
- 最终预测：z(x) = Σ_i w_i(x) p_i(x)。

当前可靠性监督使用每个头 detached 后的 argmax 正确性。也就是说，可靠性头学习的是“这个头在当前像素上是否预测正确”，而不是重新生成一组解码特征。

因此，try5 的主贡献可以准确概括为：

> 在四个全分辨率多阶段分割 logits 之间建立像素级可靠性选择机制。

### 2.4 当前训练和推理的关系

训练端仍然保留 EMCAD 原有的多输出监督：

- supervision=mutation 时枚举四个输出头的 15 个非空组合；
- 每个组合先做 logits 逐元素求和；
- 每个组合计算 0.3×CE + 0.7×Dice；
- 当 fusion_loss_weight > 0 时，再加入融合输出的辅助损失；
- pixel_reliability 模式额外加入可靠性 BCE 校准项。

推理端通过统一的融合读取逻辑得到最终 logits，然后 softmax 和 argmax 得到类别图。当前 3D 病例仍然按切片逐张输入 2D 网络，再拼回体数据。

这给后续创新留下了几个明确的缺口：

1. 解码器是单向 d4→d3→d2→d1，浅层信息不会反馈给前面的语义阶段；
2. EUCB 目前以固定上采样和深度卷积为主，内容自适应重采样能力有限；
3. 跳连融合是 LGAG 后的逐元素相加，没有显式的互补性建模；
4. 训练损失以 CE 和 batch/class 平均 Dice 为主，对表面距离、轮廓连续性和小器官困难程度约束有限；
5. Synapse 数据加载和推理是切片级 2D，当前模型没有使用相邻层的物理上下文；
6. 1 通道 CT 只通过一个 1×1 适配器映射成 3 通道，没有显式利用多个 CT 窗口；
7. 当前器官之间的空间关系和病例内连续性没有进入模型或损失。

## 3. 判断候选创新点是否合格的标准

一个候选方向进入正式实验前，至少要满足下面六条：

1. 问题具体：能说清楚是边界偏移、小器官漏检、假阳性、层间断裂还是语义细节丢失；
2. 节点不同：主计算不在 fuse_outputs() 的四头权重上；
3. 参数可控：可以与 baseline 做参数量或 FLOPs 对照；
4. 因果可消融：至少有一个“原始操作”和一个“加入新机制”的清晰差异；
5. 指标匹配：除了总体 Dice，还能用器官 Dice、HD95、ASD、边界 F1 或层间连续性解释结果；
6. 可形成论文叙事：问题、模块、公式、可视化、消融和失败边界可以连成一条线。

## 5. 方向 1：相关性门控互补跳连融合 CGCF

### 5.1 要解决的问题

LGAG 已经使用 decoder 特征对 skip 特征进行空间门控，但门控后的 skip 仍然直接与 decoder 主路相加。若两者在某个位置的通道响应高度相似，逐元素相加可能重复放大相同语义；如果浅层 skip 还包含背景纹理，重复响应会增加假阳性。

当前的融合只回答：

> 这个位置的 skip 是否应该保留？

它没有回答：

> 保留下来的 skip 中，哪些成分是 decoder 已经拥有的，哪些成分是 decoder 缺少的边界和纹理？

### 5.2 模块思路

在 LGAG 输出的 gated skip 和 decoder 主路之间估计通道相关性。将 skip 分解为：

- 与 decoder 方向平行的重复成分；
- 与 decoder 方向互补的成分。

可以构造如下概念形式：

- r = similarity(d, x_gated)；
- x_parallel = projection(x_gated, d)；
- x_complement = x_gated − r × x_parallel；
- y = d + x_complement。

其中 r 可以由通道余弦相似度、局部相关性和一个轻量门控卷积共同得到。实际实现时不应强行使用硬正交投影，可以采用带残差缩放的软抑制，让模块在训练初期接近原始 d+x。

### 5.3 插入位置

主要位置是 lib/decoders.py 中：

- d3 与 LGAG3 输出 x3 相加之前；
- d2 与 LGAG2 输出 x2 相加之前；
- d1 与 LGAG1 输出 x1 相加之前。

不改变四个输出头，也不改变 fuse_outputs()。

### 5.4 为什么可能涨 Dice

- 浅层边界信息被保留；
- 与深层语义重复的响应不再被无条件叠加；
- 小器官边缘区域更容易得到新的定位证据；
- 背景纹理引起的局部假阳性可能减少；
- 预期最先体现在胰腺、胆囊和 HD95 较高病例。

### 5.5 与 try5 的正交性

try5 在四组 logits 生成之后决定“选哪个头”；CGCF 在解码特征进入预测头之前决定“skip 提供什么信息”。一个作用于输出读出，一个作用于特征形成，论文中可以清楚区分。

### 5.6 最小消融

- B0：原始 d+x；
- B1：只做 gated skip 的残差缩放；
- B2：相关性抑制但不做互补保留；
- B3：完整 CGCF；
- B4：参数量匹配的普通 1×1 卷积。

### 5.7 风险

平行成分并不总是冗余，小器官的正确语义有时也会在浅层和深层重复出现。抑制过强会导致召回下降，因此必须记录 FP、FN、HD95 和器官级 Dice。

> 这是当前最适合作为 try5 后第一个结构创新的方向之一。项目中已有 CGCF 候选文档，但它与 try5 的作用节点仍然正交。

## 6. 方向 2：内容感知抗混叠上采样

### 6.1 要解决的问题

当前 EUCB 的空间恢复包含固定倍率上采样和深度卷积；最终四个 logits 又分别通过固定倍率双线性插值回到输入尺寸。对于薄边界、细长器官和小目标，固定插值不能根据局部结构决定采样邻域，容易产生：

- 边界变软；
- 细小结构被平均；
- 不同尺度预测出现位置偏移；
- resize 前后的标签边缘不一致。

### 6.2 模块思路

将固定上采样换成内容感知重组：

- 由当前 decoder 特征预测局部重采样核；
- 每个高分辨率位置根据邻域内容选择采样权重；
- 通过轻量深度可分离卷积控制参数量；
- 可以使用 CARAFE 类核预测思想，也可以设计 anti-aliasing filter 与 content-aware residual 的组合。

重点是让上采样本身成为特征侧模块，而不是在四个 logits 上再加一个融合权重。

### 6.3 插入位置

优先改 EUCB：

- eucb3：d4 到 d3；
- eucb2：d3 到 d2；
- eucb1：d2 到 d1。

第二阶段才考虑最后 p4/p3/p2/p1 的恢复方式。第一阶段不要同时修改 EUCB 和最终 logits 插值，避免归因混乱。

### 6.4 为什么可能涨 Dice

医学分割的 Dice 对小器官边界十分敏感。上采样阶段如果能够减少边界平均和相位偏移，可能同时改善：

- 小器官的边界召回；
- 细长结构的连续性；
- HD95 和 ASD；
- 预测体积与真实体积的偏差。

### 6.5 最小消融

- 固定 nearest；
- 固定 bilinear；
- bilinear + residual depthwise refinement；
- 内容感知上采样；
- 参数量匹配的普通卷积上采样。

### 6.6 风险

内容感知重组可能增加显存和推理时间，也可能放大噪声纹理。必须报告参数量、FLOPs、峰值显存和单病例推理时间。

## 7. 方向 3：阶段特异的多尺度核竞争

### 7.1 要解决的问题

当前每个 MSCB 都使用固定的 1×1、3×3、5×5 深度卷积分支，并在 add=True 时直接相加。所有 decoder 阶段使用相同的核集合和相同的合并逻辑。

但 d4、d3、d2、d1 面对的任务不同：

- d4 更需要整体器官和大感受野；
- d3、d2 需要局部形状；
- d1 更需要精细边界和纹理。

### 7.2 模块思路

为每个阶段学习输入条件化的多尺度核权重：

- 从当前阶段特征生成 1×1、3×3、5×5 分支权重；
- 权重可以是通道级、空间级或通道—空间低秩权重；
- 增加轻量分支多样性约束，防止所有分支都学成同样响应；
- d4 与 d1 使用不同的权重生成器，避免所有阶段共享同一策略。

与简单的“多尺度输出加权”不同，这里融合的是 MSCB 内部的特征分支，发生在预测头之前。

### 7.3 可能的 Dice 机制

- 大器官使用更大的上下文；
- 小器官和边界区域保留小核细节；
- 不同解码阶段根据局部形状自适应选择感受野；
- 减少固定核集合对某一类器官的偏置。

### 7.4 关键消融

- 固定相加；
- 全局标量核权重；
- 阶段级权重；
- 空间自适应权重；
- 加入与不加入分支多样性约束。

### 7.5 与历史尝试的关系

项目历史中已经有固定多尺度路由相关尝试，并出现过负结果。因此本方向只有在“阶段特异、输入条件化、分支多样性约束”都明确时才值得重新实验。不能把简单的固定核加权重新包装成全新的方法。

---

## 8. 方向 4：可变形深度卷积 MSDC

### 8.1 要解决的问题

固定 3×3 和 5×5 网格默认目标边界与规则方形邻域匹配。真实器官边界可能弯曲、细长、形状不规则，固定采样点会把背景组织混入局部响应。

### 8.2 模块思路

在 MSDC 的深度卷积分支旁预测：

- 采样偏移 offset；
- 可选的 modulation mask；
- 不同 kernel branch 使用不同偏移约束；
- 对偏移范围做正则，避免采样点远离局部区域。

为了控制成本，优先在 d2、d1 使用可变形深度卷积，d4、d3 保留原始 MSDC。这样可以把参数和显存集中在边界敏感阶段。

### 8.3 可能的 Dice 机制

- 贴合弯曲器官轮廓；
- 减少边界外背景响应；
- 提高小器官的轮廓召回；
- 可能降低高 HD95 病例中的局部离群点。

### 8.4 消融

- 仅 d1；
- d2+d1；
- 全部阶段；
- 有 modulation mask 与无 mask；
- 参数量匹配的扩大普通卷积。

### 8.5 风险

可变形采样对训练稳定性和输入分辨率敏感。需要记录 offset 的均值、最大值和是否出现异常大偏移。不能只报告最终 Dice。

---

## 9. 方向 5：解码器跨阶段语义反馈

### 9.1 要解决的问题

当前 EMCAD 是单向解码：d4 → d3 → d2 → d1。d1 获得了较好的浅层定位信息，却不能反过来修正 d3 中的语义判断。多输出监督会让各阶段都学习标签，但不等于阶段之间存在明确的特征反馈。

### 9.2 模块思路

在保持主路径不变的情况下增加一次轻量反馈：

- d1 经过 1×1 投影和下采样回到 d2 尺度；
- d2 经过 1×1 投影和下采样回到 d3 尺度；
- 反馈经过门控后加入对应阶段；
- 反馈只走一次，避免循环网络带来的训练不稳定。

也可以设计成“先粗解码，再浅层修正，再反馈到中层”的两轮解码。

### 9.3 可能的 Dice 机制

- d3 的高层语义得到浅层边界证据修正；
- d2 对小器官的定位更稳定；
- 多尺度输出之间的语义漂移减少；
- 对胰腺、胆囊和器官边缘相邻病例更有帮助。

### 9.4 消融

- 原始单向；
- 仅 d1→d2；
- d1→d2→d3；
- 反馈加法；
- 门控反馈；
- 参数量匹配的额外 MSCB。

### 9.5 风险

反馈路径过强会破坏 decoder 的层级语义，甚至把浅层噪声传回深层。必须使用小初始化残差系数并监控训练稳定性。

---

## 10. 方向 6：解码器全局—局部上下文桥

### 10.1 要解决的问题

PVTv2 编码器已经提供一定全局建模，但当前 decoder 的具体恢复过程主要由局部卷积、上采样和 skip 融合完成。小器官可能需要“它位于腹部哪个相对区域”这一信息，单纯局部纹理不够。

### 10.2 模块思路

在 d4 或 d3 添加一个轻量全局—局部桥：

- 全局分支使用轴向注意力、低秩空间注意力或大核深度卷积；
- 局部分支保留原始 MSCB；
- 用门控残差融合两者；
- 只在 d4/d3 使用，避免高分辨率显存暴涨。

这不是重新替换 PVT 编码器，而是在 decoder 中补充对器官整体位置和长程关系的恢复。

### 10.3 可能的 Dice 机制

- 减少局部相似组织造成的假阳性；
- 帮助小器官在复杂腹部背景中找到正确区域；
- 改善器官整体形状；
- 可能降低高 HD95 病例中的远距离误检。

### 10.4 消融

- 仅局部 MSCB；
- 仅全局桥；
- 全局与局部门控；
- d4、d3 的不同插入位置；
- 参数量匹配的大卷积基线。

### 10.5 风险

如果全局分支过强，可能损失边界细节。应同时报告大器官和小器官，不能只看总体均值。

---

## 11. 方向 7：器官条件化原型调制

### 11.1 要解决的问题

Synapse 的 9 个类别在大小、纹理、位置和边界难度上差异很大。当前 decoder 主要学习通用特征，四个输出头只用 1×1 卷积把通道映射到类别 logits，类别之间没有显式的条件交互。

### 11.2 模块思路

建立轻量器官原型：

- 从 d3 或 d2 全局池化特征得到病例级语义；
- 为每个器官类别学习一个 prototype；
- 计算当前特征与各 prototype 的匹配；
- 将匹配结果转成 FiLM 或通道调制；
- 调制 decoder 特征，再送入已有输出头。

原型不是额外的四头预测器，也不是把类别 logits 重新加权，而是用类别条件改变特征表示。

### 11.3 可能的 Dice 机制

- 让小器官获得更有针对性的通道响应；
- 减少不同器官共享纹理造成的类别混淆；
- 通过全局上下文帮助低频出现的器官；
- 重点观察 pancreas、gallbladder、stomach。

### 11.4 消融

- 无 prototype；
- 仅病例级通道调制；
- 共享 prototype；
- 每类 prototype；
- prototype 加位置编码与不加位置编码。

### 11.5 风险

类别条件模块容易增加参数量，也可能过拟合固定数据集的器官外观。需要跨 seed 和跨数据集验证。

---

## 12. 方向 8：低频语义—高频边界双路径

### 12.1 要解决的问题

当前 CAB 和 SAB 分别进行通道和空间注意力，但没有显式把低频器官整体结构与高频边界、纹理分开。高频纹理可能被当作边界，低频结构又可能在上采样中变得过于平滑。

### 12.2 模块思路

在 d1 或 x1/d1 融合后分成两条路径：

- 低频路径：平均池化、低通卷积或小波低频分量，负责器官区域；
- 高频路径：拉普拉斯、小波高频或残差卷积，负责边界；
- 用空间门控决定两条路径的比例；
- 最后以残差方式回到 d1。

重点是特征级频率分解，而不是对四个 logits 做频域加权。

### 12.3 可能的 Dice 机制

- 低频路径减少区域缺失；
- 高频路径减少边界粗糙；
- 小器官边界偏移和细长结构断裂可能改善；
- 频率分支的可视化也比较适合论文图示。

### 12.4 消融

- 低频单路；
- 高频单路；
- 固定比例；
- 空间自适应比例；
- 频率模块插在 d2 与 d1 的比较。

### 12.5 风险

CT 图像中的噪声也属于高频。高频分支需要抑制噪声放大，并报告假阳性变化。

---

## 13. 方向 9：表面距离联合监督

### 13.1 要解决的问题

当前训练主要使用 CE 和 Dice。Dice 关注区域重叠，对边界偏移的惩罚有限。已有日志和病例分析中，高 HD95 往往说明局部边缘偏离、断裂或远处假阳性。

### 13.2 模块思路

从训练标签生成每类 signed distance map 或 boundary distance map：

- 预测概率与真实距离图计算 surface loss；
- 或者对预测边界与真实边界的距离进行软约束；
- 只在 p1 或最终融合 logits 上加入低权重；
- 后续可以比较全部类别和小器官类别加权。

基础损失可写成：

总损失 = 0.3×CE + 0.7×Dice + λ_surface×L_surface。

### 13.3 可能的 Dice 机制

- 减少边界外溢和边界内缩；
- 小器官因边界偏移导致的 FN/FP 同时减少；
- Dice 可能小幅提高，HD95 和 ASD 更可能稳定改善；
- 论文中可以形成“区域重叠 + 表面几何”的互补监督故事。

### 13.4 消融

- CE + Dice；
- 加 boundary loss；
- 加 signed distance loss；
- 只作用于 p1；
- 作用于 mutation 每个组合；
- 仅小器官加权与全部类别加权。

### 13.5 风险

距离图生成需要统一 spacing 和边界定义。当前部分指标使用像素间距，不能把像素距离直接写成毫米距离。

---

## 14. 方向 10：轮廓曲率与连通性监督

### 14.1 要解决的问题

普通 boundary loss 只告诉模型边界位置，不能充分表达轮廓是否连续。医学器官常见错误包括：

- 轮廓局部断裂；
- 边缘毛刺；
- 狭窄结构被截断；
- 预测出现多个不相连小岛。

### 14.2 模块思路

从标签生成边界带和局部轮廓描述：

- 边界像素监督；
- 邻域连续性监督；
- 对边界方向变化或曲率进行软约束；
- 对预测边界中的断裂和异常尖峰增加惩罚。

实际实现可以从简单的 8 邻域连通性损失开始，再考虑曲率项。不要一开始同时加入多种高阶几何损失。

### 14.3 可能的 Dice 机制

- 轮廓连续后，边界 FN/FP 同时减少；
- 小器官的局部缺口不容易把器官切成两段；
- HD95、ASD、Boundary F1 可能明显改善；
- 如果病例中存在大面积背景，连通性约束也可减少孤立假阳性。

### 14.4 消融

- 仅边界带；
- 边界带 + 邻域连续性；
- 边界带 + 曲率；
- 全部组合；
- 不同损失权重。

### 14.5 风险

有些器官真实形状可能存在细小凹陷，过强的平滑先验会抹掉真实结构。必须检查可视化和器官体积误差。

---

## 15. 方向 11：器官自适应 Tversky/Focal 监督

### 15.1 要解决的问题

当前 DiceLoss 对类别求平均，CE 也没有显式根据器官大小和 FN/FP 类型做动态平衡。对于像胰腺、胆囊这类面积较小的器官，少量边界漏检就可能显著影响 Dice。

### 15.2 模块思路

在现有 CE + Dice 外增加一个可控的类别自适应项：

- Tversky 控制 FN 与 FP 的相对惩罚；
- Focal 调节容易样本和困难样本；
- 类别权重由训练集统计的面积和出现频次固定得到；
- 训练过程中不使用验证集或测试集自动调权。

建议先固定一组权重，再做有限消融，不要用测试集反复搜索 α、β 和 gamma。

### 15.3 可能的 Dice 机制

- 增加小器官有效梯度；
- 对漏检比误检更严重的器官提高 FN 惩罚；
- 使模型在低面积类别上保持召回；
- 可能提高目标器官 Dice，同时要监控大器官是否下降。

### 15.4 消融

- 原始 CE + Dice；
- CE + Dice + Tversky；
- 仅小器官加权；
- 所有器官动态加权；
- 固定权重与面积自适应权重。

### 15.5 风险

只优化小器官可能损害总体宏平均，也可能增加假阳性。必须报告每个器官和 FP/FN 变化。

---

## 16. 方向 12：基于错误拓扑的困难样本课程

### 16.1 要解决的问题

随机切片训练中，很多切片没有目标器官或目标非常容易。训练梯度可能被大量简单背景样本占据，模型对少数困难切片的边界和小器官学习不足。

### 16.2 模块思路

使用训练集内部的历史预测错误构造困难度：

- 每个训练切片记录 FN、FP、边界距离或连通性错误；
- 用指数滑动平均平滑困难度；
- 下一轮提高困难切片采样概率或 loss 权重；
- 只使用训练标签和训练预测，不读取验证或测试结果；
- 训练后期降低困难样本权重，避免过拟合异常样本。

它关注的是“模型实际犯了什么错”，与按 GT 面积进行的目标尺度课程不同。

### 16.3 可能的 Dice 机制

- 增加真正困难切片的训练次数；
- 针对高 HD95 病例和局部断裂建立反馈；
- 比单纯增加 epoch 更直接地利用有限训练预算；
- 可能降低小器官的病例间方差。

### 16.4 消融

- 随机采样；
- 仅面积分层；
- 基于 FN 的困难采样；
- 基于边界距离的困难采样；
- FN+边界联合困难度。

### 16.5 风险

困难样本策略容易放大标签噪声或异常病例。必须限制每个样本的最大采样概率，并报告训练分布变化。

---

## 17. 方向 13：解码特征跨尺度一致性蒸馏

### 17.1 要解决的问题

四个解码阶段都被监督，但不同尺度的特征可能学习到相互矛盾的语义。当前 try5 通过输出端可靠性选择不同头，解决的是“哪个输出更可信”；它没有直接减少四个阶段特征之间的语义漂移。

### 17.2 模块思路

对 d4、d3、d2、d1 做通道投影和空间对齐：

- 将各阶段映射到一个低维语义空间；
- 把高层特征上采样或把低层特征下采样；
- 对语义部分做 stop-gradient consistency；
- 对边界残差保留一定自由度，避免强行让所有尺度完全相同；
- 可使用 EMA teacher 或最高层/最低层作为软教师。

这里约束的是 latent feature，而不是把四个 logits 加权融合。

### 17.3 可能的 Dice 机制

- 多尺度预测的语义方向更一致；
- p4 不容易只学粗结构，p1 也不容易只学纹理；
- 训练梯度更稳定；
- 可能减少融合前不同头之间的冲突。

### 17.4 消融

- 无一致性；
- 只做 logits 一致性；
- 只做特征一致性；
- 特征一致性 + 边界残差保护；
- EMA teacher 与固定 teacher。

### 17.5 风险

一致性过强会损失多尺度互补性，甚至使四个阶段退化成相似表示。必须检查特征相似度和边界指标。

---

## 18. 方向 14：spacing-aware 2.5D 层间上下文

### 18.1 要解决的问题

当前 Synapse 训练数据返回单张 [1,H,W] 切片，测试时逐张切片推理，再拼回 [D,H,W]。模型没有看到相邻层信息，也不知道相邻切片之间的实际物理间距。

腹部器官在 z 轴上通常具有连续性。单张切片容易出现：

- 某层检测到、下一层突然消失；
- 小器官在边缘层漏检；
- 相邻层的轮廓变化不合理；
- 层厚变化导致固定邻层数量并不等价。

### 18.2 模块思路

把中心切片及相邻切片作为多通道输入，例如 3、5 或 7 层：

- 以中心层作为监督目标；
- 用 z-spacing 选择物理距离相近的邻层；
- 增加相对层间距编码；
- 经过轻量 N→3 适配器后接入现有 PVTv2-EMCAD；
- 推理时严格使用相同的中心层重建规则。

### 18.3 可能的 Dice 机制

- 利用层间连续性补回中心层漏检区域；
- 帮助判断器官进入和离开视野的边界；
- 对小器官和薄层结构尤其有帮助；
- 可能改善病例级体积和层间断裂指标。

### 18.4 消融

- 2D 单层；
- 3 层固定邻层；
- 5 层固定邻层；
- 3 层 spacing-aware；
- 5 层 spacing-aware；
- 是否加入 z-distance embedding。

### 18.5 风险

需要同时改训练数据、测试输入和病例重建，不能只改第一层卷积。上下文层数越多不一定越好，必须按 1/3/5/7 等固定矩阵逐步验证。预训练权重兼容性也要单独记录。

---

## 19. 方向 15：病例内跨切片 ConvGRU 或 SSM 聚合

### 19.1 要解决的问题

2.5D 只使用有限邻层，病例内更远的层间关系仍然没有利用。对于器官连续出现多层的病例，逐层独立预测可能产生 z 轴抖动。

### 19.2 模块思路

先对每张切片提取 encoder 或 d2/d1 特征，再沿 z 轴使用轻量序列模块：

- 双向 ConvGRU；
- 1D state-space module；
- 只在低分辨率 d2 特征上处理，控制计算；
- 输出每层的修正特征，再进入 d1 和输出头；
- 训练时按病例序列或短序列窗口采样。

### 19.3 可能的 Dice 机制

- 保持器官预测在相邻层之间连续；
- 减少孤立假阳性和短暂漏检；
- 体数据指标和 HD95 可能改善；
- 对边缘层和器官形状变化慢的区域尤其有效。

### 19.4 消融

- 独立 2D；
- 单向 ConvGRU；
- 双向 ConvGRU；
- 1D SSM；
- 只在 d2 处理与在 d1 处理。

### 19.5 风险

需要重新设计 batch 和病例级训练，训练成本显著增加。必须确认病例顺序、z 轴方向和 spacing 处理正确。

---

## 20. 方向 16：多 CT 窗口可学习输入适配

### 20.1 要解决的问题

当前灰度输入只通过 1×1 卷积从 1 通道映射到 3 通道。这个适配器可以学习通道混合，但输入本身没有显式提供不同 HU 窗口下的组织对比。

### 20.2 模块思路

构造多个可学习或半固定窗口：

- 软组织窗口；
- 宽腹部窗口；
- 较窄的对比窗口；
- 每个窗口经过独立归一化或可学习 window center/width；
- 用轻量注意力决定不同窗口对当前 decoder 的贡献；
- 最终仍输出 3 通道以兼容 PVTv2 预训练输入。

“窗口之间的通道组合”是输入表征问题，不能写成 try5 的四头输出融合。

### 20.3 可能的 Dice 机制

- 增强软组织边界；
- 让不同器官在不同强度范围下具有更明显对比；
- 减少单一窗宽窗位对低对比器官的限制；
- 小器官和胰腺等低对比组织可能受益。

### 20.4 消融

- 原始 1→3；
- 固定三窗口；
- 可学习窗口；
- 可学习窗口 + 轻量窗口门控；
- 不同窗口数量。

### 20.5 风险

窗口设置与预处理的 HU 归一化必须一致。不能在不同实验中随意改变窗宽、窗位和强度范围。

---

## 21. 方向 17：器官解剖关系图约束

### 21.1 要解决的问题

Synapse 的多个器官并非独立随机分布。器官的相对位置、大小和共现关系存在稳定模式。当前网络主要逐像素分类，没有显式约束：

- 小器官是否出现在合理区域；
- 多器官预测是否互相重叠或冲突；
- 预测中心和真实中心是否偏离；
- 某个器官的出现是否与相邻器官关系一致。

### 21.2 模块思路

增加一个轻量关系分支：

- 从每类预测概率或 decoder feature 提取软中心、面积和包围盒；
- 构造器官节点；
- 用图卷积或 MLP 建模器官间相对位置；
- 关系头输出中心距离、上下左右关系或共现关系；
- 关系损失只作为低权重辅助约束，主分割输出仍由原网络生成。

### 21.3 可能的 Dice 机制

- 减少器官位置漂移；
- 降低背景区域的器官假阳性；
- 帮助低分辨率阶段保持整体布局；
- 重点观察小器官和高 FP 病例。

### 21.4 消融

- 无关系约束；
- 仅中心距离；
- 中心距离 + 面积关系；
- 图关系模块；
- 不同关系损失权重。

### 21.5 风险

解剖关系有变异，强先验可能错误抑制真实病例。必须展示关系约束失败的病例，并避免使用硬规则后处理替代模型学习。

---

## 22. 方向 18：可微形态与拓扑先验

### 22.1 要解决的问题

预测中可能出现：

- 小孤岛；
- 不合理孔洞；
- 断裂；
- 多个分离组件；
- 细小器官边界内外毛刺。

单纯 CE 和 Dice 对这些拓扑错误约束不足。

### 22.2 模块思路

采用可微近似的形态和拓扑约束：

- soft opening/closing；
- soft connectedness；
- Euler characteristic 近似；
- 预测边界与内部区域的形态一致性；
- 对不同器官使用不同强度。

应先实现最简单的 soft morphology loss，再评估是否需要更复杂的拓扑近似。

### 22.3 可能的 Dice 机制

- 去除孤立假阳性；
- 填补小孔洞；
- 减少局部断裂；
- 对体积和边界指标都有潜在帮助。

### 22.4 消融

- 无拓扑项；
- 仅 opening/closing；
- 仅连通性；
- 形态 + 连通性；
- 只作用于小器官。

### 22.5 风险

有些真实器官边界可能存在狭窄连接或小凹陷，强形态先验会造成过度平滑。必须与原始预测和标注可视化对照。

---

## 23. 方向 19：边界软标签与距离过渡目标

### 23.1 要解决的问题

训练标签是离散类别图，resize、插值和人工标注都会让边界附近出现不可避免的不确定性。当前 CE 把边界像素当作完全确定的类别，可能导致边界振荡或过拟合标注锯齿。

### 23.2 模块思路

生成边界过渡目标：

- 内部区域保持接近 1；
- 边界带使用距离衰减的 soft target；
- 远离边界的背景保持接近 0；
- 可以只对 p1 或最终输出使用；
- 训练后期逐渐降低软标签强度，恢复清晰监督。

该方法改变监督目标，不改变四头融合，也不产生新的可靠性权重。

### 23.3 可能的 Dice 机制

- 让模型更平稳地学习边界；
- 减少单像素锯齿；
- 对 resize 后的小器官边缘更友好；
- 可能改善 Dice、HD95 和 Boundary F1。

### 23.4 消融

- 硬标签；
- 固定边界带；
- 距离衰减 soft label；
- 早期 soft、后期 hard；
- 不同边界宽度。

### 23.5 风险

边界软化过度会造成预测收缩或模糊。必须报告器官体积误差和边界偏移。

---

## 24. 方向 20：解码器坐标与解剖位置编码

### 24.1 要解决的问题

当前 decoder 特征主要由卷积和 skip 组成，网络需要从图像内容中自己推断“这个像素处在腹部哪个相对位置”。对于外观相似的组织，缺少位置提示可能增加假阳性。

### 24.2 模块思路

向 d3/d2 注入轻量位置编码：

- 归一化二维坐标；
- 与 d4 全局特征结合的相对位置；
- 可学习的器官位置偏置；
- 用 1×1 卷积和门控残差注入；
- 不直接强制某个器官只能在固定区域出现。

可以把模块解释为“软解剖位置编码”，而不是硬先验。

### 24.3 可能的 Dice 机制

- 减少相似纹理区域的误分；
- 帮助低对比、小面积器官获得位置提示；
- 增强大器官整体定位；
- 可能改善 FP 与病例间稳定性。

### 24.4 消融

- 无坐标；
- 固定坐标；
- 可学习坐标嵌入；
- 坐标 + 全局语义；
- d3 注入与 d2 注入。

### 24.5 风险

固定数据集中的位置规律可能被过拟合。需要在不同病例和不同切片层位上检查泛化。

---

## 25. 最值得优先做的 6 个方向

### 25.1 第一名：CGCF 互补跳连融合

优点：

- 直接对应 EMCAD 当前最清晰的结构缺口；
- 只改 d3/d2/d1 的跳连融合；
- 参数量很小；
- 与 try5 输出端融合正交；
- 便于画出 LGAG、重复成分和互补成分；
- 可以用边界和 HD95 解释收益。

适合论文标题方向：

Complementary Skip Fusion for Redundancy Suppression in EMCAD-based Medical Image Segmentation

### 25.2 第二名：内容感知抗混叠上采样

优点：

- 当前 EUCB 存在固定上采样路径；
- 直接针对边界恢复和小器官；
- 结构位置明确；
- 适合比较边界 F1、HD95、ASD 和计算成本。

### 25.3 第三名：spacing-aware 2.5D

优点：

- 改变的是数据上下文，不是输出融合；
- 对当前切片级 2D 路径形成明显差异；
- 医学解释清晰；
- 可能带来更大的 Dice 增益。

代价：

- 必须同时改训练读取、测试输入、中心层重建和 spacing 处理；
- 需要 3/5/7 层受控消融；
- 预训练输入适配需要单独说明。

### 25.4 第四名：表面距离联合监督

优点：

- 代码改动较小；
- 与当前 CE + Dice 互补；
- HD95/ASD 解释力强；
- 可作为 CGCF 的辅助机制，但必须先独立完成验证。

### 25.5 第五名：器官条件化原型调制

优点：

- 面向 Synapse 多器官差异；
- 重点帮助胰腺、胆囊等低分器官；
- 不在输出端做四头权重；
- 有较清楚的类条件特征解释。

### 25.6 第六名：解码特征跨尺度一致性蒸馏

优点：

- 直接处理多尺度输出之间的语义漂移；
- 与 try5 的“可靠性选择”形成互补；
- 能把多输出监督从“多个 loss”提升为“多尺度表示协同”。

## 26. 推荐的论文级实验流程

### 26.1 阶段一：冻结 try5 结果

先保存当前 try5 的完整记录：

- branch 和 commit；
- 训练命令；
- fusion_mode、fusion_loss_weight、reliability_loss_weight；
- encoder、输入尺寸、batch、epoch、seed；
- checkpoint 路径；
- 每个病例和每个器官的 Dice、HD95、ASD、Jaccard；
- 四头可靠性权重均值、标准差、最小值、最大值；
- 参数量、FLOPs、显存、训练时间和推理时间。

当前代码路径中，trainer.py 每个 epoch 会调用病例级推理并更新 best。论文版必须确认用于选模型的是独立 validation，而不是最终 test 清单。

### 26.2 阶段二：新模块先脱离 try5 做单变量验证

对任意候选模块建立四组最小矩阵：

| 组 | 输出融合 | 新模块 | 目的 |
|---|---|---|---|
| B0 | p1 | 关闭 | 原始 EMCAD baseline |
| B1 | p1 | 开启 | 验证新模块本身 |
| T0 | pixel_reliability | 关闭 | try5 单独结果 |
| T1 | pixel_reliability | 开启 | 验证组合是否进一步提升 |

顺序应该是：

1. 先比较 B1 与 B0；
2. 若 B1 有稳定收益，再比较 T1 与 T0；
3. 不能只跑 T1 与 B0，然后把所有提升都写成新模块贡献；
4. 不能在第一个 seed 上看到提升就同时叠加第二个损失。

### 26.3 阶段三：固定 seed 和患者级评估

建议至少使用三个预先固定的 seed。每个 seed 使用：

- 相同病例清单；
- 相同预处理和增强；
- 相同输入尺寸；
- 相同训练轮数；
- 相同 optimizer 和 learning rate；
- 相同 checkpoint 选择规则；
- 相同测试脚本。

主结果报告：

- 患者级总体 Dice；
- 8 个器官 Dice；
- HD95、ASD、Jaccard；
- 每病例配对差值；
- 均值、标准差、中位数；
- 提升病例数与下降病例数；
- 95% bootstrap 置信区间。

### 26.4 阶段四：机制消融

以 CGCF 为例，正式消融可以是：

| 实验 | 机制 |
|---|---|
| C0 | 原始 d+x |
| C1 | 仅可学习融合门 |
| C2 | 仅相关性抑制 |
| C3 | 相关性抑制 + 互补保留 |
| C4 | C3 + try5 |
| C5 | 参数量匹配普通卷积 |

每个候选模块都应有类似的最小机制拆分。消融数量应控制在能够完成和解释的范围内。

### 26.5 阶段五：最终论文组合

如果 CGCF 与 try5 都在多个 seed 上稳定有效，建议论文最终结构为：

1. 主模块：CGCF，负责 decoder 特征互补；
2. 辅助模块：try5 像素级可靠性多头融合，负责多阶段输出读出；
3. 训练损失保持简单，表面距离损失只在单独验证有效后再加入；
4. 不要把 20 个候选方向全部串联。

如果 CGCF 无效，可以按以下顺序换主模块：

1. 内容感知抗混叠上采样；
2. spacing-aware 2.5D；
3. 器官条件化原型调制；
4. 特征级跨尺度一致性；
5. 表面距离联合监督。

## 27. 每个候选方向的停止标准

为防止不断叠加模块，应在实验前写好停止条件：

- 三个 seed 的总体 Dice 均值没有方向一致的改善；
- 目标器官有提升，但总体 Dice 和大器官明显下降；
- Dice 提升只出现在一个病例或一个 seed；
- HD95、ASD 和可视化显示边界恶化；
- 参数量、显存或时间增加明显，但相同预算对照没有收益；
- 模块只在与 try5 组合时有效，脱离 try5 就失效；
- 训练日志出现权重塌缩、梯度异常或输出退化；
- 需要根据最终测试集反复调阈值才能得到提升。

达到停止条件时，应把方向记录为失败候选，而不是继续添加新的 loss 去挽救。

## 28. 最终建议

### 28.1 如果只选一个新模块

优先选择：

CGCF 相关性门控互补跳连融合。

理由：

- 与 try5 作用节点清楚分离；
- 直接利用 EMCAD 的 LGAG 和 d+x 结构；
- 代码改动小，参数可控；
- 适合解释“浅层边界信息重复和冗余”的具体问题；
- 容易进行三 seed、参数匹配和边界指标验证。

### 28.2 如果目标是更明显的医学上下文创新

选择：

spacing-aware 2.5D 层间上下文。

它的论文差异更明显，但工程工作量更大。必须先把训练、测试和病例重建协议设计好，再比较 1/3/5/7 层上下文。

### 28.3 如果目标是低风险快速验证

选择：

表面距离联合监督或多 CT 窗口输入适配。

这两类方向改动相对集中，容易快速得到正负结果，但结构新颖性通常低于 CGCF、2.5D 或跨尺度反馈。

### 28.4 当前不建议优先做的事情

暂缓以下做法：

- 再设计一个四头置信度融合器；
- 把 entropy、variance、uncertainty 直接变成四头权重；
- 同时更换 decoder、loss、输入尺寸和增强；
- 用测试集 Dice 搜索损失权重；
- 把一次 seed 的提升写成稳定涨点；
- 只看总体 Dice，不报告小器官、HD95 和每病例差异；
- 把已有 try3 的稀疏输出细化、try4 的分歧细化、try6 的目标尺度课程监督原样重新命名为新方法。

## 29. 一句话论文路线

当前最清晰的路线是：

> try5 解决“多个解码头在不同像素上的可信程度不同”；下一模块解决“解码器在生成这些头之前，如何从 skip 中提取互补信息、如何保持边界和器官结构”；二者经过独立消融和组合实验后，再形成“特征互补 + 输出可靠性”的双层 EMCAD 改进路线。

这条路线在机制上有两个层次：

- 特征层：减少 decoder 与 skip 的冗余、恢复边界和结构；
- 输出层：根据像素位置选择更可靠的多阶段预测。

两个层次的作用对象不同，论文中更容易建立清晰的贡献边界。
