# 99家央企行业分类、国家作用与对外沟通指南

> 适用范围：国务院国资委于2026年7月11日更新的99户中央企业名录，与本次提问所附图片一致。
>

>
> 本文不按官网宣传材料逐句摘抄，而是用产业链、国家功能和业务对接三个视角解释。企业名称链接优先采用国资委央企名录所列官网。

## 二、为什么它们能成为央企

### 2.1 根本依据是出资和管理关系，不是规模与荣誉

“央企”不是一个企业营业收入足够大、技术足够先进之后评出来的称号。严格地说，它是一种**国有产权和中央层面履行出资人职责的关系**。

本图中的99户，是国务院国有资产监督管理委员会根据国务院授权，代表国家履行出资人职责的中央企业。国务院国资委负责所监管中央企业的国有资产管理、保值增值、改革重组、负责人考核、资本收益等出资人职责。

所以，下面三种推理都是错误的：

- “企业规模很大，所以自动成为央企”；
- “企业为国家作出重大贡献，所以被授予央企称号”；
- “名称里有中国、国家或总局，所以一定是央企”。

一家企业是不是这张表里的央企，最终看国务院授权下的出资监管关系，以及是否进入国资委正式央企名录，而不是看名字、知名度或行政级别传闻。

### 2.2 为什么中央层面要直接持有这些企业

它们虽然行业不同，但中央资本长期集中在这些领域通常有六类现实原因：

1. **国家安全不能完全依靠临时市场采购。** 核工业、航空航天、船舶、兵器、军工电子等能力需要长期投入、完整体系和严格安全管理。
2. **基础网络必须全国统筹。** 电网、通信网、油气管网、卫星互联网、骨干物流和重大水利工程具有跨地区、长周期、强网络效应。
3. **能源、粮食和矿产需要供应安全。** 油气、电力、煤炭、粮食储备、稀土及其他重要矿产一旦大范围中断，会影响整个国家生产生活。
4. **关键技术和重大装备投资巨大、回报周期长。** 航空发动机、商用飞机、核电、重型装备、轨道交通等产业不适合只追求短期收益。
5. **国家重大工程需要超大规模组织能力。** 跨流域调水、大型水电、铁路、港口、电力和海外工程需要长期融资、工程管理和全产业链协同。
6. **国有资本需要专业化调整和保值增值。** 国投、诚通、国新、融通等并不靠一种产品立足，而是承担投资、运营、整合和盘活国有资本的任务。

这解释的是“为什么国家需要在这些领域配置中央资本”，不是说每一家央企的每一项业务都是行政任务，也不是说它们可以不计成本经营。

### 2.3 它们既承担国家任务，也是市场主体

理解央企最容易犯的错误，是只看到其中一面：

```text
国家功能
  +
市场化经营
  +
国有资本保值增值
  +
依法承担社会责任和安全责任
  =
央企实际运行逻辑
```

央企要参与市场竞争、签合同、核算成本、实现合理经营回报，也要在能源保供、抢险救灾、重大工程、技术攻关等场景中承担超出普通短期商业项目的责任。盈利与国家使命不是非此即彼，关键是主责主业、经营效率与国家功能相统一。

### 2.4 这99户不是中国全部“中央国企”

国务院国资委官网明确，其主要职责是监管中央所属企业中**非金融类企业**的国有资产。因此，本表不包含由财政部等履行出资人职责的中央金融企业，也不等于所有中央文化企业或中央部门所属单位名录。

对外可以准确地说：

> “这是国务院国资委履行出资人职责的99户中央企业名录。”

不宜笼统地说：

> “中国一共只有99家央企。”

## 三、对外沟通前必须理解的监管关系

央企不是政府部门，国资委也不是所有业务的行业审批机关。可以用下面这张图理解：

```text
国务院
  |
国务院国资委：主要履行出资人职责、国有资产监管职责
  |
中央企业集团：依法经营、承担主责主业和国家任务
  |
二级专业公司 / 上市公司 / 区域公司
  |
项目公司 / 生产单位 / 研究院 / 业务部门

与此同时：

国家发展改革委、工业和信息化部、国家能源局、民航局等
  -> 分别承担规划、政策、行业监管或行政许可等职责
```

例如，国家能源局负责能源行业相关监管与政策职责，国家电网是电网经营企业；中国民航局是行业主管机构，三大航空集团是航空运输企业。把企业说成行业监管者，是对外沟通中的低级错误。

## 四、行业一：国防科技、核工业、航空航天与战略装备

### 4.1 这个板块在国家体系中的位置

这类企业的共同特点是技术体系复杂、研发周期长、可靠性要求高、与国家安全密切相关。对外沟通宜停留在公开主业、民用产业和公开合作范围，不打听型号、产能、供应关系、评审过程等非公开信息。

### 4.2 这个板块对外可以怎么介绍

> “这10户企业构成我国核工业、航天、航空、船舶、兵器和军工电子等战略科技工业的重要组织载体。它们解决的不只是某个产品能否生产，而是国家能否长期保持完整研发、试验、制造和保障体系。”

## 五、行业二：石油天然气与综合化工

### 5.1 先看懂油气产业链

```text
勘探、开采
    -> 原油天然气集输
    -> 全国干线管道、储气库、LNG接收设施
    -> 炼油、化工
    -> 成品油、天然气和化工材料销售
```

三大油企是上下游一体化能源公司，但各有相对强项；国家管网主要提供骨干输送平台；中国中化的突出位置则是综合化工、农业投入品和新材料。

| 序号及企业 | 主要做什么 | 国家层面的作用 | 对接时要说清的边界 |
| --- | --- | --- | --- |
| 11 [中国石油天然气集团有限公司](http://www.cnpc.com.cn/) | 覆盖油气勘探开发、炼化销售、油服和装备，陆上油气上游能力尤其突出。 | 提高国内油气供给和多元化资源保障能力，稳定天然气及成品油供应。 | 不能把中石油理解成加油站公司；国家油气干线管网已主要由国家管网运营。 |
| 12 [中国石油化工集团有限公司](http://www.sinopecgroup.com/) | 同样覆盖油气上下游，但炼油、石化、基础化工材料和成品油销售是鲜明强项。 | 保障燃料和基础化工原料供应，支撑交通、制造、纺织、材料等产业。 | “中石化更强在炼化化工”是相对侧重，不代表它不做上游油气。 |
| 13 [中国海洋石油集团有限公司](http://www.cnooc.com.cn/) | 重点进行海上油气勘探开发，并延伸LNG、炼化和能源服务。 | 建立海洋油气开发能力，增加天然气和海上资源供应来源。 | 最鲜明的区别是“海洋油气”，不是简单按国内外地域划分。 |

| 43 [中国中化控股有限责任公司](http://www.sinochem.com/) | 重点布局生命科学、材料科学、基础化工、农业投入品及相关产业服务。 | 保障重要化工材料和农业投入品供应，推动化工产业向高端材料与农业科技升级。 | 不能只称为石油贸易公司；当前业务边界来自中化集团与中国化工重组后的综合体系。 |

### 5.2 一句话对外区分

> “中石油相对偏陆上油气和上游，中石化相对偏炼化化工，中海油突出海洋油气，国家管网负责骨干输送，中国中化更突出综合化工、材料和农业科技。这里说的是相对强项，不是互不经营。”

## 十四、行业十一：国有资本投资、运营与资产管理

### 14.1 它们的“产品”为什么看不见

### 14.2 国投、诚通、国新、融通怎么区分

- **国投**更像长期产业投资者：选产业、投项目、控股经营并培育产业。
- **诚通、国新**更像国有资本运营平台：通过基金、股权和资产运作促进资本流动与结构优化，二者各有具体基金和业务体系。
- **融通**更突出特定存量资产的接收、经营和盘活。

这只是帮助理解的主强项，不是法律上互不重叠的经营边界。对接时应问清楚具体基金、产业平台、资产包和投资阶段，而不能只问“你们集团投不投资”。

### 15.2 科研、设计、咨询、检测四种角色不要混

```text

咨询单位：判断项目是否值得做、方案是否合理、风险是否可控
```

一家公司可能同时具备其中两三种能力，但在一个具体合同里通常有明确角色。尤其要避免把“参加标准研究”“承担设计”“出具检测报告”和“政府批准”说成同一件事。

## 十六、把99户央企放回国家运行体系中理解

如果不记企业历史，只记国家需要，可以把这99户理解成七类长期能力：

| 国家需要长期保持的能力 | 对应的典型央企板块 | 国家真正关心的问题 |
| --- | --- | --- |
| 国家安全与战略科技 | 核、航天、航空、船舶、兵器、军工电子 | 关键体系能否自主研发、试验、制造和保障，而不是临时花钱能否买到一件产品。 |
| 全国性基础网络 | 电网、通信网、油气管网、卫星互联网、骨干物流、水利 | 网络能否统一规划、互联互通、稳定运行，并在灾害和高峰期保持连续服务。 |
| 能源资源与粮食安全 | 油气、煤电、矿产、稀土、粮食储备、盐业 | 关键物资中断时国家是否有储备、替代来源、调度能力和恢复能力。 |
| 工业基础与重大装备 | 汽车、轨道车辆、发电设备、输变电设备、材料与工业母机 | 产业链最底层的材料、部件、工艺和成套装备能否自主稳定供应。 |
| 重大工程与公共服务 | 铁路、公路、港口、水电、城市建设、环保、医药 | 能否组织跨地区、长周期、高复杂度项目，并承担应急和民生保障。 |
| 国有资本优化配置 | 国投、诚通、国新、融通 | 国家资本能否从低效和分散领域流向战略产业，存量资产能否有效盘活。 |
| 共性技术与质量信用 | 产业研究院、工程咨询、设计、人力、检验认证 | 技术能否工程化，标准能否统一，质量能否证明，人才和知识能否高效配置。 |

因此，“为什么这些企业由中央层面持有”不能只回答“因为重要”。更准确的说法是：这些能力普遍具有跨地区外溢、巨额长期投入、自然网络属性、供应安全要求、应急责任或全行业共性，需要中央层面保持持续投入和组织协调；同时，企业仍必须依法经营、接受市场和经营业绩检验。

## 十七、达到对外沟通水平：怎样介绍一家央企

### 17.1 30秒介绍公式

对外介绍不要背官网口号，按下面四句话组织：

```text
1. 身份：它是哪一类中央企业，在产业链什么位置。
2. 主业：它主要提供什么产品、工程、网络或服务。
3. 国家作用：它主要保障哪种安全、基础设施或产业能力。
4. 边界：它不是什么，真正合作需要落到哪个板块或法人。
```

例如介绍国家电网：

> “国家电网是国务院国资委履行出资人职责的电网央企，主要建设运营输配电网并负责相应区域的电力调度和供电服务。它的国家作用是保障大电网安全和跨区域电力配置。它不是主要发电集团，具体数字化采购通常还要落实到省级电力公司、直属单位或项目公司。”

这段话同时回答了“是谁、做什么、为什么重要、找谁合作”，比“世界一流能源互联网企业”更适合实际交流。

### 17.2 三分钟交流结构

当对方希望你多说一些时，按以下顺序展开：

1. **先讲产业链位置**：上游资源、装备制造、网络运营、工程建设、消费服务，还是科研检测。
2. **再讲核心能力**：它靠资源、牌照和网络，还是靠研发、制造、工程组织、资本或渠道。
3. **再讲国家功能**：保安全、保供应、建网络、攻技术、做应急，还是优化国有资本。
4. **说明市场属性**：是否与同类央企、地方国企、民企和外企竞争，避免说成行政垄断。
5. **最后落到合作**：具体二级公司、使用单位、技术部门、采购方式和验收指标是什么。

### 17.3 向央企人员提问的“三层问题”

- **集团层**：“贵集团这一业务由哪个专业板块牵头？总部负责战略统筹，还是也负责项目采购？”
- **业务层**：“实际使用单位是哪家二级或三级公司？目前流程中的成本、效率或安全痛点是什么？”
- **项目层**：“预算和采购主体是谁？技术决策、数据管理、验收和付款分别由谁负责？”

只问“你们央企有没有合作机会”，对方很难回答。问到业务板块、场景、主体和流程，才算进入可对接状态。

## 十八、集团总部、二级公司、上市公司和项目公司

### 18.1 六种常见主体

| 主体 | 通常负责什么 | 对接价值 | 常见误区 |
| --- | --- | --- | --- |
| 集团总部 | 战略、资本、考核、制度、重大协同和部分集中采购 | 判断集团方向、获得业务归口和重大项目协调 | 以为所有产品都由总部采购、所有合同都由总部签。 |
| 二级专业公司 | 经营一个主业板块，管理下属生产或区域单位 | 通常是技术路线、投资计划和集采的重要决策层 | 只知道集团名，不知道真正控制业务的是哪家二级公司。 |
| 上市公司 | 独立法人和公众公司，有独立治理、披露和采购规则 | 业务和财务信息相对透明，常是重要经营平台 | 把股票简称与母集团名称互换，误判资产和合同主体。 |
| 区域公司或省级公司 | 在特定地区经营网络、项目或市场 | 适合区域项目落地、运维和本地采购 | 误以为它只是办事处，忽略其预算和法人权限。 |
| 项目公司/SPV | 为某一个电站、园区、工程或投资项目设立 | 往往是项目业主、合同签署或付款主体 | 只看集团品牌，没核实项目公司信用、资金来源和付款条件。 |
| 工厂、矿山、研究院、医院等使用单位 | 实际生产、使用系统并提出技术需求 | 最清楚痛点、数据和验收效果 | 使用者赞成不等于采购已批准，也不一定掌握预算。 |

### 18.2 “和央企合作”至少要核实五个名字

```text
集团品牌名称
实际需求单位全称
招标或采购人全称
合同签署法人全称
开票、收款或付款主体全称
```

这五个名称可能完全相同，也可能分属不同层级。对外宣传时也只能陈述真实关系，例如“向某集团下属某公司提供某项服务”，不能把一次子公司试点夸大为“与整个集团达成战略合作”。

## 十九、如何找到真正的采购方、业主和决策部门

### 19.1 一个项目至少有七种角色

```text
业务使用方：真正每天使用产品的人
需求提出方：把痛点写成项目需求的人
技术决策方：审查架构、性能、接口和技术路线的人
数据与安全方：审查数据、网络、保密和合规的人
预算方：把项目列入投资或费用计划的人
采购方：组织招标、询比或其他采购程序的人
合同与付款方：签合同、验收、开票和付款的法人
```

同一个部门可能承担多种角色，但不能预先假定。尤其是软件和AI项目，信息化部门赞成、业务部门不使用，或者业务部门想使用、安全部门不同意，项目都无法落地。

### 19.2 查找顺序

1. **从集团官网确认业务板块和组织层级**，先找到最可能的二级专业公司。
2. **查看集团及子公司的年度报告、社会责任报告和公开组织信息**，确认业务规模、地区和重点项目。
3. **查官方电子采购平台、招标公告和成交公告**，观察过去同类需求到底由哪个法人采购。
4. **阅读公告中的采购人、招标代理、项目编号、资格条件和联系人**，不要把招标代理误当项目业主。
5. **通过正式公开渠道联系业务或采购部门**，说明场景和可量化价值，请对方指向实际归口单位。
6. **会前核验企业全称和统一社会信用信息**，会后用会议纪要确认需求、负责人和下一步。

### 19.3 初次对接必问清单

- 这个需求服务哪个生产、经营或管理流程？现在怎样做，最大问题是什么？
- 谁是实际使用者，谁负责技术选型，谁拥有预算？
- 项目是集团统建、板块统建、区域自建，还是单个项目试点？
- 采购主体、合同主体、部署地点和最终验收单位分别是谁？
- 已有系统、设备、接口、数据格式和供应商是什么？
- 数据能否出域？需要本地部署、专有云还是集团云？
- 是否涉及商业秘密、个人信息、重要数据、关键信息基础设施或国家秘密？
- 验收看准确率、可用率、时延、节省工时、降低故障，还是财务收益？
- 预算属于资本性投资还是费用，预计在哪个采购周期启动？
- 供应商需要哪些资质、案例、信创适配、安全测评、质量体系或行业许可？

## 二十、电话、邮件和会议可以直接使用的话术

### 20.1 首次电话

> “您好，我们关注的是贵集团下属____板块的____场景。我们目前能解决的是____问题，已有指标或案例是____。想先确认该场景由集团总部统筹，还是由____二级公司或使用单位负责；如果不属于您部门，也请您指点正确的业务归口。”

这段话的重点不是展示“我们什么都能做”，而是让对方快速判断你找的行业、场景和层级是否正确。

### 20.2 首次邮件

```text
主题：关于“具体场景 + 具体价值”的合作沟通，例如：关于矿山设备视觉巡检试点的技术交流

您好：

我们了解到贵单位在____业务中存在/正在建设____场景。
我们提供____能力，针对的是____流程，可量化目标为____。
建议先以____范围做一次技术交流或小规模验证。

为避免找错归口，想确认：
1. 该需求的实际使用和技术牵头单位；
2. 当前系统、数据和部署边界；
3. 后续是否需进入正式采购或供应商准入流程。

附件仅包含与本场景直接相关的方案、指标和案例。
```

不要把一份几十页的通用公司简介当成合作方案。对方最先需要判断的是“你是否理解我的业务、能否量化价值、是否满足合规和交付条件”。

### 20.3 第一次会议的正确目标

第一次会议通常不是“当场签单”，而是完成四个确认：

1. 需求是否真实、是否有明确业务负责人；
2. 数据、系统和现场条件是否支持实施；
3. 价值能否转化为可验收指标；
4. 下一步由谁提供什么材料、何时完成。

会后纪要至少写清：问题定义、试点范围、双方负责人、数据边界、部署方式、验收指标、采购路径、时间节点和未决风险。

### 21.2 做AI项目时，模型指标只是其中一关

央企真正验收的通常不是“论文准确率高了几个点”，而是以下整套能力：

```text
业务问题是否值得解决
    -> 数据是否合法、足够且能持续获得
    -> 模型是否在真实环境稳定工作
    -> 能否接入现有设备和信息系统
    -> 网络、数据、保密和供应链是否合规
    -> 使用者是否愿意改变工作流程
    -> 指标能否被第三方复核并形成验收
    -> 上线后谁运维、谁承担错误处置责任
```

尤其是你熟悉的医学图像分割，论文中的Dice提升不等于医院或医药央企可以立即采购。还需要明确目标疾病和使用场景、数据来源与患者授权、医院伦理、跨中心验证、医生如何复核、是否构成医疗器械软件、部署环境、失败时的处置以及临床收益。科研合作、算法验证和临床产品采购是三条不同路径。

### 21.3 AI供应商准备材料

- 一页纸业务方案：现状、痛点、目标、输入输出、量化价值。
- 技术架构图：数据从哪里来、怎样处理、模型在哪里运行、结果回到哪个系统。
- 真实指标：数据范围、基线、置信区间、失败案例和适用边界，而不只展示最好结果。
- 部署清单：算力、操作系统、数据库、中间件、接口、网络区域及国产化适配。
- 安全合规说明：数据分类、访问控制、日志、脱敏、备份、模型和代码供应链。
- 项目计划：试点范围、双方投入、里程碑、验收指标、运维和退出方案。
- 知识产权安排：数据、标注、代码、模型权重、改进成果和论文专利分别归谁、怎样使用。

## 二十二、常见错误说法及更专业的改法

| 不准确说法 | 问题在哪里 | 更专业的说法 |
| --- | --- | --- |
| “中国只有99家央企。” | 混淆国资委名录与全部中央国有单位。 | “这是国务院国资委履行出资人职责的99户中央企业。” |
| “这家公司很大，所以成为央企。” | 央企是产权和出资监管关系，不是规模荣誉。 | “它由中央层面履行出资人职责，并列入国资委央企名录。” |
| “央企就是政府部门。” | 企业没有一般行政审批和执法权。 | “央企是依法经营的企业，同时承担特定国家功能。” |
| “国资委主管这个行业。” | 国资委主要履行出资人和国资监管职责。 | “行业政策监管由相应主管部门承担，国资委侧重国有资产出资监管。” |
| “国家电网发电。” | 混淆发电侧和电网侧。 | “国家电网主要输电、配电和调度；发电由发电企业完成。” |
| “中国船舶跑远洋运输。” | 混淆装备制造与运输运营。 | “中国船舶造船，中国远洋海运经营船队、港口和物流。” |
| “中国中铁生产高铁。” | 混淆施工、车辆和列控系统。 | “中铁、铁建修基础设施，中车造车辆，通号做列控信号。” |
| “参与建设就等于项目业主。” | 施工、设计、供货、投资和运营角色不同。 | “应明确它在该项目中是业主、设计、EPC、施工、设备商还是运营方。” |
| “和某央企达成合作。” | 可能只是某个下属公司的小范围试点。 | “与某集团下属某法人就某场景开展试点/签署合同。” |
| “集团领导同意就可以直接采购。” | 央企仍有预算、采购、合规和授权程序。 | “获得业务支持后，还需进入相应立项、采购、合同和验收流程。” |
| “有关系就能绕过招标。” | 带来合规、廉洁和项目无效风险。 | “通过公开、合规渠道参与采购，以能力、资质和交付结果竞争。” |
| “AI准确率高就能上线。” | 忽略业务、数据、系统、安全、责任和运维。 | “模型指标只是技术条件，还需完成真实场景验证和全流程合规验收。” |
| “对方给了数据就可以自由训练。” | 数据提供者未必拥有全部授权，数据用途也可能受限。 | “在书面协议中明确数据来源、处理目的、权限、保存期限和成果使用范围。” |
| “自主可控就是所有部件百分之百国产。” | 自主能力、供应链韧性与零部件来源是不同维度。 | “说明关键环节掌控能力、替代方案和供应链风险，不作绝对化表述。” |
| “总部在某地，所以业务只覆盖当地。” | 大量央企全国乃至全球经营。 | “总部所在地不等于经营范围，应看实际区域公司、基地和项目布局。” |

## 二十三、常用概念速查

| 概念 | 实际含义 | 沟通提醒 |
| --- | --- | --- |
| 央企 | 中央层面履行出资人职责的国有企业；本文特指国资委名录中的99户非金融中央企业 | 不要通过名称、规模或排名自行判断。 |
| 国企 | 国有资本具有控制或重要影响的企业总称，既包括央企，也包括地方国企 | 央企是国企的一部分，国企不都属于央企。 |
| 出资人职责 | 围绕国有资本权益进行产权、考核、收益、重大事项和负责人等管理 | 不等于替代行业监管部门管理企业每项业务。 |
| 主责主业 | 企业承担国家功能和开展经营的核心业务范围 | 多元集团也有主次，合作要尽量落在相应主业和专业板块。 |
| 一级央企/集团总部 | 国资委名录中直接列出的集团母公司及其总部管理层 | “一级”是常用表达，不代表所有总部都直接经营产品或采购项目。 |
| 二级公司 | 由集团直接控制的重要专业或区域企业 | 往往是产业投资、技术路线和集中采购的重要层级。 |
| 控股与参股 | 控股通常意味着能够实施控制；参股只是持有部分权益 | “投资了”不等于“旗下公司”，需看控制关系。 |
| 项目业主 | 发起、投资并对项目建设运营负主要责任的主体 | 业主、代建、设计、施工、监理和设备商不能混称。 |
| EPC | 设计、采购、施工总承包的一种项目组织方式 | EPC承包商负责合同范围内集成，但不因此成为项目资产所有者。 |
| 集中采购/框架采购 | 由较高层级统一选择供应商、价格或框架，再由下属单位执行 | 进入框架不等于必然产生订单，还要看具体调用规则。 |
| 招标代理 | 受采购人委托组织招标流程的专业机构 | 代理机构通常不是需求使用方、项目业主或最终付款方。 |
| 供应商准入 | 对资质、质量、安全、信用和交付能力进行预审或注册 | 进入供应商库不等于中标，也不代表集团内所有单位通用。 |

## 二十四、最后形成一套稳定判断法

遇到任何一家不熟悉的央企，不要先背历史和领导讲话，依次回答八个问题：

1. 它为什么是央企：谁在中央层面履行出资人职责？
2. 它在产业链哪里：资源、制造、网络、工程、运营、科研、服务还是资本？
3. 它主要卖什么：产品、运力、能源、工程、技术、资本还是公共平台服务？
4. 国家为什么需要它：安全、保供、基础网络、关键技术、应急还是资本优化？
5. 它与最容易混淆的企业有什么相对强项差异？
6. 它不是谁：政府监管部门、同名上市公司，还是另一个相似集团？
7. 真正需求和采购在哪一层：总部、二级公司、区域公司还是项目单位？
8. 合作怎样验收：业务指标、技术指标、安全合规、合同和付款主体分别是什么？

能够清楚回答这八个问题，就已经不是停留在“听过企业名字”的层次，而是具备了进行初步行业交流、项目识别和商务对接的基本框架。

## 二十五、官方依据与使用说明

### 25.1 本文直接核对的中央官方入口

- [国务院国资委：央企名录](http://www.sasac.gov.cn/n2588045/n27271785/n27271792/c14159097/content.html)
  用于核对本文99户企业的法定名称、顺序和官网入口。该页面会随新设、重组和更名更新，本文采用页面标注的2026年7月11日版本。
- [国务院国资委：机构职责](http://www.sasac.gov.cn/n2588020/index.html)
  用于理解国务院国资委受国务院授权履行出资人职责、监管中央所属非金融类企业国有资产等制度边界。

### 25.2 怎样理解本文的来源强度

- **名录、企业法定名称和监管口径**：以国务院国资委公开页面为准。
- **每家企业的主业边界**：结合国资委名录所列企业官网公开业务进行归纳；企业名称已尽可能链接到相应官网。
- **“国家层面的作用”与“对接边界”**：是基于产业链位置、公共功能和商务角色作出的解释性归纳，不是逐句引用企业宣传材料，也不代表国务院国资委对企业作出的法定分类。
- **军工和新设央企**：只采用公开、概括性信息。对中国雅江集团、中国资源循环集团、中国长安汽车集团等新设或新调整企业，不把规划能力写成已经投产的业绩。

### 25.3 时效提醒

央企名录不是永久不变。阅读本文时，若要用于正式材料、投标、求职或重要商务活动，应再次打开国资委央企名录和目标企业官网，核对最新名称、集团关系、业务板块及采购主体。行业归类可以帮助理解，但正式合同和对外声明必须以当时有效的工商登记、授权文件和采购文件为准。
