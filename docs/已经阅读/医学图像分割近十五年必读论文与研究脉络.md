# 医学图像分割近十五年必读论文与研究脉络

> 范围：约 2011—2026。下面按“改变了研究问题或方法范式”的论文筛选，不是单纯按排行榜罗列。作者较多的论文保留第一作者及 `et al.`，便于检索；正式下载时可用题名核对完整作者列表。

## 一、先看总脉络

```text
全卷积预测
  → U-Net 编码器—解码器与 skip connection
  → 3D 医学体数据、残差、注意力、嵌套跳跃连接
  → 自动配置与强基线（nnU-Net）
  → Transformer / 全局建模
  → 基础模型与提示分割（SAM、MedSAM）
  → 大规模预训练、通用分割、状态空间模型与高效 3D 网络
```

## 二、奠基论文：从像素级预测到 U-Net

| 年 | 论文 | 作者 | 必须理解的贡献 |
|---|---|---|---|
| 2015 | **Fully Convolutional Networks for Semantic Segmentation** | Jonathan Long, Evan Shelhamer, Trevor Darrell | 把分类 CNN 改造成端到端、全卷积的像素级预测框架；医学分割后续大量工作都继承这一范式。 |
| 2015 | **U-Net: Convolutional Networks for Biomedical Image Segmentation** | Olaf Ronneberger, Philipp Fischer, Thomas Brox | 医学图像分割最重要的编码器—解码器结构；对称上采样、skip connection、小样本训练和数据增强。 |
| 2015 | **Deeply-Supervised Nets** | Chen-Yu Lee, Saining Xie, Patrick Gallagher, Zhengyou Zhang, Zhuowen Tu | 深监督的代表性系统论文；理解辅助输出、梯度路径和中间层监督。 |
| 2016 | **V-Net: Fully Convolutional Neural Networks for Volumetric Medical Image Segmentation** | Fausto Milletari, Nassir Navab, Seyed-Ahmad Ahmadi | 3D 体数据分割、残差块和 Dice loss 的经典来源。 |
| 2016 | **3D U-Net: Learning Dense Volumetric Segmentation from Sparse Annotation** | Özgün Çiçek, Ahmed Abdulkadir, Silvio S. Lienkamp, Thomas Brox, Olaf Ronneberger | 将 U-Net 系统化扩展到 3D，并讨论稀疏标注下的体分割。 |
| 2016 | **Learning to Segment Medical Images in 3D with Weakly- and Semi-Supervised Learning** | Çiçek et al. | 早期 3D 弱监督、半监督思路，帮助理解标注成本问题。 |

## 十、建议的精读顺序

1. **FCN → U-Net → V-Net → 3D U-Net**：先理解像素级、2D/3D、skip connection 和 Dice。
2. **Attention U-Net → U-Net++ → UNet 3+**：理解注意力、多尺度融合、嵌套路径和深监督。
3. **nnU-Net**：建立数据划分、预处理、训练、后处理和公平基线意识。
4. **TransUNet → UNETR → Swin UNETR → nnFormer**：理解 CNN、Transformer、窗口注意力和 3D 全局建模的关系。
5. **损失与边界论文**：Generalized Dice、Lovász-Softmax、Boundary Loss、Topology-Preserving。
6. **SAM → MedSAM → TotalSegmentator**：理解基础模型、提示分割和通用解剖分割。
7. **MedNeXt → Mamba 系列 → EMCAD**：理解 Transformer 之后的卷积回归、状态空间模型和高效解码器路线。

## 十一、下载时的检索提醒

- 同一模型经常有 arXiv 预印本、会议版和期刊版；优先用**完整英文题名**检索。
- 医学分割论文的 Dice 数字不能跨数据集直接比较；下载后先看数据集、患者级划分、2D/3D 设置、预处理、推理后处理和评价指标。
- `nnU-Net` 应作为实验协议和强基线来读；不能只把它当成一个普通网络模块。
