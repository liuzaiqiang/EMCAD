## 二、3090 Ti 对整机提出的硬条件

RTX 3090 Ti 具有 24GB GDDR6X 显存、10752 个 CUDA 核心，参考整卡功耗约 450W，使用 PCIe 4.0。真正的配套硬条件是：

1. 电源必须有足够持续输出、瞬时功耗余量和合格供电线；
2. 机箱必须容纳具体非公版显卡的长度、厚度、高度和电源线；
3. 主显卡槽应由 CPU 直连，并以至少 PCIe 4.0 x16 正常运行；
4. 机箱必须持续排出约 450W 的显卡热量；
5. CPU、内存和 SSD 必须持续向 GPU 提供数据，避免 GPU 等待；
6. 房间供电应有可靠接地，不能使用劣质插排和松动插座。

PCIe 5.0 主板不会让 PCIe 4.0 的 3090 Ti 自动加速。新平台选择 PCIe 5.0 的意义是向后兼容和未来升级。

## 三、CPU 的选购条件

### 3.1 最低线

- 现代 8 核 16 线程以上；
- 支持 PCIe 4.0；
- 单核性能不能过旧；
- 能稳定运行 4-8 个 DataLoader worker；
- 平台可继续增加内存和 NVMe SSD。

### 3.2 为什么推荐 12 核

对单卡 EMCAD，12 核 24 线程是更合理的甜点位。Ryzen 9 9900X 可以同时承担：

- OpenCV、Pillow、Albumentations 数据增强；
- H5、NPZ、NIfTI 和 SimpleITK 数据读取；
- 4-12 个 DataLoader worker；
- 训练期间的验证、日志、IDE 和后台任务。

Ryzen 7 9700X 这类 8 核 CPU 也能带动 3090 Ti，并不会造成必然的严重瓶颈；只是大量预处理和多任务并行的余量较少。

### 3.3 何时才需要 16 核

Ryzen 9 9950X 更适合以下明确需求：

- 大量 3D DICOM/NIfTI 转换和重采样；
- 训练、验证、预处理和统计分析同时运行；
- CPU 为下一组实验持续生成缓存；
- 多进程交叉验证或传统图像处理占比较高。

仅为一张 3090 Ti，没有必要购买 Threadripper、至强或双路服务器平台。X3D 型号主要针对游戏，也不是单卡深度学习的优先投资方向。

## 四、主板的选购条件

推荐 AM5 平台的 B850 ATX。B650 也可以；X870/X870E 只有在需要更多高速 USB、M.2 和扩展通道时才值得购买。

可在京东比较下列同级系列：

- 微星 MAG B850 TOMAHAWK/MORTAR；
- 华硕 TUF GAMING B850-PLUS；
- 技嘉 B850 AORUS ELITE；
- 其他明确标注主显卡槽由 CPU 直连的中高规格 ATX 主板。

下单前必须阅读主板说明书并确认：

- 第一条全长显卡槽是否为 CPU 直连 x16；
- 安装多个 M.2 后，显卡槽是否被降为 x8；
- 至少 2-3 个带散热片的 M.2 插槽；
- 2.5GbE 网卡，使用 NAS 时可考虑 5GbE；
- BIOS Flashback 或免 CPU 刷 BIOS；
- 3.5-4 槽显卡安装后还有没有可用扩展槽；
- 计划购买的 48GB/64GB 单条内存是否进入主板 QVL。

## 五、内存的选购条件

| 使用情况 | 推荐容量 | 结论 |
|---|---:|---|
| EMCAD 2D 分割、单训练进程 | 64GB（2×32GB） | 合理最低线 |
| 2D 为主，同时预处理、浏览器、IDE、多数据集 | 96GB（2×48GB） | 最推荐 |
| 3D 体数据、内存缓存、多任务并行 | 128GB（优先 2×64GB） | 有明确需求再买 |

注意：系统内存不是显存。128GB RAM 不会把 3090 Ti 的 24GB 显存变成 48GB，也不会直接解决 CUDA OOM。

内存选择原则：

- 优先购买两条套装，不要一开始就插四条；
- AM5 平台优先 DDR5-6000、CL30-36、EXPO；
- 96GB 选 2×48GB，128GB 优先 2×64GB；
- 先以默认 JEDEC 频率完成稳定性测试，再开启 EXPO；
- 开启 EXPO 后重新进行长时间内存测试；
- 容量和稳定性优先于极限频率。

DDR5 的 On-die ECC 不等于工作站端到端 ECC，3090 Ti 显存也不是专业卡的 ECC 显存。

## 六、SSD 和数据存储

推荐两块 NVMe：

- **2TB 系统/项目盘**：系统、Conda、PyTorch、代码、权重、缓存、日志、checkpoint；
- **4TB 数据盘**：原始数据、固定划分、预处理文件、训练缓存、预测结果和实验输出。

选购条件：

- PCIe 4.0 x4；
- 系统盘优先 TLC 和较好的持续写入；
- 数据盘关注 TBW、保修和满盘性能；
- 不使用来历不明的拆机盘作为唯一科研数据盘；
- 数据至少有另一份独立备份；
- SSD、机械硬盘或 RAID 都不能替代备份。

系统盘可对比西数 SN850X、三星 990 PRO、Solidigm P44 Pro 同级产品。4TB 数据盘不要只看标称顺序读写，应同时看颗粒、缓存策略、保修和持续写入。

## 七、电源和供电线

推荐：1000W、ATX 3.0/3.1、80 Plus 金牌以上、一线厂商、7-10 年长质保。

可比较：

- 微星 MPG A1000G PCIE5；
- 海韵 FOCUS/Vertex 1000W；
- 振华 Leadex 1000W；
- 海盗船 RM1000x 同级型号。

不建议普通 850W 的原因不是一定带不动，而是科研训练属于长时间高负载，3090 Ti 还有瞬时功耗峰值。1000W 可提供更合理的负载区间和风扇噪声。

供电线必须做到：

- 确认显卡到底使用 16-pin、3×8-pin 还是原厂转接线；
- 使用显卡原配转接线或电源厂商明确兼容的原生线；
- 多个 8-pin 尽量使用多根独立线，不用一根线菊花链承担全部负载；
- 插头完全插到底，不能留缝；
- 接头附近不急弯，侧板不持续挤压；
- 不同品牌、型号的模组电源线绝对不能混用。

## 八、机箱和散热

必须先确认显卡完整型号，再购买机箱。向卖家索要：

- 长度、高度、厚度和占用槽位；
- 供电接口及方向；
- 是否为水冷版；
- 是否包含原厂支架、转接线和包装。

机箱“最大显卡长度”通常未扣除前置冷排和厚风扇。还要预留电源线弯曲空间。

最低风道：

- 前部或底部 2-3 个进风；
- 后部 1 个排风；
- 顶部 2-3 个排风；
- 进风口带滤网；
- 显卡下方没有封闭结构阻挡进风；
- 使用刚性显卡支架。

3090 Ti 会在机箱中持续释放约 450W 热量，室温会直接影响核心、热点和显存温度。夏季长时间训练还要考虑房间通风或空调。

9900X 可使用高端双塔风冷；机箱空间充足并重视满载温度时，可用可靠的 360mm 一体水冷。科研机不要为了灯效购买低端水冷。

## 十、3090 Ti 新卡、库存卡和二手卡验收

付款前索要：

- 完整型号、正反面高清照片和序列号；
- 原始发票或订单截图；
- 官方保修或店保条款；
- 是否维修、换显存、换核心或刷 BIOS；
- 是否挖矿或长期高温运行；
- 原厂线材、支架和包装；
- 明确的退换条件。

到货后在确认收货前完成：

1. 检查螺丝、封签、PCB、金手指、供电口、风扇和鳍片；
2. 用 GPU-Z 或 `nvidia-smi` 核对型号和 24GB 显存；
3. 检查 PCIe 链路、BIOS、频率和功耗是否异常；
4. 做 30-60 分钟图形压力测试；
5. 做覆盖大部分 24GB 的显存压力测试；
6. 做 PyTorch 前向、反向、优化器和 checkpoint 测试；
7. 跑 EMCAD 的短训练和验证；
8. 连续运行数小时，确认无黑屏、花屏、驱动重启或过热降频。

长期训练温度建议：核心尽量低于约 80℃，Hot Spot 尽量低于约 95℃，GDDR6X 显存结温尽量低于约 95-100℃。这些是工程目标，不是厂商的绝对保修界限。

## 十一、充分利用不等于始终跑满 450W

完成默认功耗基准后，可以测试 80%-90% Power Limit：

- 记录每 epoch 时间；
- 记录 GPU 利用率、功耗、温度和频率；
- 比较默认功耗和限功耗后的吞吐；
- 不盲目超频显存。

如果功耗下降 50-100W，而每 epoch 只慢几个百分点，长期训练通常更划算、更安静，也有利于显卡寿命。真正的充分利用是稳定、高占用和高吞吐，不是最大瞬时功耗。

## 十二、结合当前 EMCAD 仓库的实际判断

当前代码路径显示：

- `trainer.py` 的 Synapse DataLoader 使用 `num_workers=8`、`pin_memory=True`；
- `train_acdc.py` 默认 `num_workers=4`，还会读取 H5/NPZ；
- `train_polyp.py` 和相关 loader 通常默认 4 个 worker；
- Synapse/ACDC 常见输入为 224×224，息肉任务常见输入为 352×352；
- `requirements.txt` 包含 OpenCV、Albumentations、SimpleITK、Nibabel、H5py 等 CPU/I/O 依赖，但没有固定 PyTorch 版本。

所以：

- 12 核 CPU 已有充足余量；
- 64GB 能训练，96GB 更适合长期研究；
- NVMe 和 DataLoader 调优可能比从 12 核升级到 16 核更有效；
- 显存占用高不代表 GPU 利用率高；
- 独立训练机优先 Ubuntu 24.04 LTS，Windows 可作为备选。

## 十三、装机后的验收顺序

### 13.1 硬件验收

1. BIOS 使用默认值，不开超频；
2. 检查内存容量、双通道和频率；
3. 检查显卡在负载下的 PCIe 链路；
4. 检查 SSD SMART、温度和容量；
5. 分别测试 CPU、内存和 GPU；
6. 做 CPU+GPU 联合负载，确认电源、插座和散热；
7. 确认无 WHEA、重启、黑屏、花屏和降频。

### 13.2 CUDA 和 PyTorch 验收

```bash
nvidia-smi
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0)); print(torch.cuda.get_device_properties(0).total_memory / 1024**3)"
```

应看到 RTX 3090 Ti、约 24GB 显存，并且 `torch.cuda.is_available()` 为 `True`。

### 13.3 EMCAD 验收

正式跑长期实验前依次完成：

1. 一个 batch 前向；
2. 一个 batch 反向；
3. 10-50 个 iteration；
4. 一个完整 epoch；
5. 一次验证；
6. checkpoint 保存和恢复；
7. 连续 2-4 小时稳定性测试。

```bash
watch -n 1 nvidia-smi
```

重点观察 GPU-Util、显存、功耗、温度、频率和每 epoch 时间。GPU-Util 经常下降且 CPU/磁盘繁忙时，应先调整 DataLoader、数据格式和缓存；显存余量很大时，再逐步增加 batch size 或使用混合精度。

## 十四、最容易踩的坑

1. 先买机箱，后来发现显卡或供电线放不下；
2. 买杂牌 1000W，只看瓦数；
3. 16-pin 未完全插入或被侧板急弯；
4. 四条 DDR5 直接开启高频 EXPO，训练随机报错；
5. 只有一块 1TB SSD，迅速被数据和 checkpoint 写满；
6. 把系统内存误当成显存；
7. 只跑娱乐烤机，不做显存和 PyTorch 反向测试；
8. 只看显存占用，不看 GPU 利用率；
9. 为单卡购买昂贵服务器平台，却在电源和备份上省钱；
10. 未核对二手卡维修史、保修和退换条件。

## 十五、建议下单顺序

1. 确认 3090 Ti 完整型号、尺寸、接口和状态；
2. 根据显卡选择机箱和电源；
3. 确定 CPU 和主板平台；
4. 查主板通道共享和内存 QVL；
5. 购买两条套装内存；
6. 购买系统盘和数据盘；
7. 购买散热、风扇和显卡支架；
8. 在显卡退换期完成所有验收；
9. 安装正式科研环境；
10. 通过短训练后再开始长期实验。

## 十七、最终结论

不要为了“带满显卡”盲目购买最贵 CPU。对当前 EMCAD 项目，优先级应当是：

1. 3090 Ti 真实可靠且有明确退换/保修；
