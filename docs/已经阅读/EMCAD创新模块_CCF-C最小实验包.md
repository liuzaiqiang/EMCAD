# 基于 EMCAD 创新模块的 CCF-C 最小实验包

## 结论先行

不需要复做原始 EMCAD 的全部实验。原论文使用 12 个数据集、PVTv2-B0/B2、多个输入分辨率、串行/并行卷积等大量实验，是为了支撑它的广泛主张：`EMCAD 是一个可迁移到多任务、多个骨干且高效的通用解码器`。

你的论文应收缩为可检验的主张，例如：

> 在固定的 PVTv2-B2 EMCAD 上，所提出的 XXX 模块能缓解某一种明确的分割困难，并在不显著增加计算量的情况下提高结果。

对于这样的主张，正式投稿的推荐下限是：`1 个主数据集 + 1 个异质验证数据集 + 3 次随机种子 + 机制消融 + 复杂度 + 定性图`。当前资源极紧张时，可以先完成单数据集版本筛选，但它不应被视为可以直接投稿的最终证据。

## 先固定一套协议

在任何对比开始前，将以下内容写入每个实验目录的 `config.json` 或 `notes.md`：

| 项目 | 对 Synapse 的固定取值 |
|---|---|
| 基础模型 | PVTv2-B2 + 原始 EMCAD decoder |
| 新方法 | 同一个 PVTv2-B2 + EMCAD + 你的一个新模块 |
| 输入尺寸 | 训练、验证、最终测试都使用 `224 x 224` |
| 数据划分 | 所有方法使用同一病例级 train/val/test 列表 |
| 初始化 | 同一个预训练权重、相同的 `--no_pretrain` 取值 |
| 训练预算 | 相同 epoch、batch size、优化器、学习率和损失 |
| 随机性 | 每个最终配置使用同一组 3 个 seed，例如 2022/3407/2025 |
| checkpoint 规则 | 只按 validation Dice 选 `best.pth`，最终 test 只在模型冻结后运行 |

重要：当前项目的 `trainer.py` 会在每个 epoch 调用 `test_vol` 并据此保存 best 模型。若该列表就是最终测试集，不能把这组分数当作论文最终测试结果，因为测试集已经参与了模型选择。正式实验需要单独的 validation 列表；这一点比多跑一个网络更重要。

## 必须做：主表的核心实验

### M1. 当前环境下的 EMCAD 基线复现

使用当前服务器、当前数据划分和 `224 x 224` 重新跑原始 EMCAD。它不是为了复现原论文的绝对数值，而是得到与你的新模块在**同一训练协议**下可直接比较的基线。

报告：mean Dice、HD95、各器官 Dice、参数量、FLOPs、推理速度（可选）。

不要把论文中 `83.63` 直接当作你的基线结果。原论文报告的是五次运行均值，且使用其数据处理、硬件和训练实现；你的对照必须写你自己实际运行得到的数值。

### M2. EMCAD + 新模块

仅改动你声称的创新模块，其他设置与 M1 完全相同。最终主表至少应有：

| 方法 | Mean Dice | HD95 | Aorta | GB | KL | KR | Liver | PC | SP | SM | Params | FLOPs |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| EMCAD-B2（本地复现） |  |  |  |  |  |  |  |  |  |  |  |  |
| EMCAD-B2 + XXX（本文） |  |  |  |  |  |  |  |  |  |  |  |  |

Synapse 的论文级主指标应是病例级 mean Dice 和 HD95；只报告日志中的 best Dice 不够。`ΔDice` 同时要落在整体指标和主要困难器官上，不能只挑最好的一类展示。

### M3. 与外部方法的必要比较

至少给出 2--4 个与任务相关的公开方法结果，例如 EMCAD 论文已列出的 UNet、TransUNet、SwinUNet、PVT-CASCADE 或其他近期可复现方法。

原则如下：

1. 你的 EMCAD 本地复现和新方法必须自行运行，且协议一致。
2. 其他论文的公开数值可以放在表中，但必须注明 `reported`、引用原文，且确认使用同一公开划分和同一指标定义。
3. 若分割、预处理、输入尺寸或评价脚本不同，就不能把其分数表述成严格公平的直接对比；最稳妥的方式是只作为参考行，核心结论仍由 M1 vs M2 支撑。

不必为了凑表重新训练十几个旧模型。

## 必须做：针对新模块的消融

消融不是把 EMCAD 原论文的所有表格重跑一遍，而是回答一个问题：性能提升是否确实来自你声称的新机制？

对于当前这种“自适应多尺度/路由”方向，可以采用下面的最小 4 行设计。若你的具体模块不同，保留这个因果结构，替换名称即可。

| 编号 | 配置 | 要证明什么 |
|---|---|---|
| A0 | 原始 EMCAD | 性能基线 |
| A1 | EMCAD + 静态多尺度分支 | 证明“增加分支/参数”本身的收益 |
| A2 | EMCAD + 自适应权重，但去掉关键依据之一 | 证明不确定性或跨尺度差异各自的作用 |
| A3 | EMCAD + 完整新模块 | 证明完整设计优于简化版本 |

若模块确实只有一个不可拆分的设计，至少做 `A0 / 参数量匹配的普通卷积替代 / A3` 三行。所有行的训练时长、输入大小、损失、种子和 checkpoint 规则必须相同。

## 必须做：代价与可解释性证据

### M4. 复杂度表

即使你不再主打“高效”，也要报告参数量和 FLOPs。因为你的方法是插入 EMCAD decoder 的模块，审稿人会自然追问增益是否只是更大的模型带来的。

复杂度必须在同一个输入大小计算。对 Synapse 统一写 `224 x 224`，不能让基线按 224、你的模型按 256。

### M5. 定性结果

选择 3--5 个预先定义的典型病例，而不是只挑最漂亮的结果。每个病例至少并排展示：原图、GT、EMCAD、你的方法。优先展示新模块声称解决的问题，例如小目标、模糊边界或断裂区域。

如果模块输出路由权重、注意力图或不确定性图，可额外放一张解释图；它只能作为机制佐证，不能替代 M1--M4 的定量结果。

### M6. 稳定性

正式结果使用 3 个 seed，报告 `mean ± std`。单 seed 只用于快速筛选创新点，不用于得出“有效”的最终结论。

资源不足时的顺序是：

1. 先用 seed 2022 跑 A0--A3，淘汰明显无效的结构；
2. 仅保留最好的完整新模块和 A0；
3. 对这两项分别补跑另外两个 seed；
4. 再跑最终冻结的 test 集。

这比把所有候选模块都跑五次更可行。

## 推荐做：第二个数据集

为避免“只在 Synapse 有效”的质疑，推荐加入 ACDC 作为第二个数据集：它也是多类别医学图像分割，原 EMCAD 论文也使用 `224 x 224`，可在相同框架下验证。你无需再跑原论文的所有 10 个二分类数据集。

第二个数据集最小只做三项：

1. EMCAD-B2 本地基线；
2. EMCAD-B2 + 完整新模块；
3. Mean Dice、各类别 Dice、参数/FLOPs和 3-seed 均值标准差。

机制消融优先在主数据集 Synapse 完成，不必每个数据集全重复。

## 明确可以不做的原论文实验

| 原论文内容 | 本文是否必须重做 | 何时才需要 |
|---|---|---|
| 12 个数据集、6 类任务 | 否 | 你声称模块具有广泛跨模态泛化能力时 |
| PVTv2-B0 与 PVTv2-B2 都做 | 否 | 你声称对不同模型规模/骨干都有效时 |
| 224/256/384/512 分辨率扫描 | 否 | 你的创新点就是分辨率鲁棒性或多尺度输入策略时 |
| 并行 vs 串行深度卷积 | 否 | 你修改的是卷积分支排列方式时 |
| 原 EMCAD 的 CAB/SAB/LGAG/MSCB 全消融 | 否 | 你改动其中某一个模块，且需要重新证明该模块的设计选择时 |
| 预训练 vs 不预训练 | 否 | 你声称模块减少预训练依赖，或改变了编码器初始化时 |
| 深监督开关 | 否 | 你改动了 loss、输出头或深监督机制时 |

特别说明：Synapse 的正式训练和测试都保持 `224 x 224`。原论文表中同时出现 256，是它在报告 FLOPs 或其他数据集设置时的需要，不意味着你应把 224 训练的 checkpoint 用 256 进行正式测试。

## 两档实际目标

### 单数据集筛选版：不能直接作为最终投稿依据

Synapse 上完成 M1、M2、A0--A3、M4、M5；先用一个 seed。目的只是判断模块是否值得继续。

### CCF-C 级投稿的务实下限：推荐采用

1. Synapse：基线 vs 完整方法，3 seeds，机制消融，Dice/HD95/各器官，复杂度，定性图；
2. ACDC：基线 vs 完整方法，3 seeds，Dice/各类别，复杂度；
3. 2--4 个公开可比方法的引用式对照；
4. 方法图、模块公式/伪代码、失败案例和局限性；
5. 所有结果保留日志、命令、代码提交号、预测结果和随机种子。

这不是录用保证，但已构成一个窄而完整、可审查的论文证据链。比“更多模块 + 只有一个 best Dice”更有说服力。

## 学术边界

可以在 EMCAD 上替换或叠加模块，也可以结合已有思想形成新的、经过论证的设计；但不能复制别人的图表、虚构对比结果、把未复现实验写成已完成，或把简单拼接包装成未经验证的机制结论。论文的贡献应诚实限定为你实际验证过的范围。

## 与原论文的对应关系

本计划直接基于仓库根目录的原论文 PDF：

- 原文第 4 节在 12 个数据集上比较 PVT-EMCAD-B0/B2；
- 原文表 4--6 依次验证组件、MSDC 多尺度核和与 CASCADE decoder 的比较；
- 补充材料表 7--11 进一步验证串并行、LGAG、预训练、深监督和输入分辨率；

本文不需要复制其规模；只应重做与你的新主张有因果关系的实验。
