# 1×1 卷积可以做什么：原理、功能与 EMCAD 项目中的实际用途

> 本文回答：`1×1` 卷积到底在卷什么？为什么只有一个像素大小的卷积核仍然有用？它在 EMCAD 项目中具体实现了哪些功能？
>
> 本文依据当前项目的 [`lib/networks.py`](../lib/networks.py)、[`lib/decoders.py`](../lib/decoders.py) 和 [`lib/resnet.py`](../lib/resnet.py) 编写。为了避免 Markdown 阅读器不支持数学公式，全文使用普通文本和代码块表示计算。

---

## 1. 先给出最核心的答案

`1×1` 卷积最重要的能力不是观察周围空间，而是：

> 在每一个空间位置上，对全部输入通道进行一次可学习的线性组合，生成新的输出通道。

如果输入是：

```text
[B, C_in, H, W]
```

一个普通的、`stride=1`、`groups=1` 的 `1×1` 卷积可以把它变成：

```text
[B, C_out, H, W]
```

它通常不改变 `H、W`，但可以任意改变通道数：

```text
64  → 128：通道扩张
128 → 64 ：通道压缩
64  → 9  ：把内部特征转换为9个类别分数
1   → 3  ：把单通道输入适配为3通道输入
```

它还可以实现：

- 跨通道信息融合；
- 特征选择与重新编码；
- 网络瓶颈结构；
- 残差连接的通道对齐；
- 注意力权重生成；
- 最终类别 logits 输出；
- 低成本替代部分全连接操作。

最简洁的记忆方式是：

```text
3×3、5×5 卷积主要观察“周围空间有什么”。
普通 1×1 卷积主要学习“当前位置的各个通道应该怎样组合”。
```

### 1.1 `point-wise 1×1` 逐词到底是什么意思

`point-wise` 通常翻译为“逐点”或“点卷积”。这里的“点”指特征图上的一个空间位置 `(h,w)`，不是指只处理一个通道。

因此：

```text
point-wise 1×1 convolution
= 在每一个空间位置上，单独执行一次 1×1 卷积
= 不读取周围位置，但通常会读取当前位置的全部输入通道
```

假设特征图在某个位置 `(h,w)` 有 4 个通道：

```text
位置 (h,w) 的通道向量：
[x1, x2, x3, x4]
```

一个普通的 point-wise `1×1` 卷积若要输出 3 个通道，就会在这个位置进行三次不同的加权组合：

```text
y1 = w11*x1 + w12*x2 + w13*x3 + w14*x4 + b1
y2 = w21*x1 + w22*x2 + w23*x3 + w24*x4 + b2
y3 = w31*x1 + w32*x2 + w33*x3 + w34*x4 + b3
```

于是：

```text
[x1, x2, x3, x4] -> [y1, y2, y3]
       4个输入通道        3个输出通道
```

网络会在所有空间位置上重复这个操作，而且所有位置共享同一套权重：

```text
(0,0) 位置：4维通道向量 -> 同一个变换 W -> 3维通道向量
(0,1) 位置：4维通道向量 -> 同一个变换 W -> 3维通道向量
(0,2) 位置：4维通道向量 -> 同一个变换 W -> 3维通道向量
……
```

这就是 `point-wise` 的真正含义：**逐个空间位置处理通道向量**。它不是依次处理一个个通道，而是在每个位置通常一次读取全部通道。

### 1.2 为什么名字里既有 `point-wise`，又有 `1×1`

两个词是在从不同角度描述同一个常见操作：

- `1×1` 描述卷积核的空间尺寸：高为1、宽为1；
- `point-wise` 描述操作方式：在每个空间点独立完成通道变换。

对于普通的 `groups=1`、`stride=1` 的卷积，这两个表述通常指同一种层：

```python
nn.Conv2d(C_in, C_out, kernel_size=1, stride=1, groups=1)
```

它的权重不是只有一个数，而是：

```text
权重形状 = [C_out, C_in, 1, 1]
参数量   = C_in * C_out
```

例如 `64 -> 128` 的 point-wise `1×1` 卷积有：

```text
64 * 128 = 8,192 个卷积权重（忽略 bias）
```

这里的 `1×1` 只代表它不向上下左右扩展；在通道方向上，它仍然可以连接全部64个输入通道。

### 1.3 一个最直观的彩色像素例子

一张 RGB 图像的一个像素可以写成：

```text
[R, G, B]
```

一个 `3 -> 2` 的 point-wise `1×1` 卷积，可以在每个像素位置生成两个新特征：

```text
特征1 = 0.6R + 0.3G + 0.1B
特征2 = -0.2R + 0.8G + 0.4B
```

它对整张图的每个像素使用同样的两套系数。它没有查看相邻像素，但把原来的 RGB 三个通道重新解释成了两个新的特征通道。训练时，这些系数不是人工指定的，而是通过反向传播学习出来的。

### 1.4 `point-wise 1×1` 和 `depth-wise 1×1` 不是一回事

这是阅读 EMCAD 时最容易混淆的地方。

普通 point-wise `1×1` 卷积通常是：

```python
nn.Conv2d(C_in, C_out, kernel_size=1, groups=1)
```

它可以跨通道加权，因此能做通道融合、扩张、压缩和投影。

而 `1×1 depth-wise` 卷积通常是：

```python
nn.Conv2d(C, C, kernel_size=1, groups=C)
```

它把每个通道单独处理：

```text
y1 = w1*x1
y2 = w2*x2
……
yC = wC*xC
```

不同通道不能在这一步相互组合。因此要同时检查两个属性：

| 检查项 | 回答的问题 |
| --- | --- |
| `kernel_size=1` | 空间上是不是只看当前位置？ |
| `groups=1` 或 `groups=C` | 通道之间能不能彼此混合？ |

在 EMCAD 的 `MSDC` 中，`1×1` 分支设置了 `groups=C`，所以它是 `1×1 depth-wise` 分支；在 `MSCB.pconv1`、`MSCB.pconv2` 和 `EUCB.pwc` 中，`1×1` 卷积没有设置深度分组，属于普通 point-wise 卷积，真正承担跨通道融合。

### 1.5 为什么它在轻量网络中反复出现

深度卷积很擅长以较低成本提取每个通道内部的空间模式，但它不会混合通道。point-wise `1×1` 卷积正好补上这一缺口：

```text
depth-wise 3×3：每个通道分别观察周围空间
        ↓
point-wise 1×1：在当前位置混合所有通道
```

它还可以便宜地改变通道宽度：

```text
MSCB.pconv1：C -> 2C，先扩张通道
MSCB.pconv2：2C -> C，融合多尺度结果并投影回来
EUCB.pwc：C_in -> C_out，上采样后对齐下一层通道
out_head：C -> num_classes，把内部特征翻译成每像素类别 logits
```

所以它反复出现并不是重复做同一件事，而是同一种“逐位置通道变换工具”在不同位置承担不同任务。

## 2. 一个 1×1 卷积核到底长什么样

### 2.1 不要只看到“1×1”

很多初学者看到 `1×1`，会误以为卷积核只有一个数字。

这只在输入通道数为 1 时成立。

对于输入：

```text
[B, C_in, H, W]
```

一个普通 `1×1` 卷积的单个输出卷积核实际上具有：

```text
[C_in, 1, 1]
```

也就是说，它在空间方向确实只覆盖当前位置，但在通道方向会同时读取全部 `C_in` 个输入通道。

如果需要产生 `C_out` 个输出通道，就需要 `C_out` 组这样的权重。因此完整权重张量形状是：

```text
[C_out, C_in, 1, 1]
```

### 2.2 一个具体例子

假设某个空间位置有 4 个输入通道：

```text
x = [x1, x2, x3, x4]
```

现在希望用 `1×1` 卷积产生 3 个输出通道。

第一个输出通道可以学习：

```text
y1 = w11*x1 + w12*x2 + w13*x3 + w14*x4 + b1
```

第二个输出通道可以学习：

```text
y2 = w21*x1 + w22*x2 + w23*x3 + w24*x4 + b2
```

第三个输出通道可以学习：

```text
y3 = w31*x1 + w32*x2 + w33*x3 + w34*x4 + b3
```

因此：

```text
[x1,x2,x3,x4]
        ↓ 可学习线性组合
[y1,y2,y3]
```

网络会在图像的每一个 `(h,w)` 位置执行同样的变换，并且所有位置共享同一组权重。

### 2.3 用矩阵理解

对于某个像素位置，可以把输入通道写成一个列向量：

```text
x(h,w) = [x1, x2, ..., x_Cin]
```

`1×1` 卷积相当于：

```text
y(h,w) = W × x(h,w) + b
```

其中：

```text
W.shape = [C_out, C_in]
b.shape = [C_out]
```

因此，普通 `1×1` 卷积可以看成：

> 在每个空间位置上重复使用同一个全连接层。

它和普通全连接层的主要区别是：

- 全连接层通常会先展平整个输入，可能破坏空间布局；
- `1×1` 卷积保留 `H、W`，只在每个位置处理通道向量；
- 所有空间位置共享同一组权重，因此参数量更可控。

## 3. 1×1 卷积会不会观察周围像素

### 3.1 单独使用时不会

普通 `stride=1` 的 `1×1` 卷积在计算位置 `(h,w)` 的输出时，只读取输入的同一个位置 `(h,w)`：

```text
输出位置 (h,w)
只读取输入位置 (h,w) 的所有通道
```

它不会直接读取：

```text
(h-1,w)、(h+1,w)、(h,w-1)、(h,w+1)
```

因此单独的 `1×1` 卷积不能直接发现一条横跨多个像素的边缘，也不能独立判断一个较大区域的形状。

### 3.2 为什么输出头仍然可以完成像素分类

虽然输出头的 `1×1` 卷积只看当前位置，但输入给它的不是原始像素，而是经过编码器、注意力、卷积、skip 融合之后的高级特征。

例如 `d1[h,w]` 已经包含：

- 编码器产生的上下文语义；
- 多层卷积带来的较大感受野；
- skip connection 带来的边界和定位信息；
- CAB 和 SAB 筛选后的响应；
- 多尺度卷积提取的不同范围局部信息。

因此最终 `1×1` 输出头虽然只读取 `d1` 的当前位置，但这个位置的通道向量本身已经汇总了周围区域的信息。

可以理解为：

```text
前面的网络负责收集和加工上下文。
最后的 1×1 卷积负责根据这些特征作类别判定。
```

### 3.3 例外：stride 大于 1

`1×1` 卷积也可以设置 `stride=2`：

```python
nn.Conv2d(C_in, C_out, kernel_size=1, stride=2)
```

这时它会在空间上每隔一个位置取样，从而降低 `H、W`。

所以严格来说：

```text
1×1 卷积是否改变 H/W，取决于 stride、padding 等参数。
```

但 EMCAD 中大多数 `1×1` 卷积使用 `stride=1`，主要负责通道处理而不是空间缩放。

## 4. 功能一：改变通道数量

这是 `1×1` 卷积最直观的用途。

### 4.1 通道扩张

例如：

```text
[B,64,H,W]
    ↓ 1×1 Conv，64→128
[B,128,H,W]
```

空间尺寸不变，但网络获得了更宽的中间表示空间。

扩张通道的意义不是简单复制 64 份特征，而是学习 128 种不同的通道组合。

### 4.2 通道压缩

例如：

```text
[B,384,H,W]
    ↓ 1×1 Conv，384→64
[B,64,H,W]
```

这可以：

- 降低后续计算量；
- 把多个来源的特征融合成较少通道；
- 建立瓶颈结构；
- 让张量满足后续模块的接口要求。

### 4.3 通道数不变也有意义

即使：

```text
C_in = C_out = 64
```

`1×1` 卷积也不是无操作。它仍然可以学习一个 `64×64` 的通道变换矩阵，重新组合全部输入通道。

---

## 5. 功能二：跨通道融合

假设某个位置有三个内部通道：

```text
通道0：边缘响应
通道1：区域内部响应
通道2：某种纹理响应
```

一个输出通道可以学习：

```text
新通道 = 0.7×边缘 + 1.2×区域内部 - 0.4×纹理
```

另一个输出通道可以学习：

```text
新通道 = -0.2×边缘 + 0.6×区域内部 + 0.9×纹理
```

因此，`1×1` 卷积可以把已有特征重新编码成更适合下一阶段的新特征。

这也是为什么 depth-wise convolution 经常和 point-wise `1×1` convolution 配合：

```text
depth-wise convolution：每个通道独立做空间处理
point-wise 1×1 convolution：在通道之间交换和融合信息
```

## 6. 功能三：低成本建立瓶颈结构

如果直接对很多通道使用 `3×3` 卷积，参数和计算量会很大。

假设输入输出都是 256 通道。

直接使用一个 `3×3` 卷积，权重数约为：

```text
256 × 256 × 3 × 3
= 589824
```

如果先用 `1×1` 把 256 通道压缩到 64，再做 `3×3`，最后用 `1×1` 恢复到 256：

```text
第一层 1×1：256 × 64       = 16384
中间层 3×3：64 × 64 × 9   = 36864
最后层 1×1：64 × 256      = 16384
总计                         = 69632
```

参数量从约 59 万下降到约 7 万。

这就是瓶颈结构的重要价值：

```text
先用便宜的 1×1 卷积调整通道宽度，
再在较少通道上执行昂贵的空间卷积，
最后用 1×1 卷积恢复所需通道。
```

## 7. EMCAD 中的用途一：把单通道医学图像适配成三通道

项目支持单通道灰度医学图像，但 PVTv2 和 ResNet 等 ImageNet 编码器通常接收 3 通道输入。

[`lib/networks.py`](../lib/networks.py#L73) 中使用：

```python
nn.Conv2d(1, 3, kernel_size=1)
```

形状变化：

```text
[B,1,H,W]
    ↓ 1×1 Conv，1→3
[B,3,H,W]
```

对于原始灰度值 `x(h,w)`，三个输出通道分别类似于：

```text
y1(h,w) = w1*x(h,w) + b1
y2(h,w) = w2*x(h,w) + b2
y3(h,w) = w3*x(h,w) + b3
```

后面还有 BatchNorm 和 ReLU，进一步调整三个通道的数值分布。

需要注意：

> 这个 `1→3` 卷积不会把灰度 CT 变成真正有颜色信息的 RGB 图像。

它只是生成三个可学习的特征通道，使单通道输入能够接入原本为 3 通道输入设计的编码器。

它比简单复制三次灰度图多了一点可学习能力：三个输出通道可以具有不同的缩放、偏置和归一化结果。

## 8. EMCAD 中的用途二：MSCB 内部进行通道扩张

MSCB 中的第一个 point-wise convolution 位于 [`lib/decoders.py`](../lib/decoders.py#L399)：

```python
self.pconv1 = nn.Sequential(
    nn.Conv2d(self.in_channels, self.ex_channels, 1, 1, 0, bias=False),
    nn.BatchNorm2d(self.ex_channels),
    act_layer(self.activation, inplace=True)
)
```

默认：

```text
ex_channels = in_channels × expansion_factor
expansion_factor = 2
```

例如：

```text
[B,64,56,56]
    ↓ 1×1 Conv，64→128
[B,128,56,56]
```

为什么先扩张？

因为接下来的多尺度 depth-wise convolution 非常便宜。先把通道扩张，可以给网络更多中间特征空间，再使用便宜的深度卷积分别处理这些通道。

这种结构与 MobileNetV2 的 inverted residual 思想类似：

```text
窄输入 → 扩张到较宽空间 → 低成本空间建模 → 投影回窄输出
```

## 9. EMCAD 中的用途三：MSCB 内部压缩并融合多尺度结果

多尺度深度卷积完成后，MSCB 使用第二个 `1×1` 卷积：

```python
self.pconv2 = nn.Sequential(
    nn.Conv2d(self.combined_channels, self.out_channels, 1, 1, 0, bias=False),
    nn.BatchNorm2d(self.out_channels),
)
```

见 [`lib/decoders.py`](../lib/decoders.py#L423)。

默认 `add=True` 时：

```text
[B,2C,H,W]
    ↓ 1×1 Conv
[B,C,H,W]
```

如果使用多尺度 concat，例如三个尺度各有 `2C` 通道：

```text
[B,6C,H,W]
    ↓ 1×1 Conv
[B,C,H,W]
```

这层同时完成：

1. 跨通道融合；
2. 多尺度信息整合；
3. 通道压缩；
4. 把输出通道调整为残差分支需要的 `C`。

所以它不是简单“删掉多余通道”，而是学习怎样把大量中间特征重新组合成目标通道。

## 10. EMCAD 中的用途四：残差连接前对齐通道

残差相加要求两边形状完全一致：

```text
x.shape == F(x).shape
```

如果输入为：

```text
x = [B,64,H,W]
```

主分支输出为：

```text
F(x) = [B,128,H,W]
```

就不能直接执行：

```text
x + F(x)
```

因为通道数不同。

MSCB 为这种情况准备了：

```python
self.conv1x1 = nn.Conv2d(
    self.in_channels,
    self.out_channels,
    1, 1, 0,
    bias=False
)
```

见 [`lib/decoders.py`](../lib/decoders.py#L435)。

它把捷径分支从：

```text
[B,64,H,W]
```

投影为：

```text
[B,128,H,W]
```

这样才能与主分支逐元素相加。

当前标准 EMCAD 的四级 MSCB 通常 `C_in=C_out`，所以不一定实际创建这层；但这个类保留了处理通道不一致的能力。

## 11. EMCAD 中的用途五：EUCB 上采样后的通道投影

EUCB 先把空间尺寸扩大 2 倍，再使用深度卷积处理空间信息，最后用 `1×1` 卷积改变通道：

```python
nn.Conv2d(
    self.in_channels,
    self.out_channels,
    kernel_size=1,
    stride=1,
    padding=0,
    bias=True
)
```

见 [`lib/decoders.py`](../lib/decoders.py#L578)。

以 PVTv2-B2 为例：

```text
d4：[B,512, 7, 7]
    ↓ 上采样
    [B,512,14,14]
    ↓ depth-wise 3×3
    [B,512,14,14]
    ↓ point-wise 1×1，512→320
d3候选：[B,320,14,14]
```

为什么必须把 512 改成 320？

因为对应的编码器 skip `x3` 是：

```text
[B,320,14,14]
```

后面 LGAG 和逐元素相加都要求两路通道能够对齐。

后续两个 EUCB 类似：

```text
320 → 128
128 → 64
```

因此 EUCB 中的 `1×1` 卷积负责：

```text
在空间上采样之后，把解码主路投影到下一层需要的通道接口。
```

## 12. EMCAD 中的用途六：LGAG 生成单通道空间门控 logits

LGAG 先把解码 gating 特征和编码器 skip 特征投影到内部通道并融合，然后使用：

```python
nn.Conv2d(
    F_int,
    1,
    kernel_size=1,
    stride=1,
    padding=0,
    bias=True
)
```

见 [`lib/decoders.py`](../lib/decoders.py#L657)。

形状变化：

```text
[B,F_int,H,W]
    ↓ 1×1 Conv，F_int→1
[B,1,H,W]
```

这个 `1×1` 卷积在每个空间位置上读取全部 `F_int` 个内部通道，并学习怎样将它们汇总成一个门控分数。

随后经过 BatchNorm 和 Sigmoid：

```text
[B,1,H,W] logits
    ↓ Sigmoid
[B,1,H,W] gate weights
```

最后乘到编码器 skip 上：

```text
gated_skip = skip × gate_weights
```

因此这里的 `1×1` 卷积负责：

> 把多个融合特征通道压成每个空间位置一个注意力门控分数。

注意，它本身只看当前位置的 `F_int` 个通道。但在它之前，`W_g` 和 `W_x` 已经通过 `3×3` 等卷积融入了邻域信息，所以最终门控分数并不缺少空间上下文。

## 13. EMCAD 中的用途七：CAB 中模拟通道 MLP

CAB 对输入做全局平均池化或最大池化后，空间尺寸已经变成 `1×1`：

```text
[B,C,H,W]
    ↓ global pooling
[B,C,1,1]
```

随后使用两层 `1×1` 卷积：

```python
self.fc1 = nn.Conv2d(
    self.in_channels,
    self.reduced_channels,
    1,
    bias=False
)

self.fc2 = nn.Conv2d(
    self.reduced_channels,
    self.out_channels,
    1,
    bias=False
)
```

见 [`lib/decoders.py`](../lib/decoders.py#L746)。

例如 `C=64`、`ratio=16`：

```text
[B,64,1,1]
    ↓ fc1：64→4
[B, 4,1,1]
    ↓ activation
    ↓ fc2：4→64
[B,64,1,1]
```

因为空间已经是 `1×1`，这里的 `1×1 Conv2d` 在功能上相当于一个作用于通道向量的全连接层。

它完成：

- 压缩通道，降低参数量；
- 学习通道之间的依赖；
- 再恢复为 `C` 个通道权重 logits；
- 经过 Sigmoid 后形成 `[B,C,1,1]` 通道注意力。

## 14. EMCAD 中的用途八：把解码特征转换成类别 logits

这是 `1×1` 卷积最接近最终分割图的一项用途。

[`lib/networks.py`](../lib/networks.py#L211) 中定义了四个输出头：

```python
self.out_head4 = nn.Conv2d(channels[0], num_classes, 1)
self.out_head3 = nn.Conv2d(channels[1], num_classes, 1)
self.out_head2 = nn.Conv2d(channels[2], num_classes, 1)
self.out_head1 = nn.Conv2d(channels[3], num_classes, 1)
```

以 Synapse 9 类分割的 `d1` 为例：

```text
d1 = [B,64,56,56]
```

每个空间位置都有一个 64 维特征向量：

```text
d1[b,:,h,w] = 64维内部特征
```

输出头相当于在每个位置运行一个 `64→9` 的线性分类器：

```text
[B,64,56,56]
    ↓ 1×1 Conv，64→9
[B, 9,56,56]
```

9 个输出通道分别表示该位置对 9 个类别的原始支持分数，即 logits。

可以把每个类别通道理解成：

```text
类别k的logit
= 该类别对64个内部特征的加权求和 + 偏置
```

例如类别“肝脏”可能学会：

```text
强烈使用某些区域语义通道
适度使用某些边界通道
压低与骨骼或背景纹理相关的通道
```

这一步建立了明确的类别通道：

```text
内部64通道：分布式特征，没有固定类别含义
输出9通道：明确对应背景和8个前景类别
```

之后再上采样到原图尺寸，并通过 Softmax、argmax 得到最终分割标签图。

## 15. ResNet Bottleneck 中的 1×1 卷积

ResNet50、ResNet101、ResNet152 使用 Bottleneck 残差块，定义位于 [`lib/resnet.py`](../lib/resnet.py#L140)。

主分支结构是：

```text
1×1 Conv：压缩/整理通道
    ↓
3×3 Conv：进行空间建模
    ↓
1×1 Conv：扩张到最终输出通道
```

代码中的第一层：

```python
self.conv1 = nn.Conv2d(
    inplanes,
    planes,
    kernel_size=1,
    bias=False
)
```

见 [`lib/resnet.py`](../lib/resnet.py#L156)。

它把输入通道映射到较窄的 `planes`。

最后一层：

```python
self.conv3 = nn.Conv2d(
    planes,
    planes * Bottleneck.expansion,
    kernel_size=1,
    bias=False
)
```

见 [`lib/resnet.py`](../lib/resnet.py#L166)。

其中：

```text
Bottleneck.expansion = 4
```

例如：

```text
256通道输入
    ↓ 1×1，256→64
64通道
    ↓ 3×3，64→64
64通道
    ↓ 1×1，64→256
256通道输出
```

这样昂贵的 `3×3` 卷积只在 64 通道上运行，而不是在 256 通道上运行，显著减少计算。

## 16. ResNet 投影捷径中的 1×1 卷积

当残差主分支改变通道数或使用 `stride=2` 改变空间尺寸时，原输入不能直接与主分支相加。

ResNet 的 `_make_layer` 会创建投影捷径：

```python
nn.Conv2d(
    self.inplanes,
    planes * block.expansion,
    kernel_size=1,
    stride=stride,
    bias=False
)
```

对应 [`lib/resnet.py`](../lib/resnet.py#L310)。

它可能同时完成：

```text
通道对齐：64→128、256→512 等
空间对齐：stride=2 时 H/W 减半
```

从而保证：

```text
主分支输出 shape == 捷径分支输出 shape
```

然后才能逐元素相加。

## 17. 1×1 卷积和 3×3 卷积的区别

| 对比项 | 普通 1×1 卷积 | 普通 3×3 卷积 |
|---|---|---|
| 空间观察范围 | 当前位置 | 当前点及周围8个位置 |
| 是否可混合通道 | 可以，`groups=1` 时读取全部输入通道 | 可以 |
| 是否可改变通道数 | 可以 | 可以 |
| `stride=1` 时是否改变 H/W | 通常不改变 | padding=1 时不改变 |
| 参数量 | `C_in×C_out` | `9×C_in×C_out` |
| 常见用途 | 通道变换、瓶颈、分类头、注意力 | 空间结构、纹理、边缘、邻域关系 |

二者不是竞争关系，而是互补关系：

```text
1×1：擅长通道维度的信息融合。
3×3：擅长空间维度的信息提取。
```

很多轻量网络都会组合：

```text
1×1 point-wise convolution
        +
3×3 depth-wise convolution
```

以较低成本同时实现通道混合和空间建模。

## 18. 重要区别：普通 1×1 卷积与 1×1 深度卷积

这是阅读 EMCAD 时很容易忽略的细节。

### 18.1 普通 1×1 卷积

```python
nn.Conv2d(C_in, C_out, kernel_size=1, groups=1)
```

每个输出通道都会读取全部输入通道，因此能够跨通道融合。

权重形状：

```text
[C_out,C_in,1,1]
```

### 18.2 1×1 深度卷积

MSDC 中的卷积统一设置：

```python
groups = in_channels
```

当 `kernel_size=1` 时，它实际上是：

```python
nn.Conv2d(C, C, kernel_size=1, groups=C)
```

每个输出通道只能读取对应的一个输入通道：

```text
y1 = w1*x1
y2 = w2*x2
...
yC = wC*xC
```

它不能执行：

```text
y1 = w11*x1 + w12*x2 + ... + w1C*xC
```

所以 MSDC 的 `1×1` depth-wise 分支更接近：

```text
对每个通道进行独立的可学习缩放和后续 BN/激活
```

真正的跨通道融合发生在 MSCB 前后的普通 point-wise `1×1` 卷积中。

### 18.3 对照表

| 类型 | groups | 能否混合不同输入通道 | 参数量 |
|---|---:|---|---:|
| 普通 `1×1` 卷积 | 1 | 能 | `C_in×C_out` |
| `1×1` 深度卷积 | `C` | 不能 | 约 `C` |

因此，不能看到 `kernel_size=1` 就自动判断它一定在混合通道，还必须检查 `groups`。

## 19. 1×1 卷积如何实现非线性特征变换

单独一个 `1×1` 卷积仍然是线性变换。

如果连续使用两个 `1×1` 卷积，中间没有激活函数：

```text
1×1 Conv A → 1×1 Conv B
```

整体仍然可以合并成一个线性变换，表达能力有限。

如果中间加入 ReLU、ReLU6、GELU 等激活：

```text
1×1 Conv → BN → ReLU → 1×1 Conv
```

就形成非线性通道网络，可以学习更复杂的通道组合关系。

例如 MSCB 的 `pconv1` 后有 BN 和激活，而 CAB 的 `fc1` 与 `fc2` 之间也有激活函数。

这也是 Network in Network 思想中 `1×1` 卷积的重要用途：在不改变空间尺寸的情况下，为每个位置建立一个共享的小型神经网络。

---

## 20. 参数量与计算量为什么低

假设输入输出通道都是 128。

### 20.1 1×1 卷积

权重数量：

```text
128 × 128 × 1 × 1
= 16384
```

### 20.2 3×3 卷积

权重数量：

```text
128 × 128 × 3 × 3
= 147456
```

`3×3` 是 `1×1` 参数量的 9 倍。

因此，如果后面要执行昂贵的空间卷积，可以先用 `1×1` 压缩通道：

```text
128 → 32 → 执行3×3 → 再恢复到128
```

这会显著降低参数量和乘加计算量。

但也不能无限压缩。如果中间通道太少，可能造成信息瓶颈，损失表达能力。因此压缩比例和扩张比例通常需要通过设计或实验选择。

---

## 21. 它能不能做“特征选择”

可以，但要准确理解“选择”的含义。

假设某个输出通道学习到：

```text
y = 1.2*x1 + 0.01*x2 - 0.8*x3 + 0.0*x4
```

那么：

- `x1` 被强烈使用；
- `x2` 影响很小；
- `x3` 被反向使用；
- `x4` 基本被忽略。

因此 `1×1` 卷积可以通过学习权重，选择、抑制和组合输入通道。

不过它通常不是硬选择，不会真的删除某个输入通道，而是使用连续权重进行软组合。

如果后面再接 Sigmoid，就可以显式形成 0～1 的软门控权重，例如 CAB 和 LGAG。

---

## 22. 它能不能代替全连接层

在某些场景下可以。

### 22.1 空间尺寸为 1×1 时

输入：

```text
[B,C,1,1]
```

使用：

```python
nn.Conv2d(C_in, C_out, kernel_size=1)
```

在数值功能上等价于：

```python
nn.Linear(C_in, C_out)
```

只是在张量布局上继续保持 NCHW。

CAB 就属于这种情况。

### 22.2 空间尺寸大于 1×1 时

它相当于把同一个全连接层应用到每一个空间位置：

```text
for each (h,w):
    y[h,w] = Linear(x[h,w])
```

这样既保持空间结构，又共享参数。

---

## 23. 它不能做什么

了解限制和了解功能同样重要。

### 23.1 单独不能直接观察邻居

它不会直接读取周围像素，因此不能单独提取 `3×3` 或 `5×5` 范围的空间形状。

### 23.2 不会自动恢复空间分辨率

默认 `stride=1` 时：

```text
H、W 不变
```

它不能把 `14×14` 自动变成 `28×28`。EMCAD 中负责上采样的是 `nn.Upsample` 和 `F.interpolate`。

### 23.3 不能凭空创造丢失的信息

把 64 通道扩张到 128 通道，并不意味着信息量自动翻倍。新通道只是原有通道的不同可学习组合，真正的新表达能力来自后续非线性、空间卷积和多层网络组合。

### 23.4 不等于注意力

`1×1` 卷积只是一个可学习通道变换。只有当它被放进特定结构，例如：

```text
池化 → 1×1 → 激活 → 1×1 → Sigmoid
```

或者：

```text
融合特征 → 1×1 → Sigmoid
```

才会成为注意力权重生成过程的一部分。

## 24. EMCAD 中一条完整的数据流示例

以 PVTv2-B2、`224×224` 输入和 Synapse 9 类分割为例。

### 24.1 灰度输入适配

```text
[B,1,224,224]
    ↓ 1×1 Conv，1→3
[B,3,224,224]
```

### 24.2 编码器输出

```text
x1：[B, 64,56,56]
x2：[B,128,28,28]
x3：[B,320,14,14]
x4：[B,512, 7, 7]
```

### 24.3 d4 的 MSCB

```text
d4输入：[B,512,7,7]
    ↓ pconv1：1×1，512→1024
[B,1024,7,7]
    ↓ 多尺度 depth-wise convolution
[B,1024,7,7]
    ↓ pconv2：1×1，1024→512
[B,512,7,7]
    ↓ 残差相加
d4：[B,512,7,7]
```

### 24.4 EUCB3 通道投影

```text
d4：[B,512,7,7]
    ↓ 二倍上采样
[B,512,14,14]
    ↓ depth-wise 3×3
[B,512,14,14]
    ↓ point-wise 1×1，512→320
d3候选：[B,320,14,14]
```

### 24.5 LGAG 生成门控图

```text
融合内部特征：[B,160,14,14]
    ↓ 1×1 Conv，160→1
[B,1,14,14] gate logits
    ↓ Sigmoid
[B,1,14,14] gate weights
```

### 24.6 CAB 生成通道权重

```text
d3：[B,320,14,14]
    ↓ 全局池化
[B,320,1,1]
    ↓ 1×1，320→20
[B,20,1,1]
    ↓ 激活
    ↓ 1×1，20→320
[B,320,1,1]
    ↓ Sigmoid
[B,320,1,1] channel weights
```

### 24.7 最终输出头

最高分辨率解码特征：

```text
d1：[B,64,56,56]
```

类别输出头：

```text
[B,64,56,56]
    ↓ 1×1 Conv，64→9
[B, 9,56,56] logits
    ↓ 双线性插值4倍
[B, 9,224,224]
    ↓ Softmax + argmax
[B,224,224] 最终类别图
```

这条链路展示了同一种 `1×1` 卷积在不同位置承担完全不同的语义职责。

## 25. 常见误解

### 误解一：1×1 卷积没有意义，因为只看一个像素

错误。

它虽然只看当前位置，但会同时读取当前位置的全部输入通道，能够完成复杂的通道组合。

### 误解二：1×1 卷积只负责降维

错误。

它可以：

```text
降维：128→64
升维：64→128
维持通道数：64→64
输出类别：64→9
输出门控图：160→1
输入适配：1→3
```

### 误解三：1×1 卷积会把所有空间位置混在一起

错误。

它在每个位置独立处理通道向量，不会把 `(h1,w1)` 和 `(h2,w2)` 的数值直接混合。

### 误解四：通道扩张会创造新的原始信息

不准确。

通道扩张会生成新的特征组合，但它们仍来源于现有输入。需要结合激活函数、空间卷积和后续网络层，才能形成更丰富的非线性表示。

### 误解五：所有 1×1 卷积都会混合通道

错误。

必须检查 `groups`：

```text
groups=1：通常能混合全部输入通道
groups=C：depth-wise，只能逐通道处理
```

### 误解六：输出头的 1×1 卷积就是 Softmax

错误。

输出头只产生 logits：

```text
内部特征 → 1×1 Conv → 类别 logits
```

Softmax 是后续把多类 logits 转成概率的独立操作。

### 误解七：1×1 卷积一定不改变空间尺寸

不完全正确。

`stride=1` 时通常不改变；`stride=2` 时仍然可以下采样。

## 26. 阅读代码时应该检查哪些参数

看到一个 `1×1` 卷积时，不要只看 `kernel_size=1`，还要依次检查：

### 26.1 输入和输出通道

```python
nn.Conv2d(C_in, C_out, 1)
```

判断它是在：

- 扩张通道；
- 压缩通道；
- 保持通道数重新编码；
- 生成类别数；
- 压成单通道权重图。

### 26.2 groups

```text
groups=1：完整跨通道融合
groups>1：只在各分组内部融合
groups=C：depth-wise，不跨通道融合
```

### 26.3 stride

```text
stride=1：通常保持 H/W
stride=2：空间尺寸通常减半
```

### 26.4 bias

如果后面紧跟 BatchNorm，常见做法是：

```python
bias=False
```

因为 BatchNorm 自己有可学习的平移参数，卷积 bias 往往显得冗余。

如果后面没有 BatchNorm，或者作者希望保留独立偏置，可能使用：

```python
bias=True
```

### 26.5 后续是否有 BN、激活或 Sigmoid

它们决定这层的实际角色：

```text
1×1 + BN + ReLU：非线性特征变换
1×1 + BN：线性投影和数值规范化
1×1 + Sigmoid：生成软门控权重
1×1 直接输出：产生 logits 或残差投影
```

## 28. 最终记忆框架

第一层理解：

```text
1×1 卷积不主要负责看周围，而主要负责混合当前位置的通道。
```

第二层理解：

```text
输入 [B,C_in,H,W]
经过普通 1×1 卷积
输出 [B,C_out,H,W]
```

第三层理解：

```text
每个空间位置执行：
y(h,w) = W × x(h,w) + b
```

第四层理解：

```text
改变通道数只是表象，真正功能是学习新的通道组合和特征表示。
```

第五层理解：

```text
普通 1×1 卷积 groups=1，可以跨通道融合。
1×1 深度卷积 groups=C，只能逐通道处理。
```

结合 EMCAD，可以记成：

> `1×1` 卷积像一个在每个像素位置重复使用的通道调度器：它可以扩张、压缩、融合、对齐和重新解释通道；在输入端把灰度图适配成三通道，在解码器内部组织多尺度特征和注意力，在输出端把内部特征翻译成每个类别的 logits。
