# 医学图像分割为什么还在不断出现新模型：本质分析

## 一、先说最核心的结论

医学图像分割领域不断出现新模型，不是因为 CNN、RNN、Transformer 完全不能用，也不是因为研究者还没有找到一个足够复杂的网络，而是因为：

> **CNN、RNN、Transformer只解决了“如何构造一个从图像到掩膜的函数”这个问题的一部分，却没有解决数据是否足够、标签是否可信、训练环境与真实医院是否一致、模型犯错是否可控，以及结果是否真正具有临床价值。**

换句话说，医学图像分割的困难并不只在“模型表达能力不够”，而在于整个问题本身具有不确定性：

- 医学图像差异很大；
- 标注数量很少；
- 边界本身可能没有唯一答案；
- 不同医院的数据分布不同；
- 临床不能只看平均 Dice；
- 一个小概率错误就可能造成严重后果；
- 模型必须满足速度、显存、可解释性、可修正性和责任边界等要求。

所以，模型越来越多，不代表研究一直在做同一件事。更准确地说，是大家在不断寻找不同约束下更好的折中方案。

但也必须如实承认：

> **并不是每一篇“新模型”都解决了新的科学问题。相当一部分论文只是改变模块、连接方式、卷积核、注意力或损失函数，然后在固定数据集上提高零点几个百分点。它们更接近增量工程和发表竞争，而不是发现了新的医学规律或学习原理。**

## 二、医学图像分割在数学上到底是什么

最简单地说，医学图像分割是在学习一个函数：

```text
f(图像) = 每个像素或体素所属的类别
```

用符号表示就是：

```text
y_hat = f_theta(x)
```

其中：

- `x` 是 CT、MRI、超声、病理切片或内镜图像；
- `y_hat` 是模型预测的器官、病灶或组织掩膜；
- `theta` 是模型通过训练学到的参数。

CNN、RNN、Transformer的作用，是规定 `f_theta` 可以怎样构造和怎样从数据中学习。

### CNN 提供的主要偏好

- 邻近像素通常相关；
- 局部纹理和边缘很重要；
- 同一种特征可能出现在图像不同位置；
- 可以通过多层卷积逐步扩大感受野。

CNN 对小数据往往比较友好，因为它提前假设了“局部性”和“平移等变性”。但它并不天然擅长所有远距离关系，也可能在多次下采样中损失小器官和细边界。

### Transformer 提供的主要偏好

- 可以让不同位置的特征直接建立关系；
- 更容易建模长距离依赖和全局结构；
- 能够与大规模预训练结合。

但 Transformer 也没有自动解决问题。它可能需要更多数据和算力；高分辨率 3D 医学图像的 token 数量巨大；全局注意力还可能强化数据中的伪相关。

### RNN 提供的主要偏好

- 用隐藏状态保存前面信息；
- 适合序列、时间变化、切片顺序或迭代细化。

但静态空间分割通常不是纯序列问题，所以 RNN 并没有像 CNN 和 Transformer 那样成为通用主干。它在纵向检查、视频、切片序列和反复修正中仍可能有价值。

### 它们共同没有解决的事情

它们可以表示非常复杂的函数，却无法仅凭结构自动回答：

- 哪个边界才是医生真正认可的边界？
- 一个没有在训练集中出现过的罕见病例应该怎样处理？
- A 医院训练的模型为什么能在 B 医院继续有效？
- 模型什么时候应该承认“我不知道”？
- 漏掉一个微小肿瘤和把肝脏边界画错两毫米，哪一个更严重？
- 模型的错误是否会改变诊断、手术或放疗计划？

这正是“模型有能力拟合训练数据”和“系统能够可靠解决临床问题”之间的巨大距离。

## 三、为什么一个足够强的模型仍然不能结束这个领域

### 1. 医学图像分割不是一个任务，而是几百类不同任务

“医学图像分割”只是一个总称，内部包括：

- CT 器官分割；
- MRI 脑肿瘤分割；
- 超声乳腺病灶分割；
- 内镜息肉分割；
- 病理全切片细胞和腺体分割；
- 血管、神经、骨骼和气道分割；
- 2D、2.5D、3D、视频和纵向随访分割；
- 单器官、多器官、实例分割和全景分割。

这些任务在图像形成原理、分辨率、噪声、小目标比例、类别数量和临床目的上完全不同。

一个在腹部 CT 上优秀的模型，不会因为使用了 Transformer，就自然理解超声散斑、病理染色差异或内镜反光。

所以，不存在一个“已经有 CNN，因此所有医学图像分割都解决了”的逻辑。

### 2. 训练数据与真实世界并不是同一个分布

模型通常假设训练数据和使用时的数据来自相似分布：

```text
P_train(x, y) ≈ P_deploy(x, y)
```

但医学中经常不成立。变化可能来自：

- 不同医院；
- 不同国家和人群；
- 不同扫描仪厂家；
- 不同成像协议；
- 不同层厚和空间分辨率；
- 不同造影阶段；
- 不同病程；
- 不同医生的标注习惯；
- 正常病例与罕见病比例变化。

模型可能在同一数据集的测试集上达到很高 Dice，换一家医院就明显下降。这不是 Transformer 层数再增加两层就必然能解决的，而是分布外泛化问题。

### 3. 医学标注并不是绝对真理

论文常把人工掩膜称为 `ground truth`，但许多情况下它更准确的含义是“某位或某几位专家按照某套规则给出的参考标注”。

例如：

- 肿瘤浸润边界在图像上本来就不清楚；
- 两位医生可能对病灶边缘有不同判断；
- 不同医院的勾画规范不同；
- 放疗靶区不仅依赖影像，还依赖临床经验；
- 很小的结构可能因层厚和部分容积效应无法被准确观察。

因此，模型即使完美学习了训练标签，也可能只是复制了某位标注者的习惯，而不是找到了唯一的生物学真相。

这意味着某些任务存在不可消除的误差下限。模型分数不能无限提高，因为“正确答案”本身就有不确定性。

### 4. 数据太少，而模型太强

深度网络参数很多，而高质量医学标注非常昂贵。小型医学数据集经常只有几十或几百个病例。

这会形成一个本质矛盾：

```text
模型具有极强的记忆和拟合能力
                     VS
训练数据只能覆盖真实世界的一小部分
```

许多不同函数都可以在训练集上表现很好，但它们在新医院和新病种上的行为完全不同。这叫欠定问题：已有数据不足以唯一确定真正应该学习的规律。

新模型的一项真实目标，就是加入更合适的归纳偏置，让模型在有限数据下更倾向于学习形状、边界、尺度和解剖关系，而不是记住数据集特征。

### 5. 平均指标掩盖了真正危险的错误

假设一个多器官模型：

- 大肝脏分得很好；
- 两个很小的器官经常漏掉；
- 平均 Dice 仍然不低。

或者一个肿瘤模型：

- 绝大多数常见病例很好；
- 所有罕见、微小肿瘤都漏掉；
- 总体平均值仍然漂亮。

Dice 更偏向区域重叠，对大结构尤其友好，但不能完整表示：

- 最坏病例；
- 边界最大偏差；
- 小病灶召回率；
- 拓扑是否断裂；
- 是否漏掉整个器官；
- 错误是否改变临床决策。

所以领域还要研究 HD95、表面距离、病灶级召回、拓扑指标、校准、失败检测和临床终点。模型“平均更准”不等于“更可用”。

### 6. 医疗要求模型知道自己什么时候可能出错

普通图片分割错一点，可能只是视觉效果不好。医学分割错一点，可能影响：

- 肿瘤体积评估；
- 手术路径；
- 放疗剂量；
- 疗效比较；
- 病情进展判断。

真正可用的系统不仅要输出掩膜，还要回答：

```text
我对这个结果有多大把握？
这个病例是否偏离训练分布？
是否需要医生重点检查？
错误最可能出现在哪里？
```

一个 Dice 低一点但能可靠报警的系统，有时比平均 Dice 更高、却静默犯错的系统更安全。

## 四、既然已经很准确，为什么仍然不一定可用

“准确”必须先问清楚在哪个条件下准确。

### 在封闭条件下，很多模型已经相当可用

某些任务已经能够显著减少医生工作量，例如：

- 边界清楚的大器官初始勾画；
- 相同医院、相同协议下的结构分割；
- 医生审核和修正模式下的辅助分割；
- 影像体积和形态的批量研究分析。

这些场景中，模型不需要完全替代医生。只要能把人工勾画从二十分钟降到几分钟，并且修改成本稳定，就可能具有实际价值。

### 在开放的真实环境中，还远没有普遍解决

真实临床部署还要满足：

- 多中心外部验证；
- 不同设备和协议下稳定；
- 极端和罕见病例安全；
- 低延迟、合理显存和硬件成本；
- 与 PACS、影像工作站和医生流程结合；
- 结果可编辑、可追踪；
- 发现分布外病例；
- 明确责任边界；
- 前瞻性验证，而不只是离线测试；
- 证明节省时间或改善临床结果。

所以，“某论文在 Synapse 上 Dice 提高到某个数”与“模型已经能在医院独立工作”之间，至少隔着数据泛化、软件工程、临床验证和监管四道关。

## 五、新模型真正有价值的研究方向是什么

真正有价值的新模型或新方法，通常不是单纯“模型更复杂”，而是在解决下面某个明确瓶颈。

### 1. 更好地利用有限标注

- 自监督预训练；
- 半监督学习；
- 弱监督学习；
- 主动学习；
- 少样本与零样本分割；
- 合成数据和可控数据增强。

目标是减少医生标注成本，而不是只在相同数据量下追求零点几的 Dice。

### 2. 提高跨医院、跨设备泛化能力

- 域泛化；
- 域适应；
- 测试时适应；
- 强度和风格鲁棒性；
- 多中心训练；
- 联邦学习。

这类研究试图解决“实验室里很好，换医院就下降”的问题。

### 3. 处理小目标、边界和拓扑

- 保留高分辨率细节；
- 多尺度融合；
- 边界监督；
- 形状先验；
- 拓扑约束；
- 连通性和细长结构建模。

这适用于血管、神经、小肿瘤和小器官等普通区域损失不擅长的问题。

### 4. 降低计算和部署成本

- 轻量化编码器和解码器；
- 稀疏计算；
- 蒸馏、剪枝和量化；
- 低显存 3D 推理；
- 移动端和床旁设备部署。

一个模型即使 Dice 高 0.5%，如果显存翻倍、速度下降十倍，可能反而没有工程价值。

### 5. 建立可靠性和失败保护

- 不确定性估计；
- 校准；
- 分布外检测；
- 自动质量控制；
- 失败病例识别；
- 人机协同修正。

这类工作更接近真实医疗需求，但往往没有单纯刷新 Dice 那么容易展示。

### 6. 利用多模态和基础模型

- 图像与文本报告结合；
- CT、MRI、PET 等多模态融合；
- 可提示分割；
- 医学视觉基础模型；
- 通用模型向具体医院适配。

目标是降低每个任务从头训练一个模型的成本，并让医生通过点、框或文字快速交互。

## 六、为什么还存在大量“换模块式论文”

除了真实技术困难，还必须看科研发表机制。

### 1. 结构创新最容易包装成论文

新增一个模块很容易画成网络结构图，也容易命名：

```text
多尺度模块
注意力模块
边界增强模块
全局局部融合模块
频域模块
动态卷积模块
```

然后在几个公开数据集上跑出一个主表，就能形成完整的论文外观。

相比之下，收集多中心数据、做前瞻性临床研究、研究失败病例和标注一致性，成本高、周期长、伦理和数据手续复杂，却不一定容易发表。

### 2. 公开基准把研究变成了容易比较的分数竞赛

只要大家都在同一数据集上报告 Dice，就能快速排序。但这也会带来问题：

- 多年间整个领域不断间接适应同一个测试集；
- 不同论文的预训练、输入尺寸和增强并不相同；
- 小数据集中的随机种子波动可能超过论文宣称的提升；
- 只报告最好的运行结果；
- 只挑对自己有利的数据集和指标；
- 计算量大幅增加，却只提高很小分数。

因此，排行榜提升不一定等于真实世界进步。

### 3. 学术评价需要持续产生“新东西”

学生要毕业，教师要项目，经费和期刊会议需要新稿件。于是“提出一个新模型”比“严谨证明某个复杂模块其实没有必要”更容易成为成果。

这并不意味着所有增量论文都是造假。科学和工程本来就依赖很多小改进。但必须承认：

> **论文数量增长，既来自问题真的困难，也来自发表体系把结构变化变成了最容易计量的创新。**

### 4. 很多所谓新模型其实是设计空间中的重新组合

常见医学分割模型大致由以下部件组成：

```text
编码器
下采样
多尺度特征
上下文建模
跳跃连接
特征融合
解码器
上采样
辅助监督
损失函数
```

很多论文只是改变其中一两项：

- 卷积换成深度可分离卷积；
- 普通卷积换成空洞卷积；
- 拼接换成加权融合；
- 跳跃连接加注意力；
- Transformer 换成窗口注意力；
- 增加边界分支；
- 改变深监督位置。

这些变化可能有用，但通常不是新的学习范式，而是在巨大的设计空间中寻找更适合某个数据集的配置。

## 七、怎么判断一篇新模型论文是真的有价值，还是只是在卷

阅读时不要先看模块名字，而要连续追问八个问题。

### 1. 它解决的具体失败是什么

是小器官漏检、边界粗糙、跨域下降、推理太慢，还是仅仅“现有方法不够好”？后者通常不是清晰问题。

### 2. 为什么现有方法会失败

作者是否提供了机制解释、数据证据或失败病例，还是只说 CNN 缺乏全局信息、Transformer 缺乏局部信息这种通用套话？

### 3. 修改与问题之间是否有因果关系

例如，声称改善边界，就应当提供边界指标和边界可视化；声称轻量化，就应报告参数量、FLOPs、显存和延迟。

### 4. 提升是否大于随机波动

只跑一个随机种子、提高 `0.2%`，很可能无法证明结构真的更好。多次运行的均值和方差比单次最好结果更可信。

### 5. 比较是否公平

必须尽量保持相同：

- 数据划分；
- 预训练；
- 输入尺寸；
- 数据增强；
- 训练轮数；
- 优化器；
- 推理和后处理；
- 评估代码。

否则提高的可能不是模型，而是训练资源。

### 6. 是否做了真正的消融实验

不仅要比较“基线”和“完整模型”，还要拆开每个组成部分，并提供参数量相近的替代方案。

### 7. 是否经过外部数据验证

同一数据集内部提高，只能证明它更适应该基准。跨中心、跨设备、跨数据集仍然有效，才更能说明学到了可泛化规律。

### 8. 是否报告失败和代价

真正可信的论文应该说明：

- 哪些病例仍然失败；
- 计算量增加多少；
- 对初始化或超参数是否敏感；
- 在什么条件下不适用。

如果一篇论文只有漂亮的平均 Dice 和结构图，却没有这些内容，它更可能是排行榜型增量，而不是问题驱动的科研。

## 八、对“医学分割研究本质”的四层回答

### 科学层面的本质

在有限、带噪声、存在分布变化的数据中，寻找能够稳定恢复医学结构的规律，并理解方法为什么有效、什么时候失效。

### 算法层面的本质

为学习函数加入合适的归纳偏置，使其保留边界、理解上下文、利用形状和多尺度信息，而不是记住训练集。

### 工程层面的本质

在准确率、稳定性、速度、显存、标注成本、可维护性和可交互性之间做出可部署的折中。

### 临床层面的本质

在明确的人群、设备、流程和责任边界内，可靠减少医生劳动或改善医疗决策，并且在不能可靠工作时及时暴露风险。

至于论文发表层面的本质，往往是：

> **把一个有限范围内可验证的改进组织成问题、方法、实验和论证。**

这与解决整个医学图像分割领域不是一回事。

## 九、对你当前做 EMCAD、Synapse 研究最重要的提醒

如果你只是不断寻找一个新注意力模块替换 EMCAD 中的旧模块，你很容易陷入“结构排列组合”。真正值得研究的起点应该是一个具体失败现象，例如：

- 小器官 Dice 明显低；
- 某些器官 HD95 波动很大；
- 相邻组织容易混淆；
- 2D 切片之间预测不连续；
- 模型参数少但实际推理并不快；
- 对输入分辨率、随机种子或预训练过于敏感。

然后建立一条能够被证伪的研究链：

```text
观察到的失败
    ↓
失败原因假设
    ↓
有针对性的最小修改
    ↓
受控实验与消融
    ↓
Dice、HD95、效率和失败病例共同验证
    ↓
确认假设成立，或者承认假设不成立
```

例如：

```text
观察：小器官和细边界明显差。
假设：解码过程中高分辨率细节损失，现有融合又被高层语义主导。
修改：增加一个受约束的细节保留或边界校正路径。
验证：逐器官 Dice、HD95、边界指标、参数量匹配对照、多随机种子和失败病例。
```

这就比“我设计了一个新的多尺度注意力模块，因为它能同时提取局部与全局信息”更接近科研。

还要保持实验纪律：固定病例级训练、验证和测试划分；只用验证集选择模型；在相同训练预算下比较；记录多次运行结果；报告逐类和逐病例指标。否则零点几个百分点的提升很可能只是数据划分、随机种子或测试集反复调参造成的。

## 十、最后把本质压缩成一句话

> **医学图像分割持续产生新模型，是因为“把一张固定数据集上的图像拟合成掩膜”已经比较成熟，但“让系统在有限标注、模糊边界、跨医院变化、罕见病例和临床风险下仍然可靠工作”远没有解决。与此同时，发表机制又把许多本来只是局部工程调整的工作包装成了全新模型。**

所以，这个领域真正缺少的往往不是第 1001 个注意力模块，而是：

- 更准确的问题定义；
- 更可信的数据和标注；
- 更严格的验证；
- 对失败机制的理解；
- 对跨中心泛化和临床价值的证明；
- 在效果、成本与安全之间诚实的权衡。

模型只是工具。医学图像分割真正研究的对象，是**在不完美的数据和高风险环境中，怎样可靠地把医学图像转换成有用的空间信息**。
