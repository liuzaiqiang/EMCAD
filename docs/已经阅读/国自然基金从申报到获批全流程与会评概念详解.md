# 国家自然科学基金：从项目申报、通讯评审、会评到结果公布的完整流程

> 适用范围：以国家自然科学基金委员会（以下简称“自然科学基金委”或“基金委”）管理的国家自然科学基金项目为对象，重点解释集中接收项目从准备申请到结果公布的常规流程。
>
> 核对日期：2026-08-27。本文结合《2026年度国家自然科学基金项目指南》、2026年度申请通知、初审通告、评审常见问答和2026年8月26日结果通告整理。不同项目类型可能存在单独指南、答辩、预算评审或者非集中接收安排，不能把某一种项目的细节直接套到所有项目。

## 一、先用一句话讲清整个流程

一份国自然申请，通常会经历：

```text
确定项目类型和申请资格
        |
申请人撰写申请书、组织参与者和附件
        |
院系/依托单位审核并正式提交
        |
基金委接收申请
        |
初审（资格、限项、材料、合规性等形式和管理审查）
        |
受理，或不予受理 -> 可就不予受理决定申请复审
        |
通讯评审/函评（同行专家分别、独立评议）
        |
按照项目规则和资助计划形成会议评审范围
        |
会议评审/会评（专家组集中讨论、比较、表决或形成建议）
        |
项目管理部门汇总评审意见和建议资助方案
        |
基金委委务会议审批
        |
批准资助或不予资助
        |
系统、邮件和依托单位渠道通知结果
        |
不予资助项目在规定期限内可申请复审
```

最容易混淆的是下面四件事：

1. **提交成功不等于受理。** 提交以后还要经过初审。
2. **受理不等于进入会评。** 受理只是说明具备进入学术评审流程的资格。
3. **进入会评不等于获资助。** 会评阶段仍然要在同组项目之间进行学术比较，并受到年度资助计划约束。
4. **通讯评审意见较好也不等于必然获资助。** 专家意见是重要依据，但最后还存在会评、资助计划、审批等环节。

## 二、“国自然”究竟是什么

科研人员平时说的“国自然”，一般是“国家自然科学基金”的简称。它不是一项单独的比赛，也不是只有一种项目，而是包含多种项目类型的资助体系。

2026年度集中接收申请中包括面上项目、青年科学基金项目（C类）、地区科学基金项目、重点项目、青年科学基金项目（B类）、青年科学基金项目（A类）、创新研究群体项目、卓越研究群体项目、重点国际（地区）合作研究项目、外国学者研究基金项目、合作创新研究团队项目、国家重大科研仪器研制项目（自由申请）、部分联合基金项目、部分重大研究计划项目和部分数学天元基金项目等。

不同项目的定位不同：

| 项目概念 | 大致作用 | 不能误解成 |
| --- | --- | --- |
| 面上项目 | 支持科研人员自主选题开展基础研究，是常见项目类型之一 | “所有人都能申请”或“难度一般” |
| 青年科学基金项目（C类） | 支持青年科研人员独立主持基础研究 | 研究生奖学金或学生项目 |
| 地区科学基金项目 | 面向规定区域依托单位的全职科研人员，促进区域基础研究能力 | 只要户籍在新疆就能申请 |
| 重点、重大类项目 | 围绕重要科学问题开展较系统、深入的研究 | 单纯因为经费大就可以套用一般项目写法 |
| 青年科学基金项目（A、B类） | 人才类项目，申请资格和评审组织另有要求 | 普通青年项目简单升级 |
| 联合基金、重大研究计划等 | 常有专门指南、限定领域和独立时间安排 | 每年固定按集中接收的同一种方式处理 |

所以，讨论申报流程时必须先回答：“申请的是哪一种项目、哪一年度、哪一个指南下的项目？”

## 三、2026年度集中接收项目的真实时间线

下面这条时间线来自基金委2026年度官方通告，能帮助你把“申报、初审、函评、会评、结果”放到一年中理解。

| 时间 | 发生的事情 | 谁在行动 |
| --- | --- | --- |
| 2026-01-14 | 基金委发布年度申请与结题事项通告 | 基金委 |
| 2026-01-15以后 | 申请人登录信息系统，按最新版提纲撰写申请书 | 申请人、主要参与者 |
| 2026-03-01 | 集中接收开始 | 申请人、依托单位、基金委 |
| 2026-03-20 16:00 | 集中接收截止 | 依托单位必须在校内截止时间前完成审核；基金委截止时间不是个人可以拖到的校内截止时间 |
| 截止后24小时内 | 依托单位在线提交本单位项目申请清单 | 依托单位科研管理部门 |
| 2026-04-29 | 公布初审结果 | 基金委、依托单位、申请人 |
| 2026-05-15 16:00前 | 2026年度不予受理项目复审申请截止 | 对不予受理有异议的申请人 |
| 2026-06-05前 | 不予受理复审结果书面通知申请人 | 相关项目管理部门 |
| 春季至夏季 | 通讯评审、形成会评范围、会议评审以及内部审批 | 同行专家、会议专家、项目管理部门、基金委 |
| 2026-08-26 | 公布大部分集中接收项目评审结果 | 基金委 |
| 2026-08-26至08-28 | 使用指定邮箱向申请人发送批准/不予资助通知及专家评审意见 | 基金委 |
| 2026-09-15 16:00前 | 2026年度不予资助项目复审申请截止 | 未获资助且对决定存在合规性异议的申请人 |
| 2026-11-06前 | 相关项目管理部门书面通知不予资助复审结果 | 基金委相关项目管理部门 |

基金委常见问答说明：国家自然科学基金项目从接收到审批完成一般需要约5个月；集中接收的大部分项目类型通常在当年8月中下旬公布资助结果，其余项目根据评审进程陆续公布。

这不是说所有项目都在8月同一天结束。非集中接收项目，以及集中接收但尚在评审或审批的其他类型项目，可能另行公布。

## 四、全流程中涉及哪些单位和个人

用户原问题中的“有关肾单位、个人”，我理解为“有关的单位、个人”。下面把各方放到同一张表中。

### 4.1 申请人

申请人是以本人名义申请并拟主持项目的科研人员。项目批准后，申请人通常成为项目负责人。

申请人负责：

- 判断自己是否符合该年度、该项目类型的申请资格和限项规则；
- 确定科学问题、研究目标、研究内容、技术路线和研究方案；
- 选择申请代码、研究属性和项目类型；
- 邀请主要参与者填写个人简历；
- 如实列出论文、专利等成果的全部作者、顺序及本人贡献；
- 编制预算制项目的预算，或按包干制项目要求填报；
- 获得主要参与者和合作研究单位对申请材料的同意；
- 完成科技伦理、科研诚信、保密等事项；
- 对整份申请书及附件的真实性、准确性和合规性负责；
- 接收评审结果，必要时本人提出复审申请。

“导师帮忙修改”“团队共同讨论”不改变申请人的责任。申请书中存在虚假成果、错误作者顺序、未经核实的参考文献或伦理问题，不能以“学生写的”“AI生成的”作为免责理由。

### 4.2 主要参与者

主要参与者是项目团队中承担实质研究任务的人，但不是项目负责人。他们的研究基础、任务分工、投入时间和专业互补性会影响专家对项目可行性的判断。

2026年度申请通知要求申请人通过信息系统邀请主要参与者在线填写个人简历，并上传系统生成的PDF简历。主要参与者也必须如实填写成果、职称和贡献。

参与者不是“挂名成员”。如果研究内容、人员专长和分工对不上，反而可能使专家怀疑研究方案是否真实可执行。

### 4.3 依托单位

依托单位是已经在基金委注册、具备相应科研和管理条件，并负责组织申请、管理项目与资金的法人单位。高校、科研机构等通常以依托单位身份组织申报。

如果一位教师通过新疆大学申报，那么在这份申请中，新疆大学就是依托单位。学校内具体经办部门通常是科学技术处、科研院或承担基金管理职能的部门，实际名称以学校机构设置为准。

依托单位的职责不是替专家决定项目学术水平，而是：

- 为申请人开通或管理信息系统账号；
- 制定校内截止时间并组织申报；
- 审核申请材料的真实性、完整性和合法性；
- 核对申请人与参与者职称等重要信息；
- 检查资格、限项、附件、伦理、诚信和合作事项；
- 在基金委截止时间前逐项确认提交电子申请书和附件；
- 集中接收截止后按要求提交本单位申请清单；
- 接收纸质初审和资助结果通知；
- 项目获批后承担项目、资金、伦理和科研诚信管理主体责任。

学校里的“院内预审”“专家预评审”“科研处形式审查”属于依托单位内部质量控制，不等于基金委的通讯评审或会评。校内专家说“可以报”，也不代表基金委已经受理。

### 4.4 合作研究单位

如果主要参与者中存在申请人所在依托单位以外的人员，其所在境内单位通常会被视为合作研究单位；合作研究单位应具有独立法人资格。基金委问答明确，境外工作单位不作为这里所说的合作研究单位。

2026年度官方通知要求：存在合作研究单位时，申请人与合作单位参与者应协商研究任务分工，双方单位协商合作研究协议或合同；如果约定转拨合作研究资金，还要分别编制相关预算，经各自单位审核后由申请人汇总。

合作研究单位不是第二个依托单位。项目仍由申请人的依托单位作为主要管理责任主体。

### 4.5 基金委项目管理部门和科学部

基金委设有数理科学部、化学科学部、生命科学部、地球科学部、工程与材料科学部、信息科学部、管理科学部、医学科学部、交叉科学部等科学部，以及承担计划、政策、财务、国际合作、科研诚信等职责的部门。

项目通常根据项目类型、申请代码和研究内容进入相应项目管理部门。对于计算机和医学图像交叉研究，不能简单地说“我是计算机学院，所以一定归信息科学部”，也不能说“数据是医学影像，所以一定归医学科学部”。最终取决于申请所选择的科学问题、申请代码、项目指南和管理分工。

项目管理人员负责组织流程，例如接收、初审、匹配评审专家、组织会议、汇总材料、处理回避以及形成管理程序上的建议。他们不是单独替代同行专家作出学术判断的人。

### 4.6 通讯评审专家

通讯评审专家是与申请项目研究领域相关的同行专家。他们在不同地点、不同时间通过评审系统独立阅读申请书并提交评审意见，所以也称“函评专家”。

基金委官方问答称：对于已受理的申请，基金管理机构应先从同行专家库中随机选择3名以上专家进行通讯评审，再组织会议评审；因国家经济社会发展特殊需要或其他特殊情况临时提出的申请，可以只进行通讯评审或会议评审。

“随机选择”不等于完全不考虑专业。通常需要在项目申请代码、关键词、研究领域、专家信息、回避关系等约束下进行匹配。专业匹配和随机机制共同存在。

### 4.7 会议评审专家组

会议评审专家组是在会议评审阶段集中审议候选项目的同行专家集体。专家会综合申请书、通讯评审意见、项目类型定位、必要时的答辩材料以及当年资助计划，对项目进行横向比较、讨论并形成评审建议。

会评专家不是对申请书再各自写一遍函评，而是在已有同行评议基础上进行集体判断和优先顺序选择。

### 4.8 答辩申请人和答辩专家

部分项目类型会通知申请人参加会议答辩。答辩通常包括限时陈述和专家提问，但项目类型、陈述形式、时间、线上或线下方式均以当年通知为准。

**会评不等于答辩。** 很多项目的会议评审并不要求所有申请人到场。是否答辩取决于项目类型和具体评审安排。

### 4.9 基金委委务会议

专家的评审结果通常体现为评审意见和建议，不是专家个人直接“拨款”。2026年度结果通告明确说明，相关项目是根据条例、项目管理办法和专家评审意见，经自然科学基金委委务会议审批后予以资助。

因此，完整关系是：

```text
同行专家提供学术评审意见
        +
项目管理部门依据规则和资助计划组织、汇总
        +
基金委按程序审批
        =
最终资助决定
```

### 4.10 科研诚信、监督和纪检相关机构

申请和评审过程中如出现伪造材料、抄袭剽窃、请托打招呼、泄露评审信息、利益输送或其他科研不端行为，可能进入科研诚信调查和监督处理程序。依托单位是科研诚信建设第一责任主体，基金委科研诚信相关部门也承担相应职责。

这些机构通常不评价“科学思想是不是足够新”，而是处理程序、公正性、诚信和纪律问题。

## 五、阶段0：先判断能不能申报

在写申请书以前，申请人必须完成资格自查。常见问题包括：

- 是否属于该项目允许的申请人；
- 年龄、职称、学位、聘用方式和工作时间是否符合要求；
- 是否正在承担或申请其他项目，是否触发限项；
- 所在单位是否为依托单位；
- 项目是否属于该指南资助范围；
- 同一或相近内容是否重复申请或已获其他项目资助；
- 是否受到科研诚信或财政科研活动限制；
- 是否需要推荐信、导师同意函、伦理批件或其他证明材料。

### 对你当前“全日制硕士在读”身份的特别说明

基金委申请条件问答明确：

> 正在攻读研究生学位的人员，在申请截止日期时尚未获得学位的，不得作为申请人申请各类项目，部分项目类型有特殊要求的除外。

符合条件的**在职攻读研究生学位人员**，经导师同意，可以通过其受聘单位申请面上项目、青年科学基金项目（C类）和地区科学基金项目；受聘单位不是依托单位的在职读研人员不能作为申请人申请这些项目。具体仍须核对当年指南。

因此，如果你是新疆大学普通全日制计算机硕士研究生：

- 一般不能以自己为项目申请人主持普通国自然项目；
- 可以在导师指导下参与实际研究和申请材料准备；
- 是否列为主要参与者，应由项目负责人依据你承担的真实任务和当年填报要求确定；
- 不要把导师申请的项目说成“我申请的国自然”，更准确的说法是“我参与了导师团队某项国自然申请/项目研究”；
- 将来取得相应学位并进入依托单位工作后，再按届时的项目指南判断申请资格。

新疆属于地区科学基金规定的资助区域之一，但“在新疆读书”不自动产生申请资格。地区科学基金强调申请人是规定区域依托单位的**全职科学技术人员**，同时仍要满足职称、学位、推荐、限项等其他要求。

## 六、阶段1：选择项目类型、科学部和申请代码

一份项目能否被合适的同行理解，与申请代码和科学问题的表达直接相关。

### 6.1 项目类型决定评审尺度

面上项目、青年项目、重点项目和联合基金的目标不同，专家不会使用完全相同的尺度。申请人应先按指南理解“该项目想资助谁、资助什么、期待什么层次的研究”，再组织申请内容。

### 6.2 申请代码帮助项目进入合适的评审领域

申请代码通常反映项目所依托的学科方向。代码选得不准确可能导致同行匹配偏差，但代码不是关键词堆砌，也不是人为“逃避竞争”的工具。

对于医学图像分割研究，需要先回答你的核心问题到底是：

- 新型机器学习理论、模型机制或视觉方法；
- 医学影像形成、重建、分析中的基础问题；
- 某种疾病的影像表型和临床科学问题；
- 医工交叉中的方法与机制问题。

如果申请书只是“把已有网络换几个模块，Dice提高一点”，容易被认为偏工程改良，科学问题不足。国自然关注的不只是模型指标高不高，还要看是否提出有价值的基础科学问题、为什么值得研究、方法为何能回答问题以及可验证的科学假设是什么。

### 6.3 研究属性与分类评审

2026年度申请通知要求申请人从以下两类中选择研究属性：

- **自由探索类基础研究**：选题源于科研人员好奇心或创新性学术灵感，不以满足现阶段应用需求为目的的原创性、前沿性基础研究；
- **目标导向类基础研究**：以经济社会发展需要或国家需求为牵引的基础研究。

2026年，面上项目、青年科学基金项目（C类）和重点项目继续结合申请人选择的研究属性组织分类评审。选择研究属性不是给项目贴一个好听标签；申请书中的问题来源、研究目标和价值论证应与所选属性一致。

## 七、阶段2：撰写并形成完整申请材料

一份申请通常不只是正文。它还会涉及个人简历、参与者简历、代表作、预算、伦理材料、合作说明、推荐信或其他附件。

### 7.1 申请书的核心不是“技术路线越复杂越好”

专家通常希望看清：

1. 研究背景中真正未解决的问题是什么；
2. 你提出了什么明确、可检验的科学问题或假设；
3. 研究目标与研究内容是否一一对应；
4. 方案为什么能够回答问题；
5. 关键难点、风险和替代方案是什么；
6. 前期工作是否证明团队有能力完成；
7. 创新点是否真实、具体，而不是口号；
8. 工作量、人员、周期和经费是否匹配。

### 7.2 主要参与者在线确认

2026年度要求申请人通过信息系统邀请主要参与者填写个人简历。这样做是为了让参与者本人确认信息，减少申请人代填、成果错列和未经同意挂名。

### 7.3 伦理审查

涉及人体、患者数据、医疗影像、隐私、生物样本或其他科技伦理敏感领域时，应按法规、伦理准则和依托单位制度完成伦理审查。医学图像数据“已经脱敏”不等于自动免除伦理和数据合规要求。

### 7.4 预算制与包干制

2026年青年科学基金项目（A、B、C类）以及试点设立的青年学生基础研究项目实行经费包干制，申请时不需要编制预算；其他类型通常实行预算制，应按目标相关性、政策相符性和经济合理性如实编报。重大科研仪器研制项目、重大项目还会严格开展预算评审。

预算评审与学术评审不是同一个概念。科学问题很好，不代表预算可以随意；预算合理，也不能弥补科学价值不足。

### 7.5 2026年使用生成式AI的明确要求

这与你正在使用Codex尤其相关。2026年度官方通知明确要求：

- 如果借助生成式AI跟踪研究动态、收集整理参考文献，必须由人工核实信息和文献的真实性、准确性；
- 申请人对使用的生成内容负责；
- 应全面、如实声明使用情况，并按国家有关规定进行标识；
- 不得使用生成式AI直接生成申请书；
- 不得使用未经核实的生成内容。

正确用法是把AI当作检索辅助、结构检查或语言讨论工具，最终科学内容、文献、数据和论证必须由申请人逐项核实并承担责任。不能让AI代写一份“看起来像国自然”的申请书后直接提交。

## 八、阶段3：院系和依托单位审核、提交

### 8.1 为什么学校往往比基金委提前截止

基金委2026年集中接收截止时间是3月20日16时，但学校必须在截止前逐项审核并确认提交。因此依托单位通常设置更早的校内截止时间，为院系审核、科研处复核和退回修改预留时间。

个人看到基金委还未截止，不代表学校必须继续接收个人修改。

### 8.2 学校审核什么

依托单位主要审核：

- 申请人和参与者身份、职称、聘用信息；
- 资格和限项；
- 申请书和附件是否完整；
- 成果信息是否真实规范；
- 合作单位、协议和预算关系；
- 伦理、诚信、保密和合法性；
- 申请材料是否按年度最新版模板制作。

学校可以组织学术预评审帮助提高质量，但正式同行学术评审权仍在基金委组织的专家评审环节。

### 8.3 无纸化申请

2026年国家自然科学基金项目全面实行无纸化申请。申请人在线撰写并提交电子申请书，证明信、推荐信等以电子扫描件上传；申请阶段依托单位在线确认，无需报送纸质申请材料。

项目获批后，依托单位才需按要求补交申请书纸质签字盖章页，并与《资助项目计划书》一并提交。

## 九、阶段4：基金委接收与初审

### 9.1 “接收”不等于“受理”

系统和依托单位完成提交后，基金委先形成“接收到的申请”。随后基金委进行初审，符合条件的才成为“受理申请”。

### 9.2 初审主要审什么

初审主要是资格、材料和管理规则审查，例如：

- 申请人是否符合资格；
- 是否超过限项；
- 是否在规定时间和渠道提交；
- 申请材料是否完整、符合模板和附件要求；
- 项目类型、期限、合作单位等是否符合规则；
- 是否存在明显重复申请、限制申报或其他不予受理情形；
- 指南明确要求的伦理、证明、推荐等材料是否具备。

初审不是对创新性、科学价值和技术路线进行完整同行评议。因为“科学问题不够好”而淘汰，通常属于后续学术评审；因为资格、限项或材料不合规而不进入同行评审，属于不予受理。

### 9.3 2026年度初审数据

2026年度集中接收期间，基金委共接收470,561项申请。4月29日初审通告显示：

- 受理469,427项；
- 不予受理1,134项。

8月26日结果通告使用“经初审和复审后共受理469,429项”的口径，比初审通告多2项。这恰好说明初审决定存在正式复审纠错机制；但不能在不知道个案材料的情况下推断那2项的具体原因。

## 十、阶段5：不予受理及其复审

申请人收到“不予受理”通知，说明申请没有进入正常同行学术评审流程，或者在初审阶段被认定不符合受理条件。

### 10.1 2026年度程序

2026年不予受理项目的申请人如有异议，应在5月15日16时前：

1. 使用申请时的账号登录科学基金网络信息系统；
2. 在线填写并提交复审申请表；
3. 打印一份与在线内容一致的纸质申请表；
4. 本人签字后，在规定期限内以特快专递寄送相关项目管理部门。

相关项目管理部门审查后：

- 原不予受理决定符合规定的，维持原决定；
- 原决定有误的，撤销不予受理决定，并使申请进入评审程序。

### 10.2 谁可以申请

必须由项目申请人本人提出。依托单位、导师、参与者或其他人不能替代申请人成为复审申请人，但依托单位科研管理部门可以提供程序和材料帮助。

### 10.3 这时复审什么

这里主要争议的是：资格、限项、材料、程序和相关管理规则是否被正确适用。因为项目尚未进入或尚未完成同行学术评议，这个环节不是让专家重新评价课题创新性。

## 十一、阶段6：通讯评审，也叫函评

### 11.1 什么是通讯评审

“通讯评审”可以理解为：基金委把申请书通过评审系统分送给若干名同行专家，专家彼此分开、独立阅读并提交意见。传统上材料可能通过函件传递，所以科研人员常称为“函评”；今天主要通过信息系统进行，但简称保留下来。

### 11.2 为什么先函评

申请量巨大，不可能让所有项目直接拿到一个会议中逐项长时间讨论。通讯评审先让多个同行独立判断，可以：

- 覆盖较细的专业方向；
- 避免某一个专家独占判断；
- 形成多角度文字意见；
- 为后续会评提供基础；
- 在有限会议资源前形成初步区分。

### 11.3 专家通常看什么

具体评审表随项目类型和年度变化，但学术判断通常围绕：

- 科学问题是否重要、清楚；
- 是否具有原创性或创新价值；
- 研究目标、内容和方案是否一致；
- 技术路线是否科学、可行；
- 前期工作和研究条件是否支持完成项目；
- 申请人和团队是否具有相应研究能力；
- 预期成果与研究周期是否合理；
- 申请是否符合项目定位和所选研究属性；
- 经费是否与研究任务匹配，需预算评审的项目还要进行相应评价。

### 11.4 通讯评审是不是“双盲”

通常不能把它理解成论文投稿中的双盲评审。申请材料包含申请人、主要参与者、前期成果和依托单位等信息，评审专家需要据此判断研究基础与能力。申请人通常不知道具体评审专家是谁，专家身份和过程受到保密、回避规则约束。

### 11.5 “大同行”和“小同行”是什么

这两个词更多是科研共同体中的非正式说法：

- **小同行**：研究主题、方法和对象与申请非常接近的专家；
- **大同行**：属于同一较宽学科领域，能判断科学价值，但未必做完全相同的细分问题。

理想评审既需要足够专业，又不能窄到只接受一种技术路线。实际专家匹配还受专家库覆盖、回避关系和评审工作量等约束，因此申请书应做到：细分同行能判断技术深度，较宽领域同行也能理解问题价值。

### 11.6 函评会给出什么

专家会按该项目评审表填写评价和资助建议，并给出文字意见。具体等级、栏目、汇总方式和进入会评的规则可能随项目类型、年度和科学部组织方式变化。

不要迷信网上所谓“几个A必上会”“某个分数必资助”的固定公式。即使某些评审表存在等级或优先顺序，项目还要进入不同学科组、不同项目类型和不同年度资助计划中比较，不存在面向所有科学部、所有年度公开统一的“3A必上”定律。

### 11.7 函评意见互相矛盾怎么办

这是同行评议中正常但棘手的情况。例如：

- 一名专家认为科学问题原创，另一名认为前期证据不足；
- 一名专家非常熟悉算法，另一名更关注临床科学意义；
- 一名专家认为风险值得承担，另一名更看重可行性。

后续项目管理和会议评审会结合完整材料与多份意见进行综合判断。不能简单用平均情绪解释，也不能因为一份负面意见就断言有人“故意卡项目”。

## 十二、阶段7：从函评到会评

### 12.1 什么叫“上会”

“上会”是非正式说法，通常指项目在通讯评审后进入会议评审的候选范围。

它意味着项目已经跨过一个重要筛选阶段，但只意味着“有资格在会议中进一步比较”，不是“已被内定资助”。

### 12.2 为什么函评很好也可能不上会

可能涉及：

- 同领域高评价申请较多；
- 不同函评专家评价尺度存在差异；
- 项目与对应类型或资助方向的契合度；
- 当年该科学部、申请代码或项目类型的资助计划；
- 评审意见中存在需要综合判断的问题；
- 具体项目管理办法所规定的遴选方式。

最重要的事实是：资助是竞争性选择，不是达到某个固定及格分数后全部发放。一个项目“本身不错”与“在当年同组中进入优先资助范围”是两个层次。

### 12.3 “上会线”是什么

“上会线”也是非正式词，指形成会议评审范围时所用的相对门槛。它不是一个适用于全国所有学科的公开统一分数线。

不要把它类比为考研国家线。项目类型、科学部、学科组、申请规模、专家评价分布和年度资助计划不同，所谓“线”会不同，而且最终执行规则应以基金委内部正式程序为准。

## 十三、阶段8：会议评审，也叫会评

### 13.1 会评的本质

会评是基金委组织同行专家以会议形式，对进入相应范围的项目进行集体评议。它解决的是函评难以单独解决的三个问题：

1. **把分散的专家意见放在一起综合判断；**
2. **在同领域或同类项目之间横向比较；**
3. **在有限资助计划下形成建议资助顺序或名单。**

### 13.2 会评专家通常会看到什么

具体材料依项目类型而异，通常可能包括：

- 申请书；
- 通讯评审意见和评价结果；
- 项目类型与指南要求；
- 必要的管理信息；
- 需要答辩项目的陈述或答辩情况；
- 预算评审材料；
- 当年资助计划和分组安排。

### 13.3 会评现场大致在做什么

在不涉及保密细节的抽象层面，可以理解为：

```text
工作人员说明规则、回避和纪律要求
        |
专家阅读项目及函评材料
        |
主审/相关专家介绍关键问题（具体组织形式依项目而异）
        |
专家组讨论科学价值、创新性、可行性和争议点
        |
需要答辩的项目进行答辩和提问
        |
专家按规定进行判断、排序、表决或形成评审建议
        |
形成会议评审意见或建议资助方案
```

会评不是几个专家随意聊天。它受项目管理办法、专家回避、保密、评审纪律和会议程序约束。

### 13.4 会评为什么强调“横向比较”

函评专家可能只看到分配给自己的若干份申请，会评则需要在更大的候选范围内比较：

- 哪个科学问题更重要；
- 哪个创新更实质；
- 哪个方案更能回答问题；
- 哪些项目高风险但值得支持；
- 哪些项目只是包装得好，科学增量有限；
- 在有限经费下应优先支持哪些项目。

因此，一份项目在函评中“评价不错”，到会评时仍可能因为同组竞争项目更强而未被建议资助。

### 13.5 会评是不是一定有答辩

不是。会评是专家会议评审；答辩是部分项目在会评中的一个环节。二者关系可以写成：

```text
会评
|- 不需要申请人答辩的会议评审
`- 包含申请人答辩的会议评审
```

面上、青年C类等常规项目不能想当然地套用人才类、重点重大类项目的答辩经验；最终看当年项目指南和通知。

### 13.6 会评通过是否已经正式获批

严格地说，还没有。会议专家形成的是评审意见或建议资助结果，之后还要经过项目管理汇总和基金委审批程序。科研人员口头说“会评过了”，通常是指学术评审阶段形成了积极建议，不等同于已经收到正式批准资助通知。

## 十四、评审中的回避、保密和禁止请托

### 14.1 为什么要回避

同行评议不可避免地发生在一个相对有限的学术共同体中，专家可能与申请人存在同单位、合作、师生、亲属、竞争或其他利益关系。回避制度的目的不是假定所有专家会徇私，而是减少利益冲突及对公正性的合理怀疑。

具体回避情形和操作以现行条例、评审回避与保密制度及当年要求为准。专家发现存在规定的利益冲突时，应按规则回避；项目管理部门也会根据系统信息和申报材料处理回避关系。

### 14.2 为什么申请人不能打听专家

基金委项目评审问答列出的科研人员禁止行为包括：

- 打探通讯评审和会议评审专家及名单；
- 打探评审分组、尚未公开的结果、会评时间地点和讨论意见；
- 本人或委托他人向专家、管理人员游说、说情、送礼或行贿；
- 收到答辩通知后至会评结束前，与规定回避关系以外的专家开展请教、咨询等学术交流活动；
- 实施或参与“围会”；
- 协助他人或单位实施请托；
- 实施其他法律法规禁止的行为。

依托单位也不得打探、收集评审专家信息，不得组织、纵容请托，不得阻碍相关调查。

### 14.3 正常学术交流和请托的界线

一般学术会议、公开论文讨论当然是科研活动的一部分。但当交流的目的转变为影响具体项目评审、获取未公开信息、绕过正式程序或施加人情压力时，就越过了界线。

最稳妥的原则是：

- 不猜评审人；
- 不找关系问结果；
- 不让导师、同事或朋友代为说情；
- 只通过基金委和依托单位正式渠道查询；
- 对程序异议使用复审、投诉或科研诚信举报渠道。

## 十五、阶段9：形成建议资助方案和基金委审批

会议评审结束后，相关项目管理部门依据：

- 申请材料；
- 通讯评审意见；
- 会议评审意见；
- 项目管理办法；
- 年度资助计划；
- 预算评审或其他必要审查结果；

按程序形成拟资助建议或相关审批材料。

2026年度结果通告明确写明：根据《国家自然科学基金条例》、相关项目管理办法和专家评审意见，经基金委委务会议审批，作出资助决定。

这里存在两个同时成立的事实：

1. 学术同行评议是资助决策的重要基础；
2. 最终结果需要由基金委依法依规审批，而不是某一位函评专家、会评专家或项目管理人员个人决定。

## 十六、阶段10：结果公布和个人通知

### 16.1 2026年实际怎么公布

2026年8月26日结果通告说明：

- 依托单位科研管理人员和申请人可登录科学基金网络信息系统查询结果；
- 基金委于8月26日至28日使用 `report@pro.nsfc.gov.cn` 向申请人发送批准资助通知、不予资助通知和专家评审意见；
- 随后向依托单位寄发纸质资助结果通知，并附资助项目清单和不予资助项目清单。

### 16.2 “公布”和“公示”不是同一个词

科研人员常说“名单公示”，但2026年度集中接收项目官方文件使用的是“评审结果通告”“查询结果”“通知”。不能据此假定所有项目在批准前都有一个面向社会、等待异议的统一“拟资助名单公示期”。

部分专项、人才计划或其他项目可能另有公示安排，应看对应指南。普通集中接收项目以基金委当年结果通告和信息系统为准。

### 16.3 为什么有的人先知道、有的人后收到邮件

系统开放、邮件批量发送和学校科研管理部门接收通知存在时间差。正式判断应以信息系统和基金委通知为准，不应以朋友圈截图、群聊消息或邮件到达先后推断结果。

### 16.4 2026年度结果数字怎么读

基金委2026年结果通告称：经初审和复审后共受理469,429项；经委务会议审批，面上项目、青年科学基金项目（A、B、C类）、地区科学基金项目、重点项目等10类项目共资助69,563项。

这不能简单计算成“2026年全部国自然最终资助率”，因为同一通告明确说明：集中接收期间接收的其他类型项目仍在评审或审批中。计算资助率必须保证分子和分母是同一项目范围、同一统计口径。

## 十七、阶段11：不予资助项目复审

### 17.1 不予资助与不予受理不同

| 结果 | 含义 |
| --- | --- |
| 不予受理 | 申请在资格、限项、材料或其他受理规则上未通过初审，通常没有进入完整学术评审 |
| 不予资助 | 申请已经受理并经过相应评审、审批程序，但最终没有获得资助 |

### 17.2 复审不是“让另一批专家重新打分”

2026年度结果通告和项目复审问答明确：具有以下情形之一的不予资助复审申请不予受理：

- 不是项目申请人本人提出；
- 超过规定截止日期；
- 复审申请内容或手续不全；
- 只是对评审专家的评审意见等学术判断持不同意见。

最后一条非常关键。比如申请人认为“专家不认可我的创新点，所以专家错了”，这通常属于对学术判断的不同意见，不能据此要求复审。

可进入复审讨论的重点通常是：是否存在程序错误、事实认定错误、回避规则问题、管理办法适用错误或者其他影响资助决定合法合规性的情形。具体是否受理和如何审查，由相关项目管理部门按复审办法处理。

### 17.3 2026年度不予资助复审程序

1. 8月26日至9月15日16时在线填写并提交复审申请；
2. 打印一份与电子版一致的复审申请表；
3. 申请人本人签字；
4. 按要求快递至相关项目管理部门综合与战略规划处；
5. 相关部门受理和审查；
6. 11月6日前书面通知申请人结果；
7. 依托单位科研管理部门可在系统查看提交和处理情况。

复审不是情绪申诉。有效复审申请需要指出明确的规则、事实、程序和证据。

## 十八、如何理解专家意见

### 18.1 专家意见不是逐字都正确，也不是可以忽略

同行评议是一种专业判断制度，不是数学证明。专家可能存在理解偏差，也可能指出申请人没有写清的问题。

申请人收到意见后，建议分成四类：

| 意见类型 | 应如何处理 |
| --- | --- |
| 明确事实错误 | 核对申请书是不是本身表达不清；如涉及程序性严重问题，再判断是否符合复审范围 |
| 多名专家重复指出的问题 | 高优先级修改，通常说明问题确实没有说服同行 |
| 学术路线分歧 | 补充论证、实验或风险控制，不能只说专家“不懂” |
| 评价很好但未资助 | 认识到竞争性和名额约束，继续完善后再申报 |

### 18.2 “感谢专家，意见都接受”也不是科学态度

你可以不赞同某个学术判断，但需要用数据、文献、理论和更清晰的论证回应。对下一年度申请而言，重点不是反驳专家本人，而是让下一位同行不再产生相同疑问。

### 18.3 为什么反馈意见未必包含会评全部讨论

申请人收到的通常是按规定反馈的专家评审意见，不等于会议现场的逐字记录。会评分组、过程、讨论和未公开信息受保密规则保护。

## 十九、最常见的错误理解

### 误区1：“学校通过了，基金委基本就会受理”

不对。学校审核是依托单位内部审查；基金委仍要进行初审并决定受理或不予受理。

### 误区2：“受理了，说明选题没问题”

不对。受理主要表示符合进入评审流程的基本条件，不代表科学价值已获认可。

### 误区3：“函评有三个好评，就一定上会”

不对。没有适用于所有项目、所有科学部和所有年度的统一民间公式。还涉及评价内容、项目类型、学科组和资助计划。

### 误区4：“上会就是中了”

不对。上会只是进入会议评审范围。会评需要横向比较并形成建议，之后还要审批。

### 误区5：“会评就是申请人现场答辩”

不对。答辩只是部分项目会评中的环节，不是会评的同义词。

### 误区6：“复审就是重新找专家评价创新性”

不对。仅仅不赞同专家的学术判断，不属于不予资助复审的有效理由。

### 误区7：“认识会评专家就应该提前沟通”

严重错误。打探专家、请托、说情、围会和获取未公开信息属于明确禁止的行为，可能触发科研诚信和纪律处理。

### 误区8：“论文多就一定能中”

不对。前期成果是能力和可行性的证据，但项目仍要回答新的科学问题。成果数量不能替代科学问题、创新性和研究设计。

### 误区9：“模型指标比别人高，就是合格的国自然科学问题”

不一定。指标提升可能只是工程结果。需要进一步解释为何提升、反映了什么新机制、解决了什么普遍性科学问题，以及怎样通过实验排除其他解释。

### 误区10：“结果公布后，所有申请书和专家名单都会公开”

不对。申请材料、专家身份和评审过程涉及保密、知识产权和个人信息。公开范围以法规和基金委平台规则为准。

## 二十、把全流程看成三道不同的门

这是最简洁、也最不容易记错的理解方式。

### 第一扇门：能不能进入比赛

```text
资格 + 限项 + 材料 + 伦理 + 诚信 + 提交程序
```

由申请人、依托单位和基金委初审共同把关。结果是“受理”或“不予受理”。

### 第二扇门：科学上值不值得支持

```text
科学价值 + 创新性 + 可行性 + 研究基础 + 项目定位
```

主要由通讯评审和会议评审的同行专家判断。

### 第三扇门：在有限资助计划下是否进入最终资助范围

```text
同行评议结果 + 同组横向比较 + 项目管理规则 + 年度资助计划 + 正式审批
```

由会议评审建议、项目管理组织和基金委审批共同完成。

一个项目可能通过第一扇门，但未通过第二扇门；也可能学术评价不差，但在第三扇门的竞争中未进入最终资助范围。

## 二十一、作为硕士研究生，你现在最值得做什么

你当前不能把目标设成“马上以自己名义申请一个普通国自然”，但完全可以提前训练未来申报所需的能力。

### 21.1 参与导师项目时，观察完整证据链

尝试弄清：

- 导师为什么选这个项目类型；
- 科学问题如何从文献和前期数据中产生；
- 为什么选择某个申请代码；
- 研究目标如何拆成研究内容；
- 每个实验怎样回答一个具体问题；
- 伦理审批和医疗数据许可怎样落实；
- 函评意见如何转化为下一版申请书修改。

### 21.2 把医学图像分割研究从“做模型”提升到“研究问题”

例如，不只问：

> 哪个注意力模块能把Dice提高0.5个百分点？

而要继续追问：

> 医学影像中哪些解剖结构、尺度变化、边界不确定性或域偏移机制导致现有表征失效？新的模型机制如何针对这个原因？怎样设计实验才能证明改进来自所提出机制，而不是参数量、数据增强或随机波动？

后者才更接近可被基础研究资助体系评议的科学问题。

### 21.3 学会区分“我的贡献”和“团队项目”

简历或面试可以写：

- 参与某国自然项目中的数据处理、模型研究或实验验证；
- 在导师指导下负责某一研究任务；
- 参与申请书前期数据准备或技术路线论证。

不要写成“主持国自然”或“本人获批国自然”，除非你确实是批准通知中的项目负责人。

### 21.4 关注新疆地区的未来机会，但不要误读资格

以后如果你毕业并在新疆符合条件的依托单位全职从事科研，可以同时关注：

- 青年科学基金项目（C类）；
- 地区科学基金项目；
- 面上项目；
- 与信息、医学、交叉领域有关的联合基金或专项。

届时应重新核对申请年度的年龄、学位/职称、限项、工作时间、依托单位和项目指南。2026年的规则不能自动当作你几年后申请时的规则。

## 二十三、最后的完整总结

国自然项目不是“交一份本子，几个专家打个分，然后公布名单”这么简单。它包含三类审查：

1. **管理与资格审查**：申请人、依托单位和基金委共同保证资格、材料、限项、伦理、诚信和程序合规；
2. **同行学术评议**：通讯评审专家独立评价，会议评审专家在此基础上集体讨论和横向比较；
3. **组织审批和结果管理**：项目管理部门按规则形成材料，基金委委务会议审批，并通过系统、邮件和依托单位通知结果。

“会评”位于流程中后段，是把分散函评意见放到同一专家会议中综合比较，并在资助计划约束下形成建议的关键环节。它很重要，但既不是申请人资格审查，也不是最终行政审批；进入会评值得肯定，但不等于正式获批。

对于你这样的计算机专业全日制硕士，当前最现实的角色是项目研究参与者和未来申请能力的学习者。先把科学问题、严谨实验、医学数据伦理、可复现性和个人真实贡献做好。等将来具备申请资格时，你面对的就不再是一个陌生的“会评黑箱”，而是一套可以逐层理解和准备的科研资助程序。
