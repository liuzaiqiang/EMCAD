# 医学图像分割：100 个小 Track 与论文手段

这份清单面向时间紧、算力有限、需要把实验推进到论文初稿的研究者。目标不是把每条都做完，而是从中挑一条主线和两三个能解释主线的验证，做出一个诚实、可复现、范围适当的研究故事。小改动不自动等于可发表创新；是否值得投稿取决于问题是否清楚、实验是否扎实、与已有工作的差异是否说得准。

## 先按最低可交付闭环行动

1. 先跑通一个可信 baseline：固定患者级划分、预训练状态、输入尺寸、增强、训练预算和验证选模规则。
2. 选一条主 track，只改一个核心变量；优先从第 25-70 条里挑与现有代码最近的方向。
3. 做最少两个有解释力的验证：模块去除/替换、参数或计算量匹配、或一个预先定义的稳健性测试。
4. 主表报告 Dice 和至少一个边界指标（HD95 或 ASD），并给逐器官/逐病例结果、参数量、推理成本和失败案例。
5. 验证集负责选模型；测试集不用于挑 epoch、调阈值或反复筛方法。仓库当前 Synapse 训练流程使用名为 test_vol 的列表逐 epoch 验证，动手前先核实该列表是不是独立验证集。
6. 一次只改一个主要变量。保留失败实验、配置、命令、代码版本、随机种子、日志、checkpoint 和逐病例 CSV。结果不涨也如实解释，不要删掉失败 run。

### 本仓库的可对接位置

- lib/networks.py 负责编码器、EMCAD 解码器和多尺度输出头的装配；lib/decoders.py 有 MSCB、MSDC、EUCB、LGAG、CAB、SAB。
- trainer.py 包含 Synapse 训练、CE+Dice、深监督、验证和 checkpoint 选择。Synapse 常见标签语义是 9 类（背景加 8 个器官）；二分类任务通常是单通道 sigmoid。
- MSCB 的 kernel_sizes、expansion_factor、dw_parallel、add 是不同控制项。一次消融只动其中一个，注意 add 只控制 MSDC 分支聚合，不能和 skip 融合混为一谈。
- 若当前分支与以上描述不同，以你正在运行的文件、配置和日志为准；文档不是对当前实验结果的背书。

| 008 | 跨中心/设备留一测试 | 有中心元数据时留一个中心作外部测试；报告域内外差距和强度分布，不把随机切分称作外部验证。 |
| 009 | 标签质量敏感性 | 依据已有质量标注或盲法复核划分高低质量标签；报告两组误差，不按模型表现删病例。 |

## 中国高校场景下的投稿现实检查

- **毕业口径先问清。** 学校、学院、专业和入学年份的要求可能不同；确认论文类型、数据库口径、作者位次、署名单位、录用/见刊时间等具体条件，并保存研究生院或学院当年正式文件。
- **选 venue 看官方信息。** 逐年核对期刊/会议官网的主题范围、征稿通知、截稿日、页数、费用、伦理要求和出版时间；数据库收录状态以学校认可口径及官方数据库查询为准。
- **作者和数据权限早确认。** 先与导师确认研究问题、数据使用授权、作者顺序和投稿责任；涉及患者数据时遵守伦理审批、去标识化和数据使用协议。
- **远离“保录用”捷径。** 代写、买论文、虚构实验、重复投稿或伪造审稿人会让毕业和学术记录风险更大；时间紧时缩小问题和实验范围，保留真实结果。
- **不把经验当承诺。** 本文的 100 条是实验设计候选，不是投稿成功率、录用周期或毕业资格保证；最终以本校文件、导师意见和 venue 官方规定为准。

## 两周内的最小推进节奏

- **第 1-2 天：** 核实 split、标签映射、数据预处理和 baseline 评估；保存清单哈希、配置和逐病例指标。
- **第 3-5 天：** 只实现一条主 track；先做前向、损失、短训练和整病例验证检查，再跑完整预算。
- **第 6-8 天：** 完成模块去除/替换消融；若主结果无改善，停止追调并判断是否有明确的效率或边界收益。
- **第 9-10 天：** 固定协议补跑配对 seed 或一个扰动/效率实验；不因测试集表现改方法。
- **第 11-12 天：** 生成逐器官表、错误图、失败病例图和方法图；先写实验设置和结果。
- **第 13-14 天：** 写讨论与局限，核对投稿范围、格式、作者信息和引用；只提交已有证据支持的结论。

这是进度模板，不是对所有项目都能在两周内完成或发表的保证。若算力或时间更少，优先完成可信 baseline、一个主改动、一个关键消融和完整失败分析。

## 选题与止损规则

- **优先做可证伪的小问题：** “边界监督是否降低 HD95？”比“新模块能否全面提升性能？”更容易得到清晰结论。
- **优先邻近代码的改动：** 如果项目已有多尺度 decoder，先试一个有机制解释的尺度/边界/融合消融，不要为追热点重写整网。
- **主结果要有任务意义：** Dice 小幅变化但小器官召回明显提升、边界距离下降或同精度计算量下降，可能比单一均值更值得讨论；仍需公平对照。
- **设停止线：** 跑通 baseline 后，主 track 若在预设预算内没有稳定、可解释的改善，停止微调；报告负结果并转向更适合现有证据的研究问题。
- **不做结果操纵：** 不改测试标签、不挑 seed、不反复查看测试集、不隐去失败病例、不编造引用或显著性。论文可信度来自可追溯的实验，不来自更响亮的形容词。
