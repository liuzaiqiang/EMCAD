# 基于 EMCAD 快速形成 CCF-C 小论文的务实路线图（2026）

## 结论先行

最快的合法路线不是继续收集“创新模块”名字，而是建立一条窄而完整的证据链：修正实验协议风险，复现可信 EMCAD 基线，用逐病例错误定位一个稳定失败模式，只改一个对应机制，做最小消融、多 seed 和第二数据集验证，再写边界清楚的论文。录用不能保证，但这比“加一个注意力、跑一次 Dice、包装成 SOTA”更接近 CCF-C 审稿最低要求。

## 1. 立即停止的做法

1. 停止继续堆 CBAM、SE、边界损失、普通注意力等常见模块；EMCAD 已有 PVTv2、MSDC、MSCB、EUCB、LGAG、CAB、SAB 和多输出监督，简单替换容易被判为模块拼接。
2. 停止先写论文再找提升；先跑基线逐病例错误表。
3. 停止把一次最高 Dice 当结论；最终配置至少补 3 个 seed。
4. 停止同时改变数据、骨干、损失、增强和训练轮数，否则无法归因。
5. 停止把原论文数字当本地基线；当前代码、split、依赖和评价实现不同，必须以本地重跑值为准。

## 2. 先做协议体检

当前主链是 `train_synapse.py → lib/networks.py::EMCADNet → PVTv2/ResNet → lib/decoders.py::EMCAD → trainer.py`。

- 验证会调用 `model.eval()`，必须确认每个 epoch 下一轮训练前明确 `model.train()`；否则 BatchNorm/Dropout/DropPath 状态错误，修复前后的差异不能算创新。
- 当前训练器在 epoch 末用体数据评估并保存 `best.pth`。确认 `test_vol` 是验证清单还是最终测试清单；若是最终测试集，就是测试泄漏。应使用病例级 `train/val/test` manifest，val 选 checkpoint，test 在设计冻结后只评估。
- HD95/ASD 必须说明单位是 voxel 还是 mm；若评价函数未传入真实 spacing，不能写成毫米。用手工小例子验证 Dice、IoU、HD95、空类别和全空预测。
- 保存 Python/PyTorch/CUDA、GPU、依赖、git commit、未提交 diff、命令、manifest、seed 和配置。当前训练目录被简化为 `model_pth/run_seed{seed}`，务必额外保存 `config.json` 防止覆盖。

## 3. 用 48 小时定位真实弱点

先跑原始 EMCAD 单 seed，不加模块。保存每病例、每器官 Dice/HD95、预测 mask 和误差图。

| 观察 | 可能问题 | 方向 |
|---|---|---|
| 小器官 Dice 低、HD95 高 | 小目标/边界恢复不足 | 边界或高分辨率 skip |
| 内部正确、边缘断裂 | 解码恢复不足 | 边界条件融合 |
| 相邻切片跳变 | 2D 缺少上下文 | 轻量 2.5D |
| 外部集掉点 | 域偏移 | 归一化/鲁棒性 |
| 四输出差异大 | 监督冲突 | 一致性监督 |
| 显存/速度瓶颈 | 结构成本高 | 轻量化 |

只有趋势在至少 20 个病例或全部验证病例中稳定，才立项；两张失败图不够。

## 4. 只押一个主线：BGSF

推荐 **Boundary-Guided Skip Fusion（BGSF）**：在 EMCAD 的高分辨率 skip 融合前加入显式边界/区域条件，减少浅层背景纹理干扰并保留真实边缘。理由是 EMCAD 的 LGAG 已做空间门控，但解码主路与筛选 skip 仍固定相加；该接口清晰，Synapse、ACDC 和病灶任务都能验证，且不必重写 PVTv2。

张量定义必须可实现：

```text
g_i：上采样解码特征；s_i：编码器 skip
b_i：由 [g_i,s_i] 预测的边界图；r_i：区域可靠性图
f_i = g_i + (1-b_i) ⊙ r_i ⊙ s_i + b_i ⊙ s_i
```

这是待验证假设，不是保证有效的公式。先做 shape、梯度、显存 smoke test；若过复杂，删掉 `r_i`，不要继续堆分支。边界标签只由训练集 mask 通过形态学梯度或腐蚀/膨胀差得到，宽度预先固定（如 1—2 个 resized pixel），测试集不得参与阈值或后处理选择。

损失先用 `L=L_seg+λ_ds L_ds+λ_b L_boundary`，只在验证集比较少量 `λ_b`（如 0.1/0.2/0.4），最终锁定一个。

## 5. 最小可投稿实验包

### 阶段 A：单 seed 筛选（第 1 周）

| 编号 | 配置 | 目的 |
|---|---|---|
| A0 | 原始 EMCAD | 本地基线 |
| A1 | EMCAD + 参数量匹配普通卷积融合 | 排除参数增加 |
| A2 | EMCAD + BGSF，去掉边界监督 | 验证边界分支必要性 |
| A3 | EMCAD + 完整 BGSF | 主方法 |

四行必须同 split、seed、输入 224、优化器、epoch、增强、监督和 checkpoint 规则。若 A3 无整体 Dice/HD95 或困难器官的一致改善，立即止损。

### 阶段 B：主数据集（第 2 周）

A0 与 A3 各补 2 个 seed，报告病例级 mean±std、每器官 Dice、HD95、参数量、FLOPs、峰值显存和推理时间，保留全部运行。

### 阶段 C：异质数据集（第 3 周）

优先 ACDC（心脏 MRI）或明确的二分类病灶集。只做 EMCAD 基线、EMCAD+BGSF、3 seed 主指标和复杂度。失败结果不能删除，应写入适用边界。

### 阶段 D：对照与定性（第 4 周）

引用 2—4 个公开方法并标注 `reported`；展示预先定义的成功、一般、失败病例各 2—3 个（原图、GT、EMCAD、BGSF、误差图）。解释图只能佐证机制，不能替代统计。

## 6. 论文收缩方式

标题可用：*Boundary-Guided Skip Fusion for Improving Boundary Reliability in EMCAD-based Medical Image Segmentation*。不要写“通用医学分割”“全面 SOTA”“临床可用”，除非有跨机构和临床流程证据。

论文必须回答：EMCAD 哪种错误最稳定？LGAG+固定加法为何可能造成它？BGSF 哪个机制针对原因？消融、seed、异质集和失败案例是否排除了参数量、随机性和泄漏？

最低表图：数据与 split 表；A0/A1/A2/A3 主指标和复杂度表；3-seed 均值标准差表；第二数据集表；方法张量流图；学习曲线和典型误差图；附录放命令、超参数、失败运行和评价实现。

## 7. 四周冲刺与止损

- 第 1—2 天：锁定 manifest、环境、smoke test、指标和 baseline 配置。
- 第 3—7 天：完成 A0 和错误画像，只选一个方向。
- 第 8—14 天：按 A1→A2→A3 单 commit 实现和消融。
- 第 15—21 天：补 3 seed 与第二数据集。
- 第 22—28 天：冻结代码，重跑关键表，整理失败、限制和复现包。

出现以下任一情况就停止：3 seed 平均无提升；提升只来自一个器官/一次 seed；依赖测试集调参；成本增幅远大于收益；第二数据集完全失败且无法收窄主张；干净目录无法重跑。止损是节省时间，不是失败。

## 8. 2026 年 AI 加速但不毁掉论文

AI 可用于生成审计脚本、shape 检查、指标单测、结果汇总、文献检索式和语言初稿；不能替你决定标签、病例是否泄漏、checkpoint/阈值、统计结论或临床意义。保存工具名/版本或日期、提示词、输入是否含敏感数据、输出、人工修改和最终采用位置。不要上传患者图像、DICOM 头、未发表稿件、审稿材料或密钥到未经批准的公共模型；投稿按目标期刊披露 AI 辅助，AI 不能列为作者。
