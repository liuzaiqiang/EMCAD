# 不确定性加权多尺度深监督

## 目标与边界

本实验只调整 EMCAD 四个深监督输出的损失汇总方式，不增加网络层、不改变推理输出，也不修改内容感知抗混叠上采样（CAA）。模型训练输出顺序为 `[p4, p3, p2, p1]`。开关为 `USE_UNCERTAINTY_WEIGHTED_DS=0/1`，默认 `0`。关闭时保留选定监督策略的原始行为；选定 `deep_supervision` 时关闭开关才是四头等权深监督。

截至本次修改，已接入全部 12 个数据集。此前版本仅完整接入了 Synapse，ACDC 曾处于部分接入状态。之后的相关功能修改默认覆盖下面全部入口，此约定已写入仓库根目录 `AGENTS.md`。

## 核心计算与解释

权重只使用当前训练批次的 logits 和本次训练累计的熵 EMA，不读取验证集或测试集标签。对每个头计算归一化预测熵，使用 `EMA=0.9` 平滑，再按温度 `0.25` 将负熵经 softmax 转为相对置信度。与均匀分配混合后再乘以四个输出头的数量，得到最终损失权重：

```text
s = softmax(-EMA_entropy / 0.25)
w = 4 * (0.8 * [0.25, 0.25, 0.25, 0.25] + 0.2 * s)
L = sum_i(w_i * L_i)
Synapse / ACDC: L_i = 0.3 * CE_i + 0.7 * Dice_i
其他 10 个二分类数据集: L_i = 原 structure_loss（加权 BCE + 加权 IoU）
```

每个权重限制在 `[0.8, 1.6]`，四个权重之和为 4、均值为 1。它只在四个尺度之间重新分配监督贡献，保持总监督权重不变；当各头的损失不同，加权后的实际总损失可以变大或变小，并不保证与原损失数值相同。20% 的自适应分配和 80% 的均匀分配防止某个头独占监督，低置信头仍获得至少 0.8 的权重。

多分类熵为 `-sum_c(p_c*log(p_c))/log(C)`；二分类熵为 `-[p*log(p)+(1-p)*log(1-p)]/log(2)`。每个头对 batch 和空间位置取平均，得到尺度级标量。首次更新直接初始化 EMA，后续为 `0.9*旧值+0.1*当前值`。本版本采用预测熵，不包含 MC dropout、跨随机前向方差、边界标签权重或额外预热机制。计算使用 float32，且在 `torch.no_grad()` 中执行，权重不反向传播；梯度仍通过被加权的原始损失传给模型和 CAA。

一个生活中的具体例子：四个人批改试卷，各自负责一种尺度的检查。某人近期判断比较稳定，监督贡献可以稍大，但不能把其他三个人全部排除。这里用的是“判断时是否犹豫”，并非“答案是否正确”：自信的人也可能犯错。对应到分割，低熵输出也可能自信地漏掉器官，背景占比很大时平均熵还可能掩盖前景错误，因此这个机制只是假设，效果尚未验证。

代码不修改 CAA 模型、数据划分、增强、基础损失、学习率、随机种子、验证指标或 checkpoint 选择规则。另补齐了 BUSI 的 `PYTHON_BIN/N_GPU` 及 ISIC 的 `N_GPU` 默认值，避免独立启动时因 `set -u` 变量未定义而退出；显式传入值仍优先。

## 统一开关与两组主实验

每个训练启动脚本都接受同一组环境变量：

```bash
# A：CAA + 固定等权四头深监督
SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=0 SEED=2222 bash sh/start_train_synapse.sh
# B：CAA + 不确定性加权四头深监督，只改 0 -> 1
SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 SEED=2222 bash sh/start_train_synapse.sh
```

在已有 CAA 基线本来就是 `deep_supervision` 时，直接比较 A/B。若已有 CAA 基线使用 `mutation` 或 `paper`，保留那组实际基线，再增加 A 作为中间对照，才能区分监督策略改变和动态权重各自的贡献。不要把原基线静默改成四头深监督。二分类 `paper` 包含四个单头损失及四头 logits 求和后的第五项损失，本机制只给四个单头分配权重，所以开关 `1` 与 `paper/mutation/last_layer` 组合会明确报错。

切换数据集时保持参数相同，只更换启动脚本和 `DATASET_NAME`，例如：

```bash
SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 bash sh/start_train_acdc.sh
DATASET_NAME=Kvasir SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 bash sh/start_train_polyp.sh
SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 bash sh/start_train_busi.sh
DATASET_NAME=ISIC2017 SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 bash sh/start_train_isic.sh
DATASET_NAME=EM SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 bash sh/start_train_cell.sh
```

使用队列时这些环境变量同样可透传：

```bash
DATASET_NAME=ClinicDB SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=0 bash sh/run_seed_queue.sh polyp 2222 3407 5678
DATASET_NAME=ClinicDB SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 bash sh/run_seed_queue.sh polyp 2222 3407 5678
```

两个队列各自顺序运行，若要同时跑，使用各自的 GPU 和原有 batch 配置。熵 EMA 属于本次训练的历史，不写入模型 state_dict；当前 checkpoint 加载机制也不新增 EMA 续训恢复支持。测试时按原有 CAA 参数加载对应模型。

## 实验对照

以 Synapse 的 `mutation` 基线为例，三组使用相同的划分、预处理、初始化权重、优化器、训练轮数、CAA 设置和配对种子：

```bash
SUPERVISION=mutation USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=0 SEED=2222 bash sh/start_train_synapse.sh
SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=0 SEED=2222 bash sh/start_train_synapse.sh
SUPERVISION=deep_supervision USE_CONTENT_AWARE_ANTIALIAS=1 USE_UNCERTAINTY_WEIGHTED_DS=1 SEED=2222 bash sh/start_train_synapse.sh
```

第一组是现有 CAA + mutation 基线；第二组隔离普通四头深监督相对于该基线的影响；第二、三组之间只切换不确定性加权开关，可判断动态权重是否优于等权深监督。对每个种子配对运行三组。`.sh` 会拒绝非 `0/1` 值；开关设为 `1` 时也要求 `SUPERVISION=deep_supervision`。实际启动日志中应核对三个参数：`SUPERVISION`、`USE_CONTENT_AWARE_ANTIALIAS`、`USE_UNCERTAINTY_WEIGHTED_DS`。

## 记录与判定

TensorBoard 记录每个训练 step 的 `train/uncertainty_ds_weight_p4` 至 `p1` 和对应的 `train/uncertainty_ds_entropy_p4` 至 `p1`。检查权重是否有变化、是否长期触及边界，以及熵曲线是否异常。建议至少比较多个配对种子的患者级 Dice、HD95，并保留每病例结果和验证集 checkpoint 选择记录；同时核实当前验证列表确实不是测试集。

机制消融必须包括固定等权、预先定义的手工衰减权重和随机权重对照，才能区分“有权重”与“基于熵的动态分配”各自的贡献。固定等权已通过开关 `0` 提供；本次开关 `1` 只实现熵权重，手工及随机权重尚无独立启动模式，不能把它们写成已完成的实验。后续实现时同样覆盖全部 12 个数据集，并保持权重总和及上下限可比较；随机对照应使用独立随机数流，避免改变模型初始化、数据增强或采样的随机序列。

不要用训练损失、单个种子或切片级均值宣称提升。Synapse/ACDC 比较病例重建后的 Dice、HD95；二分类按现有数据划分及样本级评估，并在有患者标识时按患者配对汇总，不能把没有患者 ID 的图像级划分描述成患者级划分。Dice 越大越好，HD95 越小越好；两者可能不同向变化，分别保留逐病例结果。多种子结果完成前，结论应写“效果尚未验证”。
