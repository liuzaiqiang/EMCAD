# 内容感知抗混叠上采样（CAA）候选方法

日期：2026-09-28  
当前分支：`base_cgc_for_try5_2`  
方法状态：候选方法，效果待 Synapse/ACDC 正式实验验证

> 我可以看到用户提供的两张截图。截图内容是：先替换 EMCAD 的 `EUCB3/EUCB2/EUCB1`，在特征级上采样中加入抗混叠低通和内容感知残差；暂时不修改四个 logits 的最终插值。本文档按这个边界实现。

## 1. 研究问题和主假设

当前 EMCAD 的三处 EUCB 使用：

```text
最近邻二倍插值 -> depthwise 3x3 -> BatchNorm/ReLU -> 1x1 通道投影
```

在低分辨率特征恢复到更高分辨率时，固定最近邻采样不能根据局部边界、细小器官或纹理内容改变采样方式，可能带来阶梯边缘、细节平滑和位置偏差。

本候选方法只检验一个主因素：

> 在 EMCAD 的三处特征级 EUCB 中，用固定抗混叠基底配合由当前 decoder 特征生成的内容门控局部残差，是否能在相同训练协议下稳定改善患者级总体 Dice。

这不是四个输出头的权重融合，也不是额外监督、边界损失或新的数据划分。

## 2. 代码实现

### 2.1 完整 CAA 路径

对输入 `x ∈ R^[B,C,H,W]`，完整 `caa` 模式执行：

```text
固定 3x3 binomial 低通滤波
    -> bilinear 二倍上采样（align_corners=False）得到 u
    -> 1x1 内容门控生成 g=Sigmoid(G(u))
    -> depthwise 3x3 局部残差 r=D(u)
    -> y = u + clamp(alpha, 0, 1) * g * r
```

其中：

- 低通核为 `[[1,2,1],[2,4,2],[1,2,1]] / 16`，按通道独立应用；
- `g` 是 `[B,1,2H,2W]`，广播到所有通道；
- 每个 EUCB 的 `alpha` 是该尺度独立的可学习残差幅度，初始值由 `--caa_residual_scale` 指定；
- `G` 和 `D` 都只作用于特征图，不读取标签，不产生 logits；
- 输出仍是 `[B,C,2H,2W]`，后续仍进入原有 EUCB depthwise/BN/ReLU、1x1 projection、LGAG 和 MSCB。

`content_only` 使用原始最近邻基底加内容残差，用来分离“内容自适应”因素；`aa_only` 只使用固定低通加 bilinear，不创建内容残差参数。

### 2.2 EMCAD 中的位置

只替换：

```text
EMCAD.d4 -> EUCB3 -> d3
EMCAD.d3 -> EUCB2 -> d2
EMCAD.d2 -> EUCB1 -> d1
```

不修改：

- encoder；
- LGAG、CAB、SAB、MSCB；
- 三处 skip 加法；
- 四个 segmentation head；
- `lib/networks.py` 中最终四个 logits 的 `F.interpolate`；
- loss、监督策略、metric、空类别处理、数据划分和 checkpoint 选择规则。

以 PVTv2-B2、224 输入为例，CAA 只改变以下空间恢复：

| EUCB | 输入 | CAA 输出 | 后续 skip 对齐 |
|---|---|---|---|
| EUCB3 | `[B,512,7,7]` | `[B,512,14,14]` | `x3=[B,320,14,14]` |
| EUCB2 | `[B,320,14,14]` | `[B,320,28,28]` | `x2=[B,128,28,28]` |
| EUCB1 | `[B,128,28,28]` | `[B,128,56,56]` | `x1=[B,64,56,56]` |

随后 EUCB 原有的 `1x1` 投影将通道变为 320、128、64。

## 3. 参数开关

训练和测试入口均增加：

```text
--caa_mode {off,aa_only,content_only,caa}
--caa_residual_scale FLOAT
```

模式定义：

| 模式 | EUCB 内部行为 | 用途 |
|---|---|---|
| `off` | 原始最近邻 + depthwise | EMCAD baseline |
| `aa_only` | 固定低通 + bilinear | 只检验抗混叠基底 |
| `content_only` | 最近邻 + 内容门控残差 | 只检验内容自适应残差 |
| `caa` | 固定低通/bilinear + 内容门控残差 | 完整候选方法 |

推荐初始值：

```text
caa_mode=caa
caa_residual_scale=0.1
```

`0.1` 是残差初始幅度，不是固定的最终权重；它会在训练中学习并被限制到 `[0,1]`。不要在正式测试集上反复调整该值。

## 4. 与 try5 像素级可靠性融合的关系

我通过 `git show try5:...` 读取了 try5 分支，没有切换当前分支。try5 的像素级可靠性多头融合位于四个全分辨率 logits 之后；CAA 位于 decoder 的 EUCB 内部，二者作用对象不同：

```text
encoder
  -> EMCAD decoder: EUCB(CAA) -> LGAG -> skip fusion -> MSCB
  -> 四个输出头
  -> logits
  -> try5 像素级可靠性多头融合（若之后合并）
```

CAA 没有读取或修改可靠性头、`fusion_mode`、融合辅助损失或四头推理逻辑。以后合并 try5 时，应保留独立开关：

```text
--caa_mode {off,aa_only,content_only,caa}
--fusion_mode {p1,fixed_sum,global_scalar,pixel_reliability}
```

第一阶段不要同时开启两个模块来宣称 CAA 的单独贡献。

## 5. 严格消融协议

### 阶段一：主假设

先运行同一固定 seed 的：

| 组 | `caa_mode` | 唯一改变 | 可回答的问题 |
|---|---|---|---|
| A0 | `off` | 原始 EMCAD EUCB | baseline 参考 |
| A3 | `caa` | 完整 CAA | CAA 整体是否改善总体 Dice |

两组必须固定：病例清单、预处理、输入尺寸、batch size、epoch、优化器、学习率、监督策略、随机种子、checkpoint 选择规则和评估实现。

### 阶段二：机制消融

只有 A3 值得复核时再运行：

| 组 | `caa_mode` | 解释 |
|---|---|---|
| A1 | `aa_only` | 抗混叠低通和 bilinear 是否足够 |
| A2 | `content_only` | 内容门控残差是否足够 |
| A3 | `caa` | 两个成分组合是否必要 |

如果 A1 已达到 A3，主张应缩小为抗混叠上采样；如果 A2 已达到 A3，不能声称低通与内容残差的组合是必要的。如果 A3 不稳定优于 A0，应报告负结果并停止堆叠。

### 结果底线

只有固定划分、相同 seed 配对、患者级总体 Dice 在多个 seed 上稳定改善，并且 A1/A2 支持预先声明的机制，才可以在论文中说 CAA 带来提升。

单个器官、单个 seed、边界指标、训练 loss、参数量或 forward smoke test 的改善，都不能单独证明总体 Dice 提升。

## 6. Linux `.sh` 修改位置

本次没有修改任何 `.sh`。在远程脚本的变量区加入：

```bash
CAA_MODE="${CAA_MODE:-caa}"
CAA_RESIDUAL_SCALE="${CAA_RESIDUAL_SCALE:-0.1}"
```

### Synapse 训练

在 `python -u train_synapse.py` 命令中，放在 `--supervision` 后：

```bash
  --caa_mode "${CAA_MODE}" \
  --caa_residual_scale "${CAA_RESIDUAL_SCALE}" \
```

完整 CAA：

```bash
CAA_MODE=caa CAA_RESIDUAL_SCALE=0.1 bash sh/start_train_synapse.sh
```

baseline：

```bash
CAA_MODE=off bash sh/start_train_synapse.sh
```

### Synapse 测试

在 `python test_synapse.py` 命令中加入同样两行。测试必须使用训练 checkpoint 对应的：

```bash
CAA_MODE=caa CAA_RESIDUAL_SCALE=0.1 bash sh/start_test_synapse.sh
```

并保持 `encoder、batch_size、max_epochs、base_lr、seed、supervision` 与训练目录一致。

### ACDC 训练和测试

在 `start_train_acdc.sh` 和 `start_test_acdc.sh` 的 Python 命令中分别加入：

```bash
  --caa_mode "${CAA_MODE}" \
  --caa_residual_scale "${CAA_RESIDUAL_SCALE}" \
```

ACDC 训练代码会将非 `off` 模式追加到 `run_name`，例如：

```text
acdc_seed2222_caa_caa_rs0.1
```

测试时 `--checkpoint` 必须指向该 run 的 `best.pth`。

## 9. 当前验证边界

远程服务器进入训练环境后，先执行静态检查：

```bash
python -m py_compile \
  lib/decoders.py lib/networks.py \
  train_synapse.py test_synapse.py \
  train_acdc.py test_acdc.py utils/acdc_utils.py trainer.py
```

再执行四模式的形状契约检查：

```bash
python - <<'PY'
import torch
from lib.networks import EMCADNet

x = torch.randn(1, 1, 224, 224, device='cuda')
for mode in ['off', 'aa_only', 'content_only', 'caa']:
    model = EMCADNet(
        num_classes=9, kernel_sizes=[1, 3, 5], expansion_factor=2,
        dw_parallel=True, add=True, lgag_ks=3, activation='relu6',
        encoder='pvt_v2_b2', pretrain=False,
        caa_mode=mode, caa_residual_scale=0.1).cuda().eval()
    with torch.no_grad():
        outputs = model(x)
    shapes = [tuple(output.shape) for output in outputs]
    print(mode, shapes)
    assert shapes == [(1, 9, 224, 224)] * 4
print('CAA output contract: PASS')
PY
```

该检查只证明模块能运行且没有改变四个输出的形状，不证明总体 Dice 提升。
