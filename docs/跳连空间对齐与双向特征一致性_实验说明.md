# EMCAD 跳连空间对齐与双向特征一致性实验说明

## 方法和开关

本分支移除 CAA 的网络类、模式、测试恢复参数和 `.sh` 开关，EUCB 恢复原始最近邻 ×2 上采样、深度卷积、BN、激活、1×1 投影。两个新开关均为零时不创建新增参数，最终预测仍用 `[p4,p3,p2,p1]` 的 `p1`。

**模块 A：可学习跳连空间对齐。** 在三个 EUCB 输出与其 skip 输入 LGAG 之前，将解码特征 `D`、编码 skip `S` 拼接，经 `3×3 卷积 → BN → ReLU → 3×3 卷积` 预测二维偏移 `Δ`。最后一层零初始化，初始位移为零；`2*tanh` 将每轴位移限制到当前特征网格 ±2 像素。`S'=grid_sample(S, q+Δ(q))`，随后仍用原 LGAG 门控和相加。目标是减小同一像素位置语义与边缘的空间错位。该模块在推理时也启用。**这不等于发现了真实器官形变**；用偏移图和边界误差检验实际作用。

**模块 B：双向特征一致性。** 仅在训练中计算辅助损失。前向把 skip 采样至解码网格，比较通道归一化的 `D` 与 `S'`；反向以 `-Δ` 近似将解码特征采样至 skip 网格，比较原 skip `S` 与反向结果 `D-`。两个方向分别停止目标特征的梯度，三个尺度求平均：

`L_bi=mean_scales 0.5*(||norm(D)-stopgrad(norm(S'))||²+||norm(S)-stopgrad(norm(D-) )||²)`；总训练损失为 `L_original + CONSISTENCY_WEIGHT*L_bi`。`-Δ` 仅为近似反向位移，**不是严格逆变换**。当模块 A 关闭、B 开启时比较原本未重采样的特征，这样两个开关可以独立消融。

训练入口的环境变量（保持现有 `.sh` 调用方式）：`USE_SKIP_ALIGNMENT=0/1`、`USE_BIDIRECTIONAL_CONSISTENCY=0/1`、`CONSISTENCY_WEIGHT=0.05`；默认前两者都为 1。消融本分支的两个模块时将两者置 0；若要严格复现**原始 EMCAD**，还应将现有脚本中的 `USE_PIXEL_RELIABILITY_FUSION=0` 等其他既有创新开关关闭，并核对原论文的监督和数据协议。所有四组消融必须保持这些既有开关相同。训练产出的 `config.json` 记录参数，测试脚本从 checkpoint 相邻配置恢复结构。新旧结构的 checkpoint 不要混用。

## 12 个数据集与连续种子

| 数据集 | 原有启动器 | `run_seed_queue.sh` 键 |
|---|---|---|
| Synapse | `sh/start_train_synapse.sh` | `synapse` |
| ACDC | `sh/start_train_acdc.sh` | `acdc` |
| ClinicDB、Kvasir、ColonDB、ETIS、BKAI | `sh/start_train_polyp.sh`，设置 `DATASET_NAME` | `polyp` |
| ISIC2017、ISIC2018 | `sh/start_train_isic.sh`，设置 `DATASET_NAME` | `isic` |
| BUSI | `sh/start_train_busi.sh` | `busi` |
| DSB18、EM | `sh/start_train_cell.sh`，设置 `DATASET_NAME` | `cell` |

五个息肉数据集、两个 ISIC 加其余五个，共 12 个；Cell 沿用 Polyp 二分类训练核心。测试沿用对应 `sh/start_test_*.sh` 与原有 `CKPT` 等变量。队列无须新命令，例如：

```bash
USE_SKIP_ALIGNMENT=0 USE_BIDIRECTIONAL_CONSISTENCY=0 bash sh/run_seed_queue.sh synapse 2222 3333 8899
USE_SKIP_ALIGNMENT=1 USE_BIDIRECTIONAL_CONSISTENCY=1 bash sh/run_seed_queue.sh synapse 2222 3333 8899
DATASET_NAME=Kvasir USE_SKIP_ALIGNMENT=1 USE_BIDIRECTIONAL_CONSISTENCY=1 bash sh/run_seed_queue.sh polyp 2222 3333 8899
DATASET_NAME=DSB18 USE_SKIP_ALIGNMENT=1 USE_BIDIRECTIONAL_CONSISTENCY=1 bash sh/run_seed_queue.sh cell 2222 3333 8899
```

同一组 seed 分别运行 `(A,B)=(0,0),(1,0),(0,1),(1,1)`，并保持数据划分、预训练权重、输入尺寸、训练轮数、batch、监督策略一致。仅用验证集选 checkpoint，固定后再评估测试集，不以测试 Dice 调整开关或损失权重。

## 怎么判断是否达到目的

1. 主要终点为患者级平均 Dice，次要终点为 HD95、小器官逐类 Dice。Synapse 分别报告胆囊/胰腺等八类，ACDC 分别报告 RV/Myo/LV；二分类加边界 F1/IoU。给每个 seed 和逐病例配对差值、均值与置信区间。
2. 模块 A：在同一验证病例上可视化三层位移幅值、对齐前后 skip/decoder 边界响应；记录零位移比例、均值、95 分位、达到 ±2 上限比例。与同参数量的无采样卷积对照。若位移普遍零/饱和，不能把性能变化归因于有效对齐。
3. 模块 B：单独记录原分割损失、一致性损失和三层特征余弦相似度，比较 B 单独开启与 A+B。辅助损失下降但 Dice/HD95 不改善，不算验证成功。预先在验证集试 `CONSISTENCY_WEIGHT=0,0.01,0.05,0.1`，检查过强正则是否抹去浅层边缘。
4. 报参数量、FLOPs、推理耗时与显存；重点确认小器官/边界的提升是否超出训练波动，并说明在所有 12 个数据集上的正反结果。

## 相关文献和新颖性

原始网络为 [EMCAD, CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Rahman_EMCAD_Efficient_Multi-scale_Convolutional_Attention_Decoding_for_Medical_Image_Segmentation_CVPR_2024_paper.html)。可学习跳连与语义差距已有研究，如 [UDTransNet, Neural Networks 2024](https://www.sciencedirect.com/science/article/pii/S0893608024004702)；可微空间重采样源自 [Spatial Transformer Networks, NeurIPS 2015](https://proceedings.neurips.cc/paper_files/paper/2015/hash/33ceb07bf4eeb3da587e268d663aba1a-Abstract.html)。本实现的有界偏移、插入 LGAG 的位置、反向近似和两向 stop-gradient 是基于上述思路的**本项目组合设计**，未从某一篇论文直接复制；不能宣称这些基本思想首次提出。投稿前需做完整近作查重与公平实验。方法代码完成不代表已产生 Dice 提升。

## 环境

在原有服务器 EMCAD 环境中运行；项目仓库不包含医学数据与 PVTv2 预训练权重。先确保原始数据目录、`pretrained_pth/pvt/pvt_v2_b2.pth` 等依赖已准备。A 开启时需用本分支训练生成的新 checkpoint；测试需携带同目录 `config.json`。原先训练过 CAA 的 checkpoint 结构不同，不可混作本分支结果。
