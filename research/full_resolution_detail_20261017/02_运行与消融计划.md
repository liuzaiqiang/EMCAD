# 全分辨率细节研究：运行说明、消融与审查

## 模型接口与计算

原模型返回 `[p4,p3,p2,p1]`，四个张量均为 `[B,K,H,W]`。新模型仅修正最后一个输出：

\[
P=p_1+aR_A(I)+bR_B(I,d_1),\qquad a,b\in\{0,1\}.
\]

A（`lib/full_resolution_detail.py`）把原图通道平均为亮度图，经 3×3 卷积、3×3 逐通道卷积和 1×1 类别投影得到全分辨率残差。B（`lib/semantic_gated_residual.py`）先在 1/4 尺度从 `d1` 学习语义门 `G=σ(f(d1))`，上采样至输入尺度，再对固定高频 `I−AvgPool3×3(I)` 做类别投影并计算 `R_B=Up(G)⊙Proj(highpass(I))`。两者最后投影零初始化，开启时初始输出与 baseline 一致。由于 `d1` 已含 EMCAD 的 LGAG 门控，B 可能重复现有能力。

若 A 的隐层宽度为 `c=8`，额外参数约 `22c+cK+K`；B 的门控宽度 `g=16`、d1 通道 `C` 时额外参数约 `Cg+2g+1+2K`。A 的主要额外乘加量随 `HW(18c+cK)` 增长；B 的门在 H/4 计算，但高频和类别投影在 H×W 上执行。准确 MACs/FLOPs、训练峰值显存以服务器日志实测为准。高分辨率中间激活的显存成本可能高于小参数量给人的印象。

`0/0` 直接构造原 `EMCADNet`，没有新增参数，返回结构仍为四个 logits。启用时用 wrapper；原网络只添加一个默认 `False` 的可选特征返回入口。模块配置保存在训练 `config.json`，测试从 checkpoint 同目录恢复。旧 checkpoint 的缺省模块开关视为 0；对旧 checkpoint 开启模块会因 strict state_dict 校验失败，避免悄悄漏载。预训练骨干加载逻辑、损失、增强、优化器、学习率和评估指标均沿用当前分支。

## 启动示例

在项目根目录、服务器已有数据和 Conda 环境满足脚本要求时：

```bash
USE_FULL_RESOLUTION_DETAIL_BRANCH=0 USE_SEMANTIC_GATED_RESIDUAL=0 bash sh/start_train_synapse.sh  # baseline
USE_FULL_RESOLUTION_DETAIL_BRANCH=1 USE_SEMANTIC_GATED_RESIDUAL=0 bash sh/start_train_synapse.sh  # 全分辨率细节支路
USE_FULL_RESOLUTION_DETAIL_BRANCH=0 USE_SEMANTIC_GATED_RESIDUAL=1 bash sh/start_train_synapse.sh  # 语义门控残差
USE_FULL_RESOLUTION_DETAIL_BRANCH=1 USE_SEMANTIC_GATED_RESIDUAL=1 bash sh/start_train_synapse.sh  # 两者都启用
```

五个 Polyp 数据集使用 `DATASET_NAME=BKAI|ClinicDB|ColonDB|ETIS|Kvasir bash sh/start_train_polyp.sh`；ISIC2017/18 使用 `DATASET_NAME=... bash sh/start_train_isic.sh`；BUSI、ACDC 分别调用专用训练启动器；DSB18/EM 通过 `DATASET_NAME=... bash sh/start_train_cell.sh` 继承 Polyp 开关。每个命令均可前置 `USE_FULL_RESOLUTION_DETAIL_BRANCH`、`USE_SEMANTIC_GATED_RESIDUAL`，默认皆为 0；非法值启动前报错。输出路径含 `variant_baseline/full_resolution_detail/semantic_gated_residual/detail_and_semantic_gate`，外层运行 ID 与日志名也含变体和时间标识。

脚本默认 `WAIT_FOR_TRAIN=1`，会等待训练进程并将其失败状态作为启动器退出码。需要沿用原异步启动行为时可设 `WAIT_FOR_TRAIN=0`；此时启动器只能报告进程启动状态，后续失败须查日志。测试脚本无需手动传模块开关：指定 `CKPT=/absolute/path/to/best.pth`，测试入口读取相邻 `config.json`，按训练时结构严格加载。测试与训练应使用同一代码版本。

## 实验矩阵

每个数据集在固定划分、预处理、种子、训练轮数、checkpoint 选择规则和评估代码下运行四组 `00/10/01/11`。优先顺序：Synapse 及 ClinicDB 的接口与梯度烟雾测试；随后 12 数据集四组完整训练。每组记录参数量、MACs、FLOPs（仓库口径 `2×MACs`）、训练/推理峰值显存和推理时间；至少重复三个种子并报告均值与离散度。保持同等训练预算。

已有整体 Dice、IoU、HD95 等指标继续使用；新增**离线分析**应按训练掩膜定义边界带和小目标分层，预先固定边界宽度与面积阈值，仅用验证集确定分析设置，测试集只做一次最终评估。建议比较边界 F1、surface Dice/HD95、小目标召回和整体指标。另设参数量近似匹配的普通卷积残差头、无语义门/恒定门、随机门及原有插值头对照，排除纯容量效应。不同模态（CT/MRI/超声/皮肤镜/内镜/显微）须分别报告，不能只汇总平均。

## 学术与工程审查

| 组件 | 初步创新性 | 最近先例与区别 | 主要风险及否定条件 |
|---|---|---|---|
| A | 一般偏弱 | PIDNet 的高分辨率细节分支、PointRend 的边界细化；本实现是 EMCAD 最后输出的轻量密集残差适配 | 纹理伪边界、全分辨率显存；若与等参数普通残差头无差异，不能宣称独立机制贡献 |
| B | 证据不足 | PIDNet 的边界/语义融合、EMCAD 自身 LGAG；本实现把门放在 d1→最终 logits 处并限制原图高频注入 | 与 LGAG 重复，且原图高频非真实边界；若 B 单独无效或 AB 不优于 A，不能作为第二创新点 |

两组件研究问题有区别，但**尚不能证明是两个独立、可投稿的原创机制**。尤其 B 是已有门控思想在 EMCAD 输出端的适配。最值得优先做的实验是模块 B 单独消融和等容量对照；若不能稳定产生边界收益，应停止将其作为论文第二贡献，转而重新设计。当前本机未安装 PyTorch、CUDA 或 THOP，只有静态检查；不能声称已完成真实前向、训练、显存或 12 数据集验证。
