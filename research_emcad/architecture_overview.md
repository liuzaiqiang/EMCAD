# 数据流

```text
图像 → 灰度适配(仅1通道) → PVTv2/ResNet → x1,x2,x3,x4
                                           ↓
                       EMCAD: x4→d4→d3→d2→d1 (LGAG skip, CAB/SAB/MSCB)
                                  ↓   ↓   ↓   ↓
                                  p4  p3  p2  p1 → 原有固定倍率插值
                                      └──┴──┘
                                          ↓
                     可选类别原型查询：d3/d2/d1 → K个图像条件原型 → p1修正
                     可选类别条件尺度融合：d3/d2/d1 + p3/p2/p1 → 逐类别尺度权重 → p1修正
```

两个开关为 0 时，模块对象为 `None`，不进入上述新增分支；返回值仍是原先四个 head 的 logits。两个模块均只改变最高分辨率 `p1`，其余三个深监督输出保持原计算。联合启用时，尺度融合把原型查询输出与自身类别查询相加；单独启用尺度融合时使用自身类别查询。
