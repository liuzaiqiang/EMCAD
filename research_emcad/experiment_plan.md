# 实验矩阵

| 配置 | 原型查询 | 类别条件尺度融合 | 目的 |
|---|---:|---:|---|
| baseline | 0 | 0 | 原模型结构与当前训练协议 |
| prototype | 1 | 0 | 原型查询单独贡献 |
| scale | 0 | 1 | 逐类尺度选择单独贡献 |
| joint | 1 | 1 | 是否互补 |

每个任务沿用自身现有划分、分辨率、增强、损失、优化器、学习率与验证频率。相同任务的四组使用相同手动 seed 队列，至少三个 seed，报告均值和标准差。不要把不同任务默认训练设置当成跨任务统一协议。二分类族的 `USE_PIXEL_RELIABILITY_FUSION`、`USE_MULTI_SCALE_TRAINING` 等已有实验开关必须四组固定并在论文列明，建议先设置前者为 0 以隔离本研究机制。Synapse/ACDC 报每器官 Dice、HD95 与宏平均；二分类族沿用各自现有 Dice/IoU 等指标，再补充边界相关指标需在训练后单独且一致地评估。记录参数、FLOPs、推理时间、峰值显存，硬件及 warmup 要统一。

小/大器官分组应按训练集标注面积确定阈值，再固定到验证/测试，不得用测试结果调阈值。画出每类三个尺度的平均权重、面积与权重的关系、边界局部放大、失败样例；普通热力图不构成机制证据。正式比较需要与原 EMCAD 论文复现协议的差异表，并严格隔离验证集选模与测试集最终评估。
